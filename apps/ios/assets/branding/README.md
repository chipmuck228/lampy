Re-render using Node with sharp available (not part of the runtime app):

```js
const sharp = require('sharp');
(async () => {
  await sharp('assets/branding/lampy-icon.svg').resize(1024, 1024)
    .flatten({background: '#F6F0E3'}).removeAlpha().png()
    .toFile('assets/images/icon.png');
  await sharp('assets/branding/lampy-symbol.svg').resize(1024, 1024)
    .png().toFile('assets/images/splash-icon.png');
})();
```
