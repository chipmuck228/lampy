# Splash 与进入「最近」

> 范围：只改 `apps/ios` 启动层与首页过渡。详情、回看、留下、家庭不在本轮。
> 依据：`LAMPY_APP_PRODUCT_DESIGN_GUIDE.md` §10.1、§14 启动进入首页。
> 基线：`origin/main` @ `dc0d1bc`（含 #25）。独立分支，不叠详情改版。

对照：`storyboard.html`。

## 现状

| 层 | 现在 |
| --- | --- |
| 原生 Launch Screen | `expo-splash-screen` 底色已是 `#F3F0E9`。标识是 `splash-icon.png`：白色 A 形描边，透明底。 |
| 对比度 | 白标在暖纸上几乎看不见（约 1.05:1），不能当品牌层。 |
| App 图标 | `ios.icon` 仍指向 Expo 模板 `assets/expo.icon`。本轮不另做一套 Logo。 |
| JS | `_layout` 没有 `preventAutoHideAsync`。首页直接出「最近」，没有品牌淡出，也没有冷启动会话控制。 |

沿用现有 A 形，改成墨色 `#25231F` 画在同一张图上。不发明发光球或第二套标志。

## 改后

| 规则 | 做法 |
| --- | --- |
| 原生 Splash | 底色 `#F3F0E9`，中央 76pt 墨色 A 形。暗色外观也用同一纸色，避免黑闪。 |
| JS 首帧 | 同色底 + 同一张图叠在「最近」上。标题、日期、内容已在最终坐标，位移 0。 |
| 淡出 | 本地 `getRecentLife` 成功或失败后，品牌层 380ms ease-out 透明到 0。不调家庭/网络。 |
| Reduce Motion | 内容就绪后立刻卸品牌层，不播淡出。 |
| 触摸 | 点品牌层立刻结束。 |
| 不重播 | 本进程只播一次。后台恢复、从详情/留下/回看返回首页不重播。 |
| 失败 | 错误文案在首页真实位置出现后卸品牌层。不把错误当成一直在加载。 |
| 超时 | JS 品牌层自己计时 4s。到时卸层，首页露出当时真实状态。读取稍后完成仍更新首页，不重播品牌层。 |
| 首次 / 空库 | 首页空状态已在最终位置，品牌层淡出后看见它。 |

## 状态对照

| 场景 | 品牌层 | 首页 |
| --- | --- | --- |
| 冷启动 · 有记录 | 纸色 + 墨色 A → 380ms 淡出 | 「最近」、日期、记录已在位 |
| 冷启动 · 空库 / 首次 | 同上 | 空状态文案已在位 |
| 读取失败 | 同上 | 错误句已在位，无假数据 |
| 慢启动 | 品牌层等到本地读取结束 | 不转圈、不等网络 |
| 读取一直不返回 | 4s 后卸层，无需触摸 | 显示当时真实首页；之后读到了再更新 |
| Reduce Motion | 就绪后直接卸 | 无淡出 |
| 触摸 | 立刻卸 | 已在位的首页 |
| 热启动 / 后台恢复 | 不出现 | 保持当前「最近」 |
| 从其他页返回 | 不出现 | 不跳动 |

## 原生配置

改 `app.json` 的 `expo-splash-screen` 和 `assets/images/splash-icon.png` 后，**需要重新 `npx expo prebuild --platform ios` 并安装到模拟器/真机**，Launch Screen 才会换成墨色标识。只刷新 JS 只能改 JS 品牌层，改不了系统启动图。

`ios/` 目录被 gitignore，本 PR 只提交资源与 `app.json`。审阅机需本地 prebuild。

走查帧见 `shots/SHOTS.md`。本机已在 iPhone 16 / iOS 18.6 上 `prebuild` + `expo run:ios`。横屏、iPad、iOS 26.2 真机 **NOT VERIFIED**。

## 禁止

独立夜空、粒子、发光球、每次回首页重播、为动画锁页、日期在两套坐标间跳动、Splash 等待家庭服务。
