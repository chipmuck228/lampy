# Moment 详情：多状态版面

> 范围：只改 `apps/ios` 的精确 ID 详情展示层。
> 依据：`LAMPY_APP_PRODUCT_DESIGN_GUIDE.md` §10.5、§11、§12、§15.2；#22 纸色与阅读宽度；#23 滚动与原比例。
> 基线：`origin/main` @ `f9416d9`（含 #26 Splash）。独立分支，不叠启动层改动。

对照：`storyboard.html`。走查帧：`shots/SHOTS.md`。

不改 Moment 数据、媒体文件、发生日期语义、家庭鉴权。Splash 横屏、iPad、iOS 26.2 真机仍标 **NOT VERIFIED**。

## 改前（f9416d9）

| 问题 | 现在 |
| --- | --- |
| 进入点 | 日期是 16pt sage 小字，精度字段已在 ViewModel 但页面不展示。 |
| 阅读宽度 | `min(width, 720)`，与「最近」520 不一致；iPad 上句子被拉成一条线。 |
| 返回 | 「返回原来的位置」写在 `ScrollView` 里，长图或大字号时会滚走，也可能被照片顶到卷轴外。 |
| 纯文字 | 字号对，但行宽过宽、段间等距，像字段清单。 |
| 照片 | 一律全宽纵向叠，2–3 张没有节奏，也不按比例组合。 |
| 声音 | 「一段声音 · 时长」+ 播放，像附件说明，不像当时的一段声音。 |
| 顺序 | 日期 → 字 → 图 → 未知 → 声 → 感受 → 来源 → 分享。顺序对，但层级一样重。 |
| 颜色 | 硬编码，未走 `life-page` token。 |

已有行为必须保留：精确 ID 只读；缺失 / 读失败独立态；媒体原位占位；分享在内容后且受家庭配置门控；返回原位置；播放/暂停。

改前真机参考：`shots/before/text-only.png`（回看日页进详情）、`shots/before/text-fallback.png`（#22/#23 走查）。

## 版面规则

| 规则 | 值 |
| --- | --- |
| 纸色 | `paper` `#F3F0E9` |
| 日期进入点 | 22 / 32，`sage`，`accessibilityRole="header"` |
| 精度 | 15 / 22，`ink-soft`。只映射已有 `precision`，不发明时刻 |
| 正文 | 21 / 32，`ink`，阅读宽度最多 520 |
| 边距 | 窄屏 24 / 常规宽 48，用 `readingPageWidth` |
| 返回 | 钉在安全区内、卷轴外；与正文齐左 |
| 照片 | 单图原比例全宽；2–3 张按 `detailImageBands` 组带 |
| 声音 | 详情用场景态：标题「当时的声音」、时长、发丝进度、播放/暂停 |
| 次要 | 感受、来源 14 / 20 `ink-soft` |
| 分享 | 内容之后；`isFamilyProductEntryOpen()` 才出现 |
| 去 Card | 无圆角、阴影、描边底 |

### 精度只读映射

| `precision` | 页上静句 |
| --- | --- |
| `exact` | 记下了当时的时刻 |
| `day` | 大约是这一天 |
| `month` | 大约是那个月 |
| `year` | 大约是那年 |
| `unknown` | 时间未确认 |

`dateLabel` 原样使用（含「记录于 …」回退句）。不改 `occurredAt` / `recordedAt`。

### 照片组带

| 张数 / 比例 | 组带 |
| --- | --- |
| 1 | 一条全宽，原宽高比 |
| 2，两张可读竖图 | 并排一对，各守自己的比例 |
| 2，任一为横 | 上下各一条，避免横图被挤扁 |
| 2 或 3，组里有缺失 | 改为纵排，顺序不变；占位随文字长高，不被半宽比例框裁掉 |
| 3，后两张都可读竖图 | 第一张全宽，后两张并排 |
| 缺失 / 未知 | 占原来的位置，不改成别的记录 |

Recent / 留下仍用纵向叠，不套组带。

### 叙事顺序

1. 日期  
2. 精度  
3. 文字（若有）  
4. 照片组带  
5. 未知媒介占位  
6. 声音场景  
7. 当时的感受  
8. 来源  
9. 分享给家里（门控）

空块不占位。加载中只留返回，不造假内容。

## 多状态方案

| 状态 | 页上 |
| --- | --- |
| 纯文字 | 日期作进入点，精度静句，正文按 520 阅读宽度，大量留白，无框 |
| 单图 | 字下（或无字时直接）一张原比例图 |
| 两张竖图 | 并排一对 |
| 三图 | 首张全宽，后两张能并则并 |
| 仅声音 | 日期后是「当时的声音」场景，可播可停 |
| 图 + 声 | 同一条记录里先图后声，不拆成附件列表 |
| 照片缺失 | 该格原位说明，字和其他媒体还在 |
| 声音缺失 | 播放禁用，原位说明 |
| 未知 Asset | 中性占位，不当成第 N 张照片 |
| 长内容 | 可滚到最后一行；返回始终可见 |
| 最大字号 | chrome 不缩小倍率；内容可滚完，不压返回 |
| Moment 不存在 | 独立句，不换成相邻记录 |
| 读失败 | 说明还在 + 再试一次 |
| 家庭未配置 | 无「分享给家里」 |
| 家庭已配置 | 分享在来源之后 |

横屏短高度：顶距收为 4–8pt，返回仍钉住。iPad：正文 520，列居中。这两项与 iOS 26.2 真机本轮若未走上则标 **NOT VERIFIED**。

## 禁止

改发生日期语义、改媒体文件、把详情做成可编辑、用相邻 Moment 填空、假波形、大卡片、把分享做成社交互动、把返回滚进长图下面。
