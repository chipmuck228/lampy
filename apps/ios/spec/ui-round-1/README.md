## 1. 当前问题（改前）

下列判断来自 `origin/main` 的页面实现（`app/index.tsx`、`app/leave.tsx`）。真机截图见 `shots/before/`；若该目录只有源码还原页，则真机项标 **NOT VERIFIED**。

### 最近

1. **日期贴在每一条上**，同日多条各自重复「9月24日」，没有共享的日期语境（指南 10.2：同日共享一个日期锚点）。
2. **条目等距、等高节奏**，`gap: 20` + 每条 `paddingVertical: 8`，去掉边框后仍像通用列表，而不是疏密变化的生活段落。
3. **第一视觉是顶栏控件**：`最近` 与 `回看` `留下`（及可选 `家庭`）抢同一行；内容要滚过 chrome 才开始（指南：最近一天的真实内容先被看见）。
4. **空状态不像第一次留下**：文案是「最近还没有留下什么。」，没有「这里，留下自己的生活。」和「留下第一条」。
5. **阅读宽度拉到 720**，iPad 上句子被拉成一条横线，不像一页生活册。
6. **错误只是一行字**，语义正确，但和列表条目没有层级区分。

### 留下

1. **空白输入框先占 160pt**，未写字时像表单字段，不像一张正在形成的生活页。
2. **拍摄 / 照片 / 留下纵向堆在内容后面**，和感受词表同一份「控件清单」；键盘弹出时主操作容易被顶出屏幕。
3. **感受词表视觉重量接近模板选择器**：标题 + 一排 chip 占据创作面中部。
4. **声音入口和照片入口不在同一操作带**，「声音」在内容流里，「拍摄/照片」在底部，像两套工具栏。
5. **恢复草稿只有说明、没有放弃**（放弃在 #20，本轮只保留已有说明，不发明半套放弃）。
6. **没有发生日期**（#21）；本轮不补，避免和未合并逻辑分叉。

源码还原页：`storyboard.html` 中「改前」各帧。

## 2. 版面规则

| 规则 | 值 | 用途 |
| --- | --- | --- |
| 背景 `paper` | `#F3F0E9` | 整页 |
| 正文 `ink` | `#25231F` | 标题、记录文字、主操作「留下」 |
| 次级 `ink-soft` | `#5C5851` | 说明、恢复提示 |
| 时间/导航 `sage` | `#53604F` | 日期、回看、家庭、拍摄/照片 |
| 错误 `clay` | `#87513D` | 失败与权限说明 |
| 声音 `sound` | `#4F626D` | 录音状态（沿用现有声音组件） |
| 细线 `hairline` | `rgba(37,35,31,0.16)` | 留下页操作带顶线，仅此一处 |
| 正文阅读宽度 | 最多 520 | 只含文字和照片，不含边距和日期轨 |
| 日期轨+正文 | 120 + 32 + 520 = 672 | 边距在外侧；iPad 页宽 768 |
| 边距 | 窄屏 24 / 常规宽 48 | 算在阅读宽度之外 |
| 日期 | 16 / 22，`sage`，一天一次 | 段落起点；分组用含年的 `dayKey` |
| 记录正文 | 21 / 32，`ink` | 先于控件 |
| 日间间距 | 日块 40，同日条 36，条内 8 | 疏密来自内容关系，不机械等距 |
| 照片 | 原宽高比，全宽，最多三张纵向组合 | 不裁成方缩略图；`maxHeight` 520 |
| 声音 | 现有播放/暂停/时长/失败文案 | 不做装饰波形 |
| 主操作 | 「留下」「留下第一条」 | 文字，不悬浮圆钮 |
| 次操作 | 「回看」「拍摄」「照片」「声音」 | `sage`，44–48pt |
| 空 | 价值句 + 一条主操作 | 不放假记录 |
| 错 | 先说内容还在，再说能做什么 | 不覆盖草稿或已保存记录 |

去 Card 检查：无圆角、无阴影、无描边列表。结构只靠日期、字级、留白和媒介比例。

## 3. 真实内容下的页面方案

每一种都要能在真机用真实草稿/记录走到，不能只做理想态。

| 状态 | 最近 | 留下 |
| --- | --- | --- |
| 首次使用 | 价值句 +「留下第一条」；顶栏仍有「留下」「回看」 | 空白页：一句占位、声音入口、感受可选、底栏拍摄/照片/留下 |
| 单条纯文字 | 一个日期 + 一句正文，大量留白 | 文字在页上生长，底栏不压字 |
| 同日多条 | 日期只出现一次，条与条用留白分开 | — |
| 1–3 张照片 | 原比例叠在该条文字下 | 照片插在文字和声音之间，不是附件列表标题 |
| 声音 | 「一段声音 · 时长」+ 播放 | 录制中显示时长；停止后可听、重录、移除 |
| 混合 | 字 / 图 / 声 / 感受按内容顺序 | 同一页组合，不先选类型 |
| 恢复草稿 | — | 已有说明：「上次还有一些内容没保存…」；继续编辑。放弃待 #20 |
| 媒体缺失 | 该照片/声音原位说明，记录仍可点开 | 已留下的字和其他媒体保留 |
| 保存失败 | 不出现半条新记录 | 底栏上或内容流显示失败句，草稿仍在，可再试 |
| 读取失败 | 「最近的记录暂时读不出来…」 | 「草稿暂时读不出来…」 |

横屏短高度：顶距收为 4pt，内容可滚，留下底栏仍在键盘上方。

## 4. 大字号、VoiceOver、横屏、iPad

- **Dynamic Type**：不设缩小倍率。最近页顺序为标题「最近」→ 次要「家庭/回看」→ 主操作「留下」，各有独立 48pt 点击范围，可纵向排列。
- **VoiceOver**：最近为「最近 → 家庭/回看 → 留下 → 日期 → 该日各条」。留下为「最近（返回）→ 恢复说明 → 文字 → 照片 → 声音 → 感受 → 错误 → 拍摄/照片/留下」。
- **横屏**：`height < 500` 时压缩顶距；留下底栏改为纵向：拍摄/照片一行，留下单独一行。不出现悬浮钮。
- **iPad / 常规宽（≥768 且高度足够）**：正文 520；日期轨 120 在外侧，不挤占阅读宽度。横屏手机不当成平板。
