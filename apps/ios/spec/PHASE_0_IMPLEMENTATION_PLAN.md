# Phase 0 之后的 iOS 实施清单（按独立 PR）

每条 PR 必须可单独审查、带测试、不改微信小程序领域代码。第一条可运行功能固定为纯文字个人闭环。

## PR-1（下一条可合并功能）— 纯文字个人 Moment

**必须同时具备：**

1. 创建纯文字个人 Moment（非表单字段堆，但是可先用低装饰结构）；
2. 草稿自动恢复（同一 draft id，不自动激活、不自动分享）；
3. 持久保存到本机 SQLite（经 Use Case，不经 Screen 拼行）；
4. 「最近」展示刚保存的记录；
5. 用 **精确 Moment ID** 打开只读详情；找不到则独立错误，不回退其它记录。

验收（自动化，可用临时 SQLite）：

- 空库不出现 mock；
- 连点保存不产生重复 Moment；
- 杀进程后文字仍在（集成测试模拟重启）；
- `createdAt` / `recordedAt` 不冒充用户未确认的发生时间精度；
- Repository 错误不删除已有数据。

本 PR **不做**：图片、录音、家庭、账号、同步、significance、通用 UI kit。

## PR-2 — 图片（最多 3 张）

拍摄或相册；临时文件转持久 Asset；application 强制 ≤3；缺失图不删 Moment。权限仅在用户点「照片」时请求。

## PR-3 — 现场录音（最多 1 段）

录制 / 停止 / 试听 / 删除。无音频文件导入入口，除非另开 ADR。权限仅在用户点「声音」时请求。真机验证录音中断。

## PR-4 — 回看（年 / 月 / 日）

复用日历边界语义，不用随机坐标、不用标准日/月/年 Tabs。返回恢复滚动与所选时间。

## PR-5 — 媒体失败与权限拒绝

拒绝相机仍能写字；磁盘不足可恢复；部分 Asset 原位降级。

## PR-6 — 当时的感受（可选）

展示层映射 `content.emotion`；未知旧值安全显示。不做趋势。

## PR-7 — 家庭（仅当真实能力存在）

先审计邀请/成员/送达。禁止 mock 家庭 feed。Transmission 独立写入。

## PR-8 — 无障碍与品质

超大字号、VoiceOver、Reduce Motion、横屏、iPad 分屏。真机清单。

## 明确不排进近期 PR

公开社交、点赞评论、AI、significance、3D 核心浏览、把微信 WXML 译成 RN。
