# ADR 0004：家庭同步隔离边界

状态：已接受（Phase 0）
日期：2026-09-24

## 决策

家庭、网络送达、跨设备同步 **不是** Moment 上的布尔字段，也不是本轮 UI 可以宣称的能力。

Transmission 保持独立实体。本地 `status: sent` 只表示「用户确认了分享意图」，**不是**家人已收到。

## 隔离

```text
个人本地 Moment / Asset / Draft
        │
        │  仅经明确 use case
        ▼
Transmission 记录（本地意图）
        │
        │  未来独立同步管道（未实现）
        ▼
家庭成员 / 账号 / 网络送达
```

- iOS application 不得在未实现同步时把「家庭」做成可切换的假范围。
- 不得写入假联系人、假已送达、假家庭时间线。
- 垂直切片（PR-1）只做 **个人、本机**。
- 家庭页、邀请、撤回、云同步另开 Phase 3，且必须先有真实能力审计。

## 后果

产品文案在未送达时只能写「已经保存在这台设备上」，不能写「家人已收到」。
