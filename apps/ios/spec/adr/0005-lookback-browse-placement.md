# ADR 0005：回看浏览位置

状态：已接受
日期：2026-09-24

## 决策

回看的年 / 月 / 日格子只使用 `time.occurredAt` 与 `time.occurredAtPrecision`，并按查看者时区的自然日边界计算。`recordedAt`、`createdAt` 和媒体拍摄时间不得决定格子。

| 精度 | 浏览位置 |
| --- | --- |
| exact / day | 发生时间所在自然日 |
| month | 该年该月的「日子未确认」，不进入某一天 |
| year | 该年的「月份未确认」，不进入某一个月 |
| unknown 或没有 occurredAt | 「时间未确认」，不进入任何年、月、日 |

`recordedAt` 只在「时间未确认」条目上显示为「记录于 …」，并带 `usedRecordedAtFallback`。

查询按发生时间的时区范围分页：年页只读该年范围，日页只读该日范围。年列表只读非 unknown 的 `occurred_at` 值，不读 Asset。未知时间单独计数和分页，按记录时间新到旧。

## 恢复范围

- 所选年 / 月 / 日写在路由参数里；栈内返回保持原页。
- 滚动位置只记在本次进程内存。
- 冷启动回到「最近」，不自动跳回上次回看位置。
