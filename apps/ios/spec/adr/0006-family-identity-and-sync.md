# ADR 0006：家庭身份与同步

状态：已接受（产品与架构决策已锁定；实现按切片交付）
日期：2026-09-25
基线：`origin/main` = `c6b8d4b`

## 背景

ADR 0004：家庭 / 网络送达不是 Moment 布尔字段；本地 `Transmission.sent` 不是家人已收到。Phase 0–2 只做个人本机闭环。仓库在本 ADR 定稿时仍无账号服务、无家庭表、无部署中的 API。

## 已决定

1. **个人库与登录分离。** 个人 Moment 继续只存在 iOS SQLite。未登录可用现有个人记录、媒体、回看、感受。进入家庭能力才要求登录。历史 `ownerId=local-user` 行不因登录被改写或迁走（账号与个人行的合并若需要，另开迁移 ADR）。
2. **登录。** iOS 首个方式为 Sign in with Apple。服务端校验 identity token，分配 Lampy 稳定 `userId`。Apple `sub` 只作外部身份关联。邮箱不得作主键。Apple 登录成功 **不等于** 家庭成员资格。
3. **授权在服务端。** 成员关系与家庭访问由服务端逐请求裁定。第一版一个账号最多加入一个家庭；存储不要写死该上限。创建者可邀请、移除、解散。成员可退出，且只能分享自己的记录。创建者不能读取他人未分享的个人记录。
4. **邀请。** 可撤销、一次性、限时。接受必须已登录，服务端重新检查邀请、家庭、成员资格。新成员默认不能访问**加入之前**已分享的内容。
5. **分享（后续切片，本轮不实现）。** 用户明确选择的 Moment **固定 revision 快照**。编辑个人原件不自动改已分享版本。媒体不得传设备本地路径。接收副本必须保留来源与家庭访问范围，**不能**因写入本机就变成不受家庭权限约束的普通个人 Moment。
6. **传输阶段。** 分清：等待上传（本机作业）、服务端已保存、接收设备已取得并写入。现有 `Transmission.sent` ≠ 对方已收到。领域枚举暂不增加 `queued`/`delivered`；application 用作业状态表达，不把本地 `sent` 显示成已送达。
7. **资格结束后的读权（解决快照矛盾）。** 撤回、退出、移除或解散后，服务端停止提供相应家庭内容。个人原始记录不删除。App 必须清理其控制的家庭缓存（含已写入的接收快照缓存）。产品 **不能** 承诺收回他人此前下载、导出、截屏的副本。无法向服务端确认权限时，**不展示**家庭内容；个人库仍可离线使用。
8. **删除类操作分开。** 个人归档不自动撤回分享。删除个人原件、撤回分享、删除账号是不同命令，各有结果与失败恢复。创建者退出前必须移交创建者身份或解散家庭。
9. **首版分享字段。** 不含 `context.people`。确认界面必须让用户看见将要分享的字段。不得默认序列化整个领域对象。

## 快照矛盾的结论

领域把 received 写成「接收者自己的 Moment」。若把它落进个人 `moments` 表并按个人详情展示，退出家庭后仍能读，就与「服务端停止提供 / 无法确认权限则不展示家庭内容」冲突。

**产品规则：** 接收快照是**家庭授权下的缓存副本**，不是个人库的新主人记录。

- 在 App 内：失去成员资格或无法确认授权后，不得再展示该快照（家庭页、详情、个人最近/回看都不得把它当成普通个人 Moment）。
- 服务端：停止对该用户提供该内容。
- App：删除或隔离其控制的家庭缓存。
- 设备外副本：无法保证收回。这不是「退出后 App 里仍可打开收到的记录」。

## 否决

- 用 `local-user` 假装多人。
- 用微信 nearby mock 当接收。
- 用 iOS 个人列表换标题当家庭 feed。
- CloudKit 家庭容器作为首版（与「邀请组成的私人空间」不同构；本轮不采用）。
- 仅设备互加、无服务端裁定。

## 实现位置（技术选型，不是产品未决）

- 家庭身份与成员命令先放在 iOS 仓库内可测试的服务端模块（`apps/ios/src/family-api`），由 HTTP 暴露。不改根目录微信 `domain/`。
- 生产部署、Apple 密钥、公网 URL **本仓库尚未具备**。未配置时服务可跑测试，不得编造生产密钥或假成功。
- Transmission / 快照存储的共享领域扩展留给分享切片；本轮不改微信领域文件。

## 后果

- 个人默认私密与未登录闭环不变。
- F1 只做身份与成员。F3 之后才允许分享 UI。
- 本地缓存永远不能单独证明当前家庭授权。
