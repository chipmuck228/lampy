# ADR 0006：家庭身份与同步基础设施（Phase 3A）

状态：提案（待用户决定后才能进入实现切片）
日期：2026-09-25
基线：`c6b8d4b`

## 背景

ADR 0004 已隔离：家庭 / 网络送达 / 跨设备同步不是 Moment 布尔字段；本地 `sent` 不是家人已收到。Phase 0–2 只做了个人本机闭环。

产品 Phase 3 要求真实成员、明确分享、家庭时间页和失败幂等。当前仓库没有账号、家庭、邀请或同步管道（见 `FAMILY_CAPABILITY_AUDIT.md`）。

## 决策（本轮能锁定的）

1. 继续遵守 ADR 0004：未有真实能力前，iOS 不画可切换的假家庭范围，不写假联系人、假已送达、假时间线。
2. 家庭权限不落在 Moment 的单个布尔或单独改 `accessSummary`。
3. 接收沿用已有「接收者自己的 Moment + snapshotRevision」方向，不在本 PR 改共享领域代码。
4. 需要新增 Family / Membership / Invitation，或给 Transmission 增加家庭目标 / `queued` / `delivered` 时，**先单独开根目录领域 PR**，再让 iOS 适配。
5. 个人 Moment 默认私密不变；家庭管理员不得替成员创建私人记录。

## 候选方案（身份 + 同步）

下列均为候选，**本轮不选定**。

| 方案 | 优点 | 成本与风险 | 与现有领域 |
| --- | --- | --- | --- |
| A. Sign in with Apple + 自建同步 API | 账号可撤销；状态有服务端证据；与「私人空间」可控 | 要建后端、审计、删除账号；商店与隐私清单 | Transmission 需服务端 id；`local-user` 必须迁移 |
| B. iCloud / CloudKit 家庭容器 | 少自建服务器 | 成员模型受 Apple 家庭/容器限制；难以表达自定义邀请/撤回证据；跨 Android 无 | 家庭身份可能绑 Apple 家庭，与「邀请组成的私人空间」不一定同构 |
| C. 仅设备 + 本地二维码互加 | 无账号服务器 | 无跨设备恢复；无法证明送达；丢失即丢成员图 | 仍不是 `local-user` 可扩展的多人模型 |
| D. 电话/邮件自建账号 | 熟悉的邀请通道 | 验证、滥用、未成年人保护成本高 | 同上，需迁移 ownerId |

**否决作为家庭 MVP：** 继续只用 `local-user` 假装多人；用微信 nearby mock 当接收；用 iOS 本机列表当家庭 feed。

## 数据迁移与隐私

- iOS 现有表（`moments` / `drafts` / `assets` / `record_quarantine`）继续表示**个人本机**数据。家庭表（成员、邀请、Transmission、接收快照）应新表或新库段，不复用微信 Key `lampy_transmissions`。
- 引入真实 `accountId` 时：必须有把历史 `ownerId=local-user` 行归到该账号的迁移 ADR；失败不得丢失个人记录。
- 不跑 `migrate-lights-to-moments-v1` 来「生成」家庭。
- 日志仍不得记录私人正文、原图、原音频（产品指南 §15.4）。
- 公开发布家庭分享前，UGC / 未成年人 / 举报屏蔽 / 账号删除仍是发布门槛（§16.3），不能用本 ADR 代替法律意见。

## 需要用户决定的事项

未决定前，实现切片不得把其中任一项写成默认产品行为。

1. 账号与同步选 A / B / C / D 还是其他。
2. 一人能否同时加入多个家庭。
3. 是否有管理员；谁可邀请、移除、解散。
4. 分享目标是家庭空间还是点对点成员；Transmission 是否新增 `familyId`（共享领域 PR）。
5. 加入前已分享内容是否对新人可见。
6. 主动退出后，已落盘快照：保留 / 只读 / 删除。
7. 被移除后是否与第 6 条相同。
8. 撤回后接收端已落盘快照：删除 / 标已撤回仍可读 / 仅停同步。
9. 原 Moment 编辑后：旧快照继续、提示更新、还是必须新 Transmission。
10. 接收端 Asset：复制文件还是引用云 key。
11. 家庭解散后的内容归属与谁可解散。
12. `queued` / `delivered` 是否进入领域 status（当前枚举没有）。
13. 快照在发送时打包还是仅在接收时物化。
14. `context.people` 是否进入快照。
15. 已分享 Moment 被归档/回收后，家庭页如何处理。
16. 最后一位成员离开是否自动解散。
17. 邀请过期时间与邀请通道（链接 / 码 / 系统分享）。
18. UGC 发布的目标市场与最低治理集合（举报、屏蔽、未成年人）。
19. 品牌是否正式使用「家庭」作为一级入口名称。
20. 历史 `ownerId=local-user` 行如何归到真实账号。

## 后果

- Phase 3A 只交文档。
- 下一刀是「真实身份与成员」，不是家庭时间页 UI。
- 共享领域变更与 iOS 适配拆开审阅。
