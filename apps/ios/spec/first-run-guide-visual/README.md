## 每屏结构

系统图标 + Lampy 并排 → 照片 → 照片内短句 → 一句主张 → 一句解释 → 短线段进度与操作。

取消功能标签、额外引言、「自己的生活记录」等重复层。不加入统计或装饰卡片。

| 屏 | 照片 | 照片内短句 | 主张 | 解释 | 操作 |
| --- | --- | --- | --- | --- | --- |
| 1 | 午后咖啡与窗边光线 | 一杯咖啡，一段午后。 | 日子，不必特别才值得留下。 | 不必写成故事。把这一刻，轻轻留给自己。 | 继续 |

| 3 | 窗边植物与灯 | 有些日子，值得再坐一会儿。 | 从一个日子，继续读起。 | 回到那一天，慢慢读完。过往就在这里，允许停留。 | 留下瞬间；可上一屏 |

## 契约（未改）

1. 只有最后点击「留下瞬间」才写首次完成标记。
2. 中途退出不算完成；完成后不重播。
3. 已有记录、读库失败、存储异常沿用 `decideFirstRunGuide` / `finishFirstRunGuide`。
4. 完成后的落点仍是现有 `leaveHref('recent')`，不强制改路由。
5. 上滑翻页保留；长正文先滚动，到底后才允许翻页。
6. 最后一屏继续上滑不能代替点击完成。

## 动画

照片在 `onLoad` 后从 0 淡入到 1，约 500ms；标题和解释作为一块约 450ms，晚约 100ms。图片失败仍保留文案和操作。相邻未到屏保持透明，不先完整出现再重播。不自动翻页，不阻塞继续 / 返回 / 留下瞬间。Reduce Motion 开启或查询失败时直接完整显示。只在 AppState 为 active 且未开 Reduce Motion 时启动页动画。切后台、快速翻页、返回时取消动画与延迟，恢复 opacity=1、位移=0。旧回调不作用于新页。不重新挂载 Gate，不绕过本机保护。

分页宽高来自 SafeArea 内实际容器测量，正文列和照片只从该尺寸算一次 gutter。三屏按屏幕 ID 记住正文视口／内容高度；切屏不丢测量。窗口尺寸变化才失效并重测；未测完不当成“正文不需要滚动”。尺寸变化后当前页对齐对应分页位置。

## 与原型差异

- 无网页手机外壳、状态栏、Home Indicator。
- 无 01 留下 / 02 最近 / 03 回看 功能标签，无「为平常的生活…」引言。
- 字色、短线段进度、顶栏标识和右侧留白按 splash 原型；字体用随包 Noto / DM Sans 子集，不运行时拉 Google Fonts。
- 不从 Unsplash 运行时加载。
- 照片按窗口和 `readingWidth` 裁切，不按 852 网页框写死高度。
