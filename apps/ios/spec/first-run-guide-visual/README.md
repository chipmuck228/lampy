## 每屏结构

简洁 Lampy 标识 → 照片 → 照片内短句 → 一句主张 → 一句解释 → 进度与操作。

取消功能标签、额外引言、「自己的生活记录」等重复层。不加入统计或装饰卡片。

| 屏 | 照片 | 照片内短句 | 主张 | 解释 | 操作 |
| --- | --- | --- | --- | --- | --- |
| 1 | 午后咖啡与窗边光线 | 一段咖啡，一段午后。 | 日子，不必特别才值得留下。 | 不必写成故事。把这一刻，轻轻留给自己。 | 继续 |
| 2 | 窗边花朵 / 晨光 | 今天，也有想记住的光。 | 轻轻扫过，也能看见日子的样子。 | 文字、照片和声音，保留原来的样子。想再读一遍时，随时停下来。 | 继续；可上一屏 |
| 3 | 窗边植物与灯 | 有些日子，值得再坐一会儿。 | 从一个日子，继续读起。 | 回到那一天，慢慢读完。过往就在这里，允许停留。 | 留下瞬间；可上一屏 |

不用原型的「不必翻找」或「进入 Lampy」。

照片随包离线，来源见 `apps/ios/assets/first-run/SOURCES.md`。

## 契约（未改）

1. 只有最后点击「留下瞬间」才写首次完成标记。
2. 中途退出不算完成；完成后不重播。
3. 已有记录、读库失败、存储异常沿用 `decideFirstRunGuide` / `finishFirstRunGuide`。
4. 完成后的落点仍是现有 `leaveHref('recent')`，不强制改路由。
5. 上滑翻页保留；长正文先滚动，到底后才允许翻页。
6. 最后一屏继续上滑不能代替点击完成。

## 动画

照片轻微淡入，文字短距离出现。不自动翻页，不循环，不强制等待。Reduce Motion 查询结束前按静态显示；查询失败也静态。切后台、快速翻页、返回时取消旧动画，恢复 opacity=1、位移=0。旧回调不作用于新页。不重新挂载 Gate，不绕过本机保护。

## 与原型差异

- 无网页手机外壳、状态栏、Home Indicator。
- 无 01 留下 / 02 最近 / 03 回看 功能标签，无「为平常的生活…」引言。
- 字号用现有 `type.title` / `type.body` / `type.meta`，不照搬网页 11px，不 `nowrap`。
- 不从 Google Fonts 或 Unsplash 运行时加载。
- 照片按窗口和 `readingWidth` 裁切，不按 852 网页框写死高度。
