# 尚无真实实现的能力

更新日期：2026-09-25。空壳 UI **不得**用文案或假数据宣称下列能力已存在。

| 能力 | 仓库事实 | iOS 现状 |
| --- | --- | --- |
| 家庭成员 | 产品已决定（ADR 0006）；仓库无账号服务、无成员表 | 未实现。细目见 `FAMILY_*` |
| 网络送达 | `Transmission.status = sent` 只是本地意图；不等于对方已收到 | 未实现。细目见 `FAMILY_ACCESS_AND_SNAPSHOT.md` |
| 跨设备同步 | 无账号、无云、无冲突合并 | 未实现。细目见 `FAMILY_CAPABILITY_AUDIT.md` |
| Sign in with Apple / Lampy `userId` | 决策已定；无服务端、无生产密钥 | 未实现 |
| 接收快照退出后仍当个人 Moment | **禁止**。快照是家庭缓存，资格结束后 App 内不展示 | 能力未交付；规则见 ADR 0006 |
| 音频从文件/系统资源导入 | 微信记录页是现场录音；无已验收的导入用例 | **不得做入口** |
| 家庭时间线 | 无有权读取的家庭内容源 | 未实现 |
| 撤回 / 送达状态变化 | 领域有 status 枚举，无网络状态机 | 未实现 |
| 相机 / 相册写入 iOS | 已接 `expo-image-picker` + 持久文件 + 独立 Asset | 已实现；真机权限未验证 |
| 麦克风录音 | 已接 `expo-audio` 现场录音；无导入入口 | 已实现；真机麦克风/来电/后台未验证 |
| SQLite Moment 仓库 | iOS 已建 `moments` / `drafts` / `assets` 表 | 文字、图片、录音、回看与当时感受闭环 |
| 草稿持久化（iOS） | iOS `drafts` 表 + Use Case 恢复 | 已实现文字、图片、录音与当时感受草稿 |
| 当时的感受 | 领域 `content.emotion` 自由字符串 | 已实现可选词表与未知旧值原样展示；无趋势/评分 |
| significance | 领域有字段，页面未采集 | MVP 不做 |
| 公开社交 / 点赞 / AI | 规格禁止 | 不做 |
| 暗色完整主题 | 待决定 | 未交付 |
| 编辑 / 删除详情内容 | 详情只读 | 未实现 |
| 真机权限与音频中断 | 需真机 | **未验证** |
| 真机从系统设置恢复相机 / 相册 / 麦克风 | 自动化已覆盖可注入拒绝→恢复；真机设置页未走 | **未验证** |

当前 `apps/ios` 交付个人文字、最多三张照片、一段现场录音、年/月/日回看与可选当时感受闭环。页面不得宣称家庭或同步已经接上。不得提供导入音频文件入口。家庭产品规则见 ADR 0006；仓库实现事实见 `FAMILY_CAPABILITY_AUDIT.md`。
