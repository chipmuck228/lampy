# 生活回眸 · 用户许可

出现在确认页，用户点「开始整理」之前必须能读完。第一版只覆盖**本机分析**。文案可微调语气，不能删掉带 **[必要]** 的句子。

---

## 1. 确认页正文（第一版）

**标题：** 在开始之前

**范围行（按选择代入）：** 这次整理的是你留下的 **2023年8月** 个人记录。

**[必要]** 整理在这台设备上完成，不经过 Lampy 的服务器，也不发给其他公司的接口。

**本次会用到（[必要]，数字来自确认页摘要）：**

- 你写过的文字；
- 你主动写下的「当时的感受」（没写的不会被猜）；
- 照片和声音的**数量、类型、是否还在、录音时长**。  
  第一版不会把照片画面或声音内容送去识别或转写。

**这次不会用到（[必要]）：**

- 家庭里收到的内容；
- 时间还没确认、因而不在这个范围里的记录；
- 你没有选中的其他年份或月份；
- 账号、邀请或设备里的其他文件。

**会保存什么（[必要]）：** 一份短的「生活回眸」。它是整理结果，不是原来的记录。你可以删掉这份回眸；删除不会拿掉原来的文字、照片和声音。

**可以怎样停下来（[必要]）：** 整理过程中可以取消。取消后不会留下半份回眸。原来的记录还在。

**按钮：** 「开始在本机整理」 / 「先不整理」

辅助说明（推荐，非必要）：回眸不是把那段日子重新过一遍。没有写下的日子，不会被写成空白的生活。每一段都可以回到它用过的那条记录。

## 3. 以后若增加云端

**[必要]** 不能把本节第一版许可当成云端许可。

若产品要改为（或增加）在服务器、其他设备或第三方模型上处理：

1. 另写方案（范围、传输字段、保存位置、保留时长、谁能读）；
2. 用**新的**确认文案，写明离开本机；
3. 必须再次由用户明确授权；
4. 未授权时保持本机路径或不可用状态，**不得**静默回退到云端。

阶段 A/B/C 都不实现云端回眸。
