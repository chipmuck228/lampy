## 1. 三个方案（同一范围，不同页）

用户已经能在书页里读原件。回眸要解决的是：主动选一个月或一年之后，要不要多一份短文。三案必须并排看。

| | **A · 现有时间书页** | **B · 不使用模型的范围原件** | **C · 端侧短回眸（本提案）** |
| --- | --- | --- | --- |
| 用户做什么 | 在 `/lookback` 展开年/月/日，点「看这条」 | 选一个月或一年，按时间看该范围内的原件列表 | 选范围 → 看见将使用哪些内容 → 确认许可 → 得到短文 |
| 读什么 | 原 Moment：文字、图、声、感受 | 同左，只是先收成一个范围 | 第一版：原文摘录按来源排列，每段可点回精确 ID。图/声只随原记录展示 |
| 模型 | 无 | 无 | 仅本机。媒体字节不进模型。不可用则停，不转公用 API |
| 空白 | 安静格 / 中性空说明 | 列出该范围实际有的记录；没有就说没有 | 证据不够则只展示原件或不出归纳；禁止「这一年你很安静」 |
| 感受 | 有则显示，无则不写 | 同左 | 只把用户已填的感受当上下文；空感受不推断 |
| 失败 | 读失败保留原记录 | 同左 | 生成失败不影响最近、回看、原媒体 |
| 家庭 | 底带入口条件不变 | 同左 | 同左。不读接收快照 |

**推荐：A 继续是回看默认。C 是从年或月主动发起的可选动作。B 是 C 的失败/不够证据时的退路，也是用户取消生成后仍能读原件的页。**

不推荐用 C 替换 A。书页已经能读；回眸若写错，用户必须还能回到原件。也不推荐一进回看就自动跑模型。

C 的禁止项（与产品指南一致，且本阶段写死）：

- 不自动推送、不自动运行、不自动分享
- 不生成新图片、不转写或识别声音、不识别照片内容
- 不计算情绪趋势、积极率、人生评分、连续天数
- 不把家庭、邀请、账号资料或整个个人库交给模型
- 不把本机路径或媒体字节交给模型
- 不把记录空白解释成生活空白
- 不写纪念馆 / 告别 /「还原那段日子」

## 2. 完整流程

入口只从回看书页的**年章节**或**已展开的月**发出，文案「生活回眸」。不进最近、不进详情、不进家庭。范围只能是一个月或一年。

```text
书页年/月 → 选范围（若从月进入则范围已定）
        → 看见本次将使用哪些内容
        → 读许可并主动确认
        → 生成中（可取消）
        → 预览（未保存：可点来源、可离开、可再生成）
        → 「保留这份回眸」（主动保存）
        → 点来源 → 现有 `/moment/:id`
```

任一步都可以回到书页。预览通过机器校验**不等于**自动保存。取消、离开预览或杀进程都不留下衍生物。只有用户点「保留这份回眸」之后才有可删的一份。原始 Moment 始终不变。

### 2.1 将使用哪些内容（确认前必须看见）

确认页只展示本机已经决定送进分析的摘要，不展示家庭内容，不展示未选范围：

- 范围标签：`2023年` 或 `2023年8月`
- 范围内个人记录总数（按与书页相同的落位规则）
- 其中：有文字 N 条、只有照片/声音 M 条、发生日期未确认（若用户选了年/月，这些**不计入范围**，单独一句「时间未确认的记录不在这次里」）
- 本次实际会送进模型的条数与覆盖说明（见 §4）
- 媒体：只写「N 张照片、N 段声音」，并标明缺失数。不预览路径，不把字节送进去
- 感受：写「其中 N 条你写下了当时的感受」。没有则不出现推断语

用户在确认前可以放弃。第一版不要求逐条勾选；若复审认为必须能排除某条，见 §8。

### 2.2 必须出现的真实状态

| 状态 | 用户看见 | 模型 | 原记录 |
| --- | --- | --- | --- |
| 模型不可用 | 「这台设备现在不能在本机整理回眸。」可改看原件（B） | 不调用，不转云 | 不动 |
| 内容太少 | 「这次留下的文字还不够整理成回眸。」展示原件或回书页 | 不调用 | 不动 |
| 只有媒体 | 「这些记录主要是照片或声音，第一版不识图、不听声，所以没有短文。」可点原件 | 不调用 | 不动 |
| 发生日期不确定 | 选年/月时，`unknown` **不进入**本次范围；确认页写明 | 不看到这些 ID | 不动 |
| 范围内只有 year 精度却选了某月 | 该年未确认月的记录不进该月回眸（与书页一致） | 不看到这些 ID | 不动 |
| 媒体缺失 | 确认页「N 张照片现在看不到」；预览不补图、不拿别条顶上 | 只收到类型/数量/缺失，无字节 | 不动 |
| 生成中 | 「正在本机整理。」可取消 | 进行中 | 不动 |
| 取消 | 回到确认页或书页。不留半份回眸 | 停止 | 不动 |
| 失败 | 「这次没有整理出来。原来的记录还在。」可再试或看原件 | 已失败 | 不动 |
| 部分覆盖 | 预览顶上写清「读了 N / 共 M 条有文字的记录」，禁止「这一年你的生活」 | 只看见送进去的 ID | 不动 |
| 预览（未保存） | 原文摘录 + 来源链接 +「保留这份回眸」/ 离开 / 再生成 | 已结束；尚无衍生物 | 不动 |
| 离开预览 | 回到书页或确认页。不留回眸 | 无 | 不动 |
| 已保留 | 才出现「删掉这份回眸」 | 无 | 不动 |
| 来源失效 / revision 变了 | 仅已保留份：来源标「后来改过」或「这条已经不在」。不改写原 Moment | 不自动重跑 | 不动 |
| 删除结果 | 只删已保留的衍生物。确认「只删这份整理，不删原来的记录」 | 无 | 不动 |

## 3. 输入、输出、校验

只读契约、候选输出和校验器见 [`CONTRACT.md`](./CONTRACT.md)。

要点：

- 模型请求按白名单**逐字段构造**，不是先投影整条再删除。键表与测试要求见 `CONTRACT.md` §2
- 每段必须带来源 Moment ID。**第一版只允许原文摘录 + 按来源排列**。自由归纳机器验不了真，不得宣称已自动验证
- 机器校验只拒绝它能证明的事（ID、范围、quote 非子串、第一版出现归纳种类、部分覆盖禁用词）。拼情节、改感受等人审错误见 `CONTRACT.md` §4.2 与 `SAMPLES.md`
- 机器通过 → 临时预览。未点「保留这份回眸」则无衍生物。未通过则整份丢弃。原记录不变

## 4. 记录很多时

端侧上下文有限。不得一次假装读完一个大年。

推荐默认（阶段 C 可按阶段 B 测得的窗口改数字，但规则不变）：

1. **先数范围。** 与书页同一落位：选月则 `exact`+`day`+`month`；选年则该年所有已落位记录（含 `year` 精度）。`unknown` 永不进年/月回眸。
2. **只把「有文字」的个人 Moment 做成模型行。** 只有媒体的行出现在确认页计数里，不进模型正文。
3. **单次上限 40 条有文字的记录**，按发生日新到旧。超出则分批；第一版默认只跑**第一批**，确认页写「将阅读最近 40 条有文字的记录，这个范围里一共有 180 条」。
4. **覆盖必须写进输出。** `analyzedIds` 是实际送入的 ID。预览和任何句子都只能谈论这些 ID。
5. **禁止全称。** 部分覆盖时不得出现「这一年你的生活」「整年」「你一直」。即使用户选的是年，也只能写「这次读到的这些记录」。
6. **不要把没输入的记录写进去。** 模型没看见的 ID，校验器按「未送入本批」拒绝。

用户若想覆盖另一部分，应再选更小的范围（某月），而不是让第一版在后台默默跑完全年。

## 5. 许可与以后的云端

许可全文见 [`CONSENT.md`](./CONSENT.md)。

确认动作必须同时说清：这是**本机分析**；本次使用哪些字段；预览还不会保存；只有再点「保留这份回眸」才留下一份可删除的结果；如何取消；删除回眸不等于删除原记录。

以后若增加云端处理，必须另写方案并重新取得明确授权，不能把本机许可静默当成云端许可。

## 6. 阶段边界

| 阶段 | 做什么 | 本 PR |
| --- | --- | --- |
| **A 设计与契约** | 本文 + 对照稿 + 样本 + 许可 | **只做这个** |
| **B 端侧探针** | 独立分支。小型 iOS 原生模块探测 Foundation Models：availability、中文 locale、上下文容量；**只用隔离合成文字**，不进入个人库。测结构化输出、耗时、取消、错误。Expo Development Build **真机**。不可用只回报状态，不转公用 API，不放密钥。接不上就写阻碍，不靠 mock 声称可行 | 不做 |
| **C 受控原型** | 独立分支。application 按所选范围读个人 Moment；白名单构造输入；第一版只摘录原文。机器校验通过后预览；用户主动保留才落盘。可取消/离开/再生成/删除已保留份。失败不影响最近、回看、原媒体 | 不做 |

- ADR 0001：Expo SDK 57 Development Build，不为此先升 SDK 58
- 模拟器 / Jest **不能**当作可用性结论

## 7. 风险

| 风险 | 为什么现在就要写清 |
| --- | --- |
| 产品指南与 Phase 0 把「AI」列为未经确认禁止 | 本 PR 就是确认材料。若复审否决，不进入 B/C |
| Foundation Models 在当前 Expo 57 / 设备上不可用 | B 必须用真机探测。不可用则停，不接云 |
| 校验器验不了自由归纳 | 「专名 + 子串」抓不住拼情节；有感受字段也证明不了「你很幸福」。第一版只做原文摘录，人审错误不得标机器 PASS |
| 书页计数与回眸范围不一致 | 必须复用同一落位规则，不能另算一套「这一年」 |
| 个人库被误送进模型或探针 | A 把输入面收死；B 禁止碰个人库；C 只读所选范围 |
| 用户以为回眸是生活本身 | 文案必须说「根据这些记录整理」，并点回原件 |
| 旧 revision | 预览保存的是生成时的 `id`+`revision`。原件后来改了要标明，不写回 Moment |

## 8. 待决定（阶段 A 停在这里）

1. **入口位置。** 推荐年章节与展开月各一条「生活回眸」。是否只要年、不要月，由复审定。
2. **「内容太少」阈值。** 推荐：0 条有文字 → 不调用。第一版有文字则只摘录原文，不因条数放开归纳。
3. **确认前能否排除单条。** 第一版推荐不能，以降低负担；若隐私复审要求可排除，再加。
4. **超限年是否允许用户改选「继续下一批」。** 第一版推荐不自动续跑，请用户改选某月。
5. **衍生物存哪。** 推荐独立 SQLite 表，不进 `moments` / `assets`。文件格式待 C。
6. **revision 变化后是否作废整份回眸。** 推荐仍可打开，来源行标「后来改过」，不自动重生成。
7. **阶段 B 设备门槛。** 哪台真机、哪个 iOS 版本算「可用」。未测之前不写 PASS。

家庭入口、身份验收、个人 Moment 语义不在待决定里——保持现状。
