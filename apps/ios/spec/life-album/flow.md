## 2. 必须出现的同屏状态

### 2.1 册列表

| 状态 | 用户看见 |
| --- | --- |
| 空 | 「把一些日子，放在一起。」「先收下一条，也可以慢慢添。」「新建一册」 |
| 有册 | 册名、条数、最近收入时间。点开管理。无封面图时用字封面 |
| 读失败 | 「生活册暂时读不出来，原来的记录还在。」重试。不假装空 |
| 新建 | 单栏册名，占位「一些日子」。保存后进回看收集模式 |

### 2.2 回看 · 普通

| 状态 | 用户看见 |
| --- | --- |
| 有记录 | 现网连续阅读。右上生活册。时间目录收起时只占切换行 |
| 空库 | 现网空文案。生活册图标仍在，可进空列表 |
| 时间目录展开 | **原位**展开在标题与正文之间，有高度上限。正文保持挂载、仍可阅读，不是旧式全屏覆盖层，也不把阅读树卸掉。见 §3 |
| 点生活册 | 有册 → 列表或上次打开的册；无册 → 空列表 |

### 2.3 回看 · 收集模式

| 状态 | 用户看见 |
| --- | --- |
| 进入 | 顶栏：「正在收进《册名》」。退出。阅读树、目录、分页、位置保留 |
| 未收 | 该条脚：「收进这一册」。低强调，48pt 触控，不挡正文 |
| 已收 | 「已收下」。再点撤回 |
| 收成功 | 立即保存。不切页、不重建播放器、不重置滚动 |
| 已在册中 | 同一册不再出现「收进」；显示「已收下」 |
| 退出 | 册仍在。回到普通回看，位置与播放继续 |
| 可预览 | 至少一条后出现「看看这一册」 |

### 2.4 普通模式收进（菜单）

| 状态 | 用户看见 |
| --- | --- |
| 打开菜单 | 「收进生活册」。详情不永久加大按钮 |
| 有多册 | 列出册名。已收入的册标注「已在这一册」，不可再收 |
| 无册 / 就地新建 | 名称栏，默认「一些日子」，收进并保存 |
| 取消 | 关菜单。阅读位置与播放不变 |

### 2.5 预览

| 状态 | 用户看见 |
| --- | --- |
| 生成中 | 「正在排成一册。」可离开。原记录不动 |
| 失败 | 「这一册暂时排不出来。收进的记录还在。」重试。保留已有分页若有 |
| 成功 | 封面到收尾整册。可前后翻页。声音只在真实可播时显示控件 |
| 缺媒体 | 该块可见「这张照片现在看不到」或「这段声音现在听不到」。不丢条、不补假图 |
| 来源已改 | 「这条后来改过。」仍按当前册顺序排；不改写 Moment |
| 来源已不在 | 「这条已经不在。」占位，不静默删页、不从隐藏副本复活 |
| 导出 | 阶段 D。阶段 A/B/C 预览里**没有**购买按钮或假价格 |

### 2.6 管理

| 动作 | 结果 |
| --- | --- |
| 改册名 | 只改册。Moment 不动 |
| 换封面 | 选已收入记录里的一张图，或改回字封面 |
| 开篇 | 可选短文，用户自己写。空则无开篇页 |
| 移出 | 只断册内引用 |
| 调序 | 只改册内顺序 |
| 删册 | 确认：「只删这一册，不删原来的记录。」已导出的本机文件按 [CONTRACT.md](./CONTRACT.md) 清理；App 外已分享文件无法撤回 |

## 3. 播放器与位置

收集、打开菜单、保存收入，都不得：

- 停掉无关的当前播放（除非该条被移出且正在播——推荐不停，因原件仍在）
- 重建 `useRecentClipPlayback` 会话
- 丢掉 `LookbackReadingSnapshot`

时间目录展开时（与现网留下规则对齐，不恢复覆盖层）：

| 仍可用 | 禁用 / 隐藏 |
| --- | --- |
| 时间目录本身（收起、选年/月/日/未确认） | 浮动「＋ 留下」 |
| 底带 最近／回看 | 右上生活册图标 |
| 已经在屏上的正文阅读（保持挂载） | 「收进这一册／已收下／看看这一册」 |
| 播放器会话（不重建） | 通过正文点进详情或打开溢出菜单 |

声音沿用现网目录规则，不是「继续播」：

- **打开目录**：先暂停，进度留在当前播放器里。
- **目录开着**：不重建 `useRecentClipPlayback`，也不在目录里提供另一套播放。
- **收起目录**：不自动续播。用户再点播放，才从留下的进度继续。

目录收起后，上述禁用项按普通或收集模式恢复。不得再引入挡住正文的覆盖层。
