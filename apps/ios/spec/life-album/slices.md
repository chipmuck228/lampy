本轮只做 A。不得自动开工 B–E，未批准阶段不增加生产入口或占位按钮。

| 阶段 | 做什么 | 本 PR |
| --- | --- | --- |
| **A 设计与完整样本** | 本文档 + 对照稿 + 由内容决定页数的静态册 | **只做这个** |
| **B 本机册子** | `LifeAlbum` 表、新建、收集、撤回、列表、管理、回看收集模式、详情菜单、设置入口。恢复阅读位置。不排版、不导出、不付费 | 不做 |
| **C 排版探测与预览** | 隔离夹具测字体、换行、图框、内存。写出真实 `AlbumLayout`。`/albums/:id/preview` 整册可翻。失败保留已收条目 | 不做 |
| **D PDF 导出** | 与预览同一 layout。临时文件、取消、失败清理、系统分享。导出说明（文件可能离开本机）。不承诺 PDF 内嵌声音 | 不做 |
| **E 付费** | 另审。真 StoreKit / 真权益。改「目前没有付费项目」。创建收集预览保持免费 | 不做 |

## 阶段 B 验收（供复审，不在本 PR 跑）

- 空列表三句原文
- 默认册名「一些日子」
- 同一册不能收重复 id；两册可以收同一 id
- 移出 / 删册后 Moment 仍在最近和回看
- 收集时滚动、分页、播放不重建
- 目录打开时生活册与收集按钮不可用；打开目录先暂停并留进度，收起不自动播，播放器不重建
- 无搜索
- 无假购买
- 隔离库，不写 Liuz17

## 阶段 C 验收

- 夹具按内容分页，覆盖 SAMPLES 种类；不设最低页数
- 预览与 PDF 使用同一份带框、`textRange`、字体和指纹的 layout JSON
- `textRange` 须由真实字体测量得出，不等于逐行断点。阶段 C 用隔离夹具对照预览画布与 PDF 画稿，证明同页、同框、同切片；量不出来或两份不一致，不得标同版 PASS
- 缺媒体、未确认、同日、跨月按契约；正文顺序为文字 → 图 → 声
- 静态 HTML 样本不得标 C 的 PASS

## 阶段 D 验收

- 同一 layout 出 PDF
- 取消/失败无残片
- 导出后改 Moment，旧 PDF 内容不变
- 说明「无法从 App 外撤回」
