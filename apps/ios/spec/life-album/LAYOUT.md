# 生活册 · 自动排版

有限版式 + 真实尺寸测量 + 分页规则。不依赖 AI。不做万能排版引擎。

---

## 1. 管道

```text
原 Moment / Asset
  → 排版输入（按册顺序、白名单字段）
  → 选块版式（四种正文 + 封面/开篇/收尾）
  → 按真实字框与图框测量
  → 装进固定页
  → AlbumLayout
  → 预览与 PDF 共用
```

输入只取：`id`、`revision`、`note`、`feeling`、`occurredAt` / `precision`、`recordedAt`、每个 Asset 的 `id` / 类型 / 宽高比 / 时长 / 是否可读。不取路径字符串进 layout 文本，不取家庭字段。

---

## 2. 第一版页面尺寸

只约束一种页：

| | 值 |
| --- | --- |
| 名称 | `album-a5-v2`（页尺寸仍为 A5；v2 起字体解析与缓存指纹随实测字体更新） |
| 页 | 竖向 420 × 595 pt（A5 72 dpi） |
| 边距 | 上 40、下 44、左右 36 |
| 版心 | 348 × 511 pt |
| 纸 | `#F3F0E9` |
| 墨 | `#25231F` |
| 软墨 | `#5C5851` |
| 辅助 | sage `#53604F`，感受色点沿用词表，不新增彩条 |

屏幕预览按同一比例缩放，不另排一版「手机专用页」。

字阶（册内，不改全局）：

| 用途 | 大小 / 行高 |
| --- | --- |
| 封面册名 | 28 / 36 |
| 开篇、正文 | 17 / 32 |
| 日期 | 15 / 22，sage |
| 脚注、声音、缺媒体 | 15 / 22，inkSoft |

中文按字盒换行。禁止为了塞进本页而缩小字号或压缩行距。

## 3. 六种协调版式

| 代号 | 用在 | 规则 |
| --- | --- | --- |
| **Cover** | 第 1 页 | 字封面：册名居中偏上。图封面：一张已选图，**原比例**完整落入上半，下面册名。不裁切成方块。无图不画假风景 |
| **Opening** | 可选第 2 页 | 用户开篇全文。超过一页则续页，不截断。无开篇则跳过 |
| **DayText** | 短句、长文 | 该日第一次出现时印日期。短句可与同日其他短记录同页，记录之间留 16pt 并有浅分隔，不合成一段。长文全文，自然跨页，**不截六行**。跨页顶上可印浅色日期 +「续」 |
| **Pictures** | 1–3 图 | **只保留记录内原顺序**，不按横竖或面积重排。每张原比例。单图：宽度吃满版心，高度随比例；过高则本页结束，下一页独放。多图：按原序依次往下排，装不下的整张下页。第一版只改尺寸与分页，不换左右、不「大图在上」。照片优先版式第一版不做，要做须另写规则 |
| **Sound** | 一段声音 | 日期（若本日未印）、时长、可播时才有播放位置。无真实播放能力时只印「一段声音 · 时长」，**不画假波形进度**。无原件：占位说明 |
| **Close** | 末页 | 「这些日子，先放到这里。」无统计、无情绪总结。缺页不补广告 |

块在记录内顺序：日期（若需要）→ 文字 → 图（逐张）→ 声音 → 未知媒体 → 感受（原词 + 色点）→ 「记录于」若发生时间未确认。

## 4. 分页硬规则

1. **无遗漏、无重复、无截字。** 收入的每条、每张图、每段声、每个未知媒介在**正文**里各有一块。同一 `assetId` 在正文只出现一次。**封面可以复用册内已有照片**：封面是封面页的展示，不算第二次正文收入，也不另收一条。移出该条则封面回字封面。
2. **不缩字硬塞。** 装不下就下页。
3. **孤立标题。** 日期行后面若只剩不到两行正文，日期跟正文一起翻页。
4. **断段。** 长文按段落优先；段内按行。不在行中切半个字。跨页不重复已排句子。
5. **照片与说明相邻。** 该条若有文字，至少一行文字与第一张图在同一页；做不到则图在次页，文字页脚不写「见图」之外的新故事句。
6. **同日多条。** 日期只突出一次。后条不再印大日期，可用 1px 浅线分开。
7. **跨月。** 新月第一条当新的日期突出，不插入「十月」章名或自动散文。
8. **未确认时间。** 不补造发生日。按 `recordedAt` 排在用户指定顺序里的位置（默认：发生日可知的按发生日，`unknown` 保持用户收集顺序，不插入假日历）。印「记录于 YYYY年M月D日」。
9. **空白。** 一页内容低于版心 35% 且下一条是短句、同日，可共页。下一条是大图或新日则不必硬填。禁止为填空白生成句子。
10. **感受。** 只显示原词与小色点。无感受则无行。未知旧值原样，不改近义词。

---

## 5. 测量

阶段 C 用与渲染相同的字体、行高、可用宽度测文本高度；用 Asset 宽高比测图框。禁止用「每行 20 字 × 行数」估算当最终分页。

预览滚动或翻页只是窗子；页边界以 `AlbumLayout.pages` 为准。

---

## 6. 缺失与未知

| 情况 | 版面 |
| --- | --- |
| 图 missing | 与原图同宽的浅框 + 「这张照片现在看不到。」 |
| 声 missing | 「这段声音现在听不到。」保留时长若仍知道 |
| 未知媒介 | 现网 `MomentUnknownMedia` 同类说明，不丢弃 |
| Moment 找不到 | 整条一块：「这条已经不在。」 |
| revision 已变 | 正常排当前内容，条末可标「后来改过」 |

---

## 7. 不要做的排版

自动标题、自动摘要、情绪折线、纪念馆封面、仿真翻书、贴纸、用户自选十几套模板、把同日多条改写成一篇。
