## 1. 产品契约

用户轻松留下。用户决定哪些片段放在一起。Lampy 负责认真编排，**不替用户定义生活**。

| 名称 | 用语 |
| --- | --- |
| 功能 | 生活册 |
| 创建 | 新建一册 / 做成一册 |
| 收集 | 收进生活册 / 收进这一册 |
| 预览 | 看看这一册 |

不要求分类、标签、AI 摘要、模板选择或逐页编辑。同一记录可以收入不同册；同一册不得重复同一 `momentId`。移出或删除册子**不删除**原 Moment。

创建、收集、完整预览免费。完整成品导出拟收费。基础数据备份与付费导出分开。阶段 A **不实现支付**，不展示假价格或可点击的假购买按钮。

不要：打卡、评分、自动故事标题、情绪报告、翻书动画、推荐、「为你精选」、把多条拼成一个故事。

## 3. 空状态与主流程

空库文案：

- 把一些日子，放在一起。
- 先收下一条，也可以慢慢添。
- 新建一册

```text
新建一册（只填册名，默认「一些日子」）
  → 进入回看收集模式（顶栏：正在收进「册名」+ 退出）
  → 沿用目录 / 连续阅读 / 分页 / 位置 / 播放器
  → 每条低强调「收进这一册」→「已收下」（可撤回）
  → 立即落盘。退出收集 ≠ 放弃整册
  → 收一条即可「看看这一册」
普通模式从菜单收进
  → 选择已有册，或就地新建
  → 回到原阅读位置，不重建播放器
```

不设完成百分比或最低条数。搜索若不存在，本轮与后续第一版都不新增搜索或语义识别。

## 4. 成册视觉（一套版式）

竖向纸页、暖白底、墨色、舒展行距、克制辅助色。沿用已确认 Lampy 视觉。生活册专用排版**不得**改全局 `life-text` 字阶。

结构：封面 → 可选开篇 → 正文 → 安静收尾。无图可用纯文字封面。不自动写标题、故事、总结或情绪报告。

编辑仅：改册名、换封面、可选开篇、移出记录、调整记录顺序。不做逐页拖动、字体菜单、边框和贴纸。

细则见 [LAYOUT.md](./LAYOUT.md)。完整纸页见 [sample/index.html](./sample/index.html)。
