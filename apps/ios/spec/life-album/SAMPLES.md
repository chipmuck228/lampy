# 生活册 · 合成夹具

全部正文为评估编写。**不是**真实用户记录，也没有真人私人媒体。阶段 B–D 只许用这类夹具，禁止把 `lampy.db`、Liuz17 或相册导入评估。

册名在产品里默认是「一些日子」。本夹具册名为 **示例册 · 窗边**，避免被当成某人的生活。

ID 使用 `moment_album_eval_*`。图像是本目录原创几何稿，来源见 [sample/media/SOURCE.md](./sample/media/SOURCE.md)。声音无原件，一律标占位。

### m03 长文（合成）

> 这是一条合成长文，只用来看跨页，不是谁的日记。下午坐在桌边，把一盏灯拧到刚够写字。窗外没有要拍下来的事，于是写下这一段。第一页应该在句子中间自然断开，第二页接着读，不要出现省略号，也不要改成「六行预览」。写到这里仍然只是纸上的练习：两张几何图和一段未附原件的声音会跟在后面，顺序与记录里一致。

约 180 字，加上两图和声音后应占 2–3 页。

## 3. 人审检查（整册，不只封面）

- [ ] 能从封面翻到收尾，中间没有跳页空白故事
- [ ] 9月3日日期只出现一次
- [ ] 9月12日长文无截断、无「还有正文」
- [ ] 两图原比例，未裁成统一方块
- [ ] 声音无假波形
- [ ] 10月相对 9 月没有自动章名
- [ ] 未确认条没有编造发生日
- [ ] 缺失图可见，且 m09 整条还在
- [ ] 感受只有原词和色点
- [ ] 页脚或封面标明「合成夹具，不是用户生活」
