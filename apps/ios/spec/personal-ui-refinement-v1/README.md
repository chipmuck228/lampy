# 个人 MVP 体验精修 v1

独立分支 `ios/personal-ui-refinement-v1`，基线 `origin/main`（含 #46 `6e25227`）。只改 `apps/ios`。家庭入口关闭。`identityLoopAccepted` 保持 false。不推进 AI 回眸。不改 Moment、发生时间精度、个人保存、草稿恢复、媒体保全、播放状态机、Face ID 保护语义。

Lampy 是轻盈、私密、精致的生活记录。原话、照片和声音是主体。沿用暖纸 / 墨 / 克制青与阅读宽度。用字号、间距、对齐和细分隔分层，不给记录套卡片，不加统计面板或装饰动画。

## 图标

只用来源 `expo-symbols`（SF Symbols），经 `LifeIcon` / `LifeIconButton` / `LifeLabeledHit`。不混 emoji、Unicode 拼凑符号或其他图标库。

| 用法 | 形式 |
| --- | --- |
| 本机设置、展开/收起、看这条箭头、播放/暂停/再听 | 图标；关键处保留短文字 |
| 拍摄、照片、录音 | 图标 + 短标签 |
| 留下、失败重试、放弃草稿 | 只保留明确文字 |

图标按钮有 `accessibilityLabel`。装饰图标 `accessible={false}`，不重复朗读。触达 ≥ 48pt。不缩小系统字体。不靠藏信息制造简洁。

## 页面

**最近**  
阅读顺序不变：文字/照片/占位 → 声音 → 感受 → 看这条。同日短浅线保留。日期标题简洁；发生日与记录日同一天时不在条目上重复「发生于」。播放沿用现有状态与进度，符号改为统一 SF Symbol。看这条低强调、箭头与文字居中；播放与打开触达分开。顶端「本机与账户」改为设置图标，`accessibilityLabel`「本机设置」，大字号下不挤压标题。底带只统一视觉，不改路由或宽度降级。

**回看**  
保留 C′ 年/月/日展开、摘录上限、精确 ID、「还有 N 条」、定位滚动、返回位置、声音暂停。年份章节、月份主标题「9月」+ 次要「14条」+ 独立展开符。VoiceOver：`2026年9月，有14条记录，已收起/已展开`。日期行：日期+星期主，数量次。短摘录与「看这条」收紧，同日两条用底部分隔。三类未确认时间入口不合并。不增月历、筛选、统计或新浏览模式。

**留下**  
拍摄 / 照片 / 录音统一图标+短标签。正文仍是一页内容，媒体可辨认可移除。感受与发生日期未选时收成入口，展开后仍能改选、清除。「留下」是唯一主动作；放弃草稿低强调但可发现。恢复说明改为「上次没保存的内容已放回来。」保存/失败原因仍在固定操作栏附近。最大字号下按实际宽度把「留下」换到下一行，拍摄／照片保持一行，不裁切。

**本机设置**  
路由仍是 `/account`。用户页：本机保护 Switch + 已开启/未开启 + 一句说明；「个人记录保存在这台设备」（并写明目前没有跨设备同步或云备份）；末尾低强调版本。家庭 API、测试账号、授权说明只在独立页 `/account-diagnostics`，且路由用同一开关把门：关闭时不展示诊断内容、不发诊断请求。本机设置默认只有保护、存储说明和版本；开关打开时页尾有「开发诊断」入口。不清除 Keychain，不重写账户逻辑。保护失败文案保留。

## Dynamic Type

系统字号改完回到 Lampy 时，原生 `Text` 会立刻变大/变小，JS 里的 `fontScale` 有时还停在旧值。阅读页用 `usePageMetrics` 在窗口变化和重新进入前台时重读。窗口和 `PixelRatio` 先记下已确认的字号；只有一侧变成新值、另一侧仍是确认值时才采纳。两侧暂时不一致时，80ms / 400ms 重读保持已确认的新值，不把仍停在旧值的窗口当成又一次变化。底带按标签实际画出的宽度选一行 / 2×2 / 整列。留下页在字号变化时只重测输入框、图标行和感受/日期行，不重建整页，以免丢掉草稿和录音。竖屏最大字号下三项整列是让得开，不是回归。标题、感受和锁定遮罩（「这台设备已保护」）不再写死小于放大后字形的 `lineHeight`。

保护开启后，未解锁时 `inactive` 先遮挡并挡住系统快照；真正进后台才作废上一轮认证。Face ID 引起的 `inactive` 不揭开。只有这一轮在前台的成功认证才显示私人内容。已经解开后，系统认证收起带来的 `inactive` 不再重新上锁，也不把原生防截屏黑层留在活窗口上；切换器仍用纸色遮挡盖住上一帧。设置提交和解锁资格仍然分开。

留下操作栏里，相机/相册/麦克风拒绝只留短状态，完整说明进「查看说明」。保存失败仍写在栏里并可以再试。

## 为何还留这些文字

- **留下 / 确认放弃 / 再试一次**：误触代价高，图标不够。
- **拍摄、照片、录音**：三种媒体进路，短标签避免认错。
- **放弃这份草稿**：低强调但不能藏。
- **恢复说明、保存失败、本机保护状态**：不藏状态与原因。
- **看这条**：打开详情不是通用「前进」，保留两字。
- **播放 / 暂停 / 再听一次**：状态变化需要词，不只靠图标。
