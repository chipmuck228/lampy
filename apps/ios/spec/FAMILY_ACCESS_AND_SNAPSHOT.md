# 家庭读取权限与快照

日期：2026-09-25。权限无法确认 → 最小授权（不展示家庭内容）。个人库可离线。本机缓存 **不是** 当前授权证明。

---

## 1. 矩阵（已决定）

| 状态 | 本人个人原 Moment | 现成员读该分享（加入后产生） | 现成员读他人未分享个人记录 | 前成员读家庭内容 / 接收快照 | 外人 |
| --- | --- | --- | --- | --- | --- |
| 未登录 | 是（本机个人库） | 否 | 否 | 否 | 否 |
| 已登录、无家庭 | 是 | 否 | 否 | 否 | 否 |
| 分享前 | 是 | 否 | 否 | 否 | 否 |
| 分享成功且双方当时均为成员；读者在分享**之后**加入 | 是 | **否**（加入前分享默认不可见） | 否 | 否 | 否 |
| 分享成功；读者在分享时已是成员 | 是 | 是（服务端仍确认资格） | 否 | 否 | 否 |
| 退出 / 被移除 / 解散 / 撤回该分享 | 是（原件） | 否 | 否 | **否**（App 清理家庭缓存） | 否 |
| 离线或权限无法确认 | 是 | **不展示** | 否 | **不展示** | 否 |

创建者与成员在「读他人未分享个人记录」上同为否。

---

## 2. 接收快照（规则已定，能力未交付）

**何时形成（后续切片）：** 用户确认可见字段后，服务端保存该 `revision` 的快照包（媒体为服务端对象，不是设备路径）。接收设备在 Membership 仍有效时下载并写入**家庭缓存**。

**包含（首版）：** `note` / `emotion` / 已选媒体的服务端引用 / 时间与精度 / `origin`（received 三件套）/ `familyId` 与访问范围。  
**不包含：** `context.people`；整个 Moment JSON 默认全量；`localUri`。

**原件之后的编辑：** 不改已保存 revision。要更新只能新一次分享。

**落入本地之后：** 仍是家庭授权对象。禁止 upsert 进个人 `moments` 当 `origin.created` 使用。退出/移除/撤回/解散/无法确认授权后：App 删除或隔离该缓存，界面不展示。不承诺收回导出文件。

**本轮：** 不实现形成、上传、下载、展示。

---

## 3. 保全

| 情况 | 必须 | 禁止 |
| --- | --- | --- |
| 未登录 / 令牌无效 | 个人库不变 | 展示成员或家庭 |
| 服务端不可达 | 个人库可用；家庭为未确认 | 用上次成员列表当现成员 |
| 邀请过期/撤销/重复接受 | 明确错误；不建第二条 Membership | 当成已加入 |
| 已有家庭时再创建/再接受 | 拒绝 | 静默换家庭 |
| 非创建者邀请/移除/解散 | 拒绝 | 部分成功 |
| 创建者直接退出 | 拒绝 | 留下无创建者的家庭 |
| 重试 | 幂等键同一结果 | 重复家庭或重复邀请 |
