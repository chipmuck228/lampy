分享确认区在用户选好目标后显示「以 昵称 的身份，分享给『家庭』」。缺少昵称显示「当前账号」。资料读取失败不产生可确认预览；资料返回的 userId 必须匹配准备请求的账号。切账号、失焦或锁定后迟到资料不进入预览；确认仍使用原有账号 / 会话 / 目标 / 原记录资格核对。旧客户端没有资料读取能力时保留无昵称兼容。

昵称只描述身份；相同昵称的作者仍按 authorUserId 区分。撤回只允许真实作者；家庭权限、历史受众、原文、媒体上传和本机保护不变。服务端仅对已授权的有效分享读取作者资料，不新增全局资料查询，不返回邮箱或密码。

不增加数据库迁移或原生依赖；家庭、受控注册与诊断默认关闭。未实现付费、公网部署、账号删除、邮箱验证、正式注册或 TestFlight。
