# Revisit：记录日历

基线 main df04627（#119），独立 UI 切片，无数据库迁移、云端部署、新原生模块或付费开关。

回看右上角「慢慢看 / Take your time」现在是按钮，打开当前回看页内的弹层，不进行路由跳转。日历沿用现有纸色、字体和 LookbackMonthCalendar：有明确日期的格子显示当天记录条数，空白日仅显示日期、不响应点击。默认打开当前阅读月份（仍有记录时），否则打开最近有记录的月份。左右按钮在有记录的月份间移动，点击月份标题可直接跨年选月。日期和条数上下排列，辅助功能朗读仍包含完整日期和记录数量。

点击有记录日期，收起弹层并直接更新原回看阅读区，沿用 getHistoryDay 的全部记录及后续分页，而不是仅展示摘要或第一条。原页面的收进册子上下文保留；进入日历时暂停原声音。点击日历外的空白、关闭按钮或系统返回可收起弹层，不改变阅读日期。重新进入页面会刷新日期数据，读取失败提供重试，切换月份忽略迟到结果，后台和本机锁定隐藏日期并作废在途读取。

日历遵循既有 occurredAt 和发生时间精度语义：不会拿 recordedAt/createdAt 补造日期，也不将仅知年/月或未知日期的记录塞入某一天。这些记录仍在原时间目录中；日历提示其保留位置。只查询个人本地历史，不包含家庭云端记录。

| 项目 | 操作与通过标准 |
| --- | --- |
| 中英文入口 | 回看 / Revisit 右上角「慢慢看 / Take your time」可点，打开日历弹层，无页面跳转 |
| 日期标记 | 至少跨两个月、两年准备记录；每个有记录的日期下显示正确条数，不再使用圆点；未记录日期不可点 |
| 月份选择 | 前后切月、点击月份标题跨年选择，标记不串月，边界按钮不可点 |
| 当天全部记录 | 同一天多条文字/照片/声音；点击日期后返回该日阅读，全部记录可读，超过 50 条可继续加载 |
| 返回与取消 | 点击外部空白、关闭按钮或系统返回收起弹层且不改变日期；阅读日期后再次打开日历，显示对应月份 |
| 日期精度 | 只有年/月、未知日期的记录不被放到虚构日期，原时间目录中仍可读 |
| 变更与失败 | 新增/删除/改日期后重开日历，标记更新；加载失败显示重试，不伪装为空库 |
| 声音与保护 | 进入日历暂停旧声音；切后台/锁定遮挡日期，回来正常恢复，不自动播放 |
| 屏幕与字号 | iPhone 横竖屏、系统大字号下月历可用，无截断或无法返回 |
| 免费和离线 | 不弹购买、不出现正式导出；本地记录日历离线可用 |
