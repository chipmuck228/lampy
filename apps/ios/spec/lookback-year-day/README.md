# 回看年页与日页

> 范围：只改 `apps/ios` 回看**年**页和**日**页的展示层。月页（#24）、详情、家庭、留下、最近不在本轮。
> 依据：`LAMPY_APP_PRODUCT_DESIGN_GUIDE.md` §4.2、§4.4、§4.5、§10.4 年/日、§12、§13。
> 基线：`origin/main` @ `a41140f`（含 #22 / #23 / #24）。独立分支，不叠 #24 的旧 head。

对照页：`storyboard.html`。不用连续天数、完成率、红色空缺或打卡热力图。

## 改前年页

十二个月等权按钮。有记录的月份画按当月最大值拉长的密度带；安静月份同样可点，只是文案为「安静」。

问题：

1. 空月份与有记录月份一样重，像待完成格子。
2. 密度带随条数变长，接近热力图。
3. 超大字号下仍横向挤十二个等权项。
4. 与 #24 月页（安静不可点、可读列表、克制圆点）节奏不一致。

## 改后年页

| 规则 | 做法 |
| --- | --- |
| 年位置 | 1…12 月按真实月份排成三列四行。空位不是缺口。 |
| 安静月份 | 低强调「1月」，不可点，不进空月页。 |
| 有记录 | 墨色月份 + 与月页相同的克制圆点。点进原月页。 |
| 可读入口 | 下方「有记录的月份」列出 `1月 · 有2条记录`。 |
| 整年为空 | 十二个安静月 + 「这一年还没有留下什么。」 |
| 月份未确认 | 保留原入口，不放进某一月的格子。 |
| 最大字号 | `fontScale >= 1.3` 不画三列，只留纵向列表。 |
| 窄内容宽 | 用与月页相同的内容宽。三列每格不到 44×44pt 时不画格。 |

## 改前日页

每条 Moment 都是同一张 `HistoryMomentRow`：重复整段日期、再堆文字/图/声/感受。日期精度也带一份完整日期。空日说明已中性，但条目没有层次。

## 改后日页

| 规则 | 做法 |
| --- | --- |
| 共享日期 | 页标题是这一天。条目不再重复「2026年9月24日」。 |
| 精确时刻 | `occurredAtPrecision=exact` 才写 `08:15`。 |
| 日期精度 | 只有 day 时不写时刻，也不用 recordedAt 冒充。 |
| 内容层次 | 文字是正文；照片保留原比例（#23）；声音、未知 Asset、感受跟在内容后。不是等高卡片。 |
| 进入详情 | 整条仍进精确 ID。长文、三图、缺失媒体可滚完。 |
| 无记录 | 「这一天还没有留下什么。」不催每天留下。 |

不改：`occurredAt` 精度、个人 Moment、媒体保存、年/月/日/详情路由、回看滚动恢复、#24 月历。

## 状态对照

| 状态 | 真数据含义 | 年页 | 日页 |
| --- | --- | --- | --- |
| 稀疏年 | 一两月有留下 | 对应月有点；列表那一两行 | — |
| 密集年 | 多月有留下 | 多月同权圆点；每月一行 | — |
| 整年无记录 | 12 月都安静且无 year 精度 | 全安静 + 中性空说明 | — |
| 月份未确认 | `occurredAtPrecision=year` | 不占月格；原入口 | — |
| 整月无记录 | 日页由月历安静日不可达；若直达 | — | 中性空说明 |
| 同日多条 | 一天 2+ 条 | — | 共享标题，各条按内容展开 |
| 精确 + 日期 | exact 与 day 混排 | — | 只有 exact 显示时刻 |
| 三张照片 / 缺失 / 长文 | 已有媒体与长 note | — | 完整滚动，进原 ID |
| 最大字号 | Dynamic Type 超大 | 不画三列 | 条目纵向可滚到末尾 |
| 窄内容宽 | 三列不足 44pt | 只留列表 | 单栏 |
| 横屏 / iPad | 短高或常规宽 | 按内容宽，不按机型 | 阅读柱内，不拉满屏 |
