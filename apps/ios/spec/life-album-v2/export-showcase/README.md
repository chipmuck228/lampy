# 导出成品展台（export showcase）

基线：main `142a399`。独立分支 `ios/album-export-showcase`。只改个人册「导出这一册」页面的呈现与生成过程的反馈；PDF 内容、排版规则、付费门控、家庭导出、默认关闭的开关全部不变。

## 为什么改

原导出页是一列验收用文字：「生成PDF」、字体嵌入、字形运行名、DPI。用户付款前看不到自己会得到什么，付款后也只看到一行文件信息。购买意愿来自「看见自己的日子变成一本书」，而这本书在应用里本来就有：纸页预览用的是同一份 Core Text 分页。

## 现在的页面

1. **成品展台**：用这一册当前的真实分页，在原生纸页视图里画成一本 A5 小册。合着出场，封面过一道光，随后自动翻开到第一个跨页。左右拖动或轻点左右半边翻页；上一页／下一页按钮与 VoiceOver 上下轻扫同样可用。书页、书脊阴影、纸边厚度、桌面投影都只是呈现，不改动任何一块的位置、字形或图片比例。
2. **这一册的真实数字**：页数、记录数、照片数、声音数、时间跨度，全部从分页结果读出，不估算、不补写。
3. **素纸／手作**：整册即时换纸，与连续阅读共用同一偏好（写回 `saveAlbumReadingState`，保留原阅读位置）。
4. **这份文件会是什么**：精确 A5、原比例不裁切、文字可选可搜、每次导出独立成版、声音留标记与时长。只写已有实现与已有规格承诺的事。
5. **一个主按钮**：未购买时为 StoreKit 本地化价格「解锁导出 · ¥…」；已购为「装订成册」。购买、生成、分享仍是三个独立动作：购买成功只把按钮变成「装订成册」，不自动生成。
6. **装订过程**：书合上，光从封面掠过；进度条与文字来自导出服务真实上报的步骤（核对权益→读取→备纸与字体→收好照片与声音 n/N→逐页排版→印成PDF→逐页复核→装订成册），不是计时动画。取消立即收起。
7. **完成**：触感反馈，书轻轻落下；卡片显示「第N版 · 页数 · 大小」和「保存或打印PDF」，并附导出离开 Lampy 后无法收回的说明。
8. **已装订的版本**：书架式列出各版。正式模式不再显示字体运行名等验收细节；低于 300DPI 的提醒保留。开发打印验收模式仍显示全部诊断。

本机保护锁定或进入后台时，整页（书、数字、价格）都不渲染，与原页面一致。分页里有读不到的记录或媒体时，按钮禁用并提示先核对，避免必然失败的一次生成。

## 改动范围

- `album-print.ts`：导出服务新增可选 `progress` 回调，只在请求仍有效时上报；回调抛错不影响成品。诊断阶段名不变。
- `album-export-showcase.ts`：纯函数（数字、跨度、跨页／书叶编号、进度比例与文案、版次、失败归类）。
- `album-export-book.tsx`：翻页书。只有正在翻的那一叶带透视变换；静止页面的外层变换恒为 1，按当前静止尺寸绘制（合上为封面尺寸，翻开为跨页尺寸）。实测在外层缩放或透视下 Core Animation 会粗糙合成页面位图，因此不用「整本书缩放」。
- `album-export-showcase.tsx` / `album-print-screen.tsx`：页面组合；原有的锁定、后台、代次、取消、迟到结果保护全部保留。
- `album-export-unlock.tsx`：抽出 `useAlbumExportUnlock`，家庭购买面板继续用原组件，文案不变。
- 原生 `AlbumPageView` 新增可选 `renderScale`：按显示尺寸设置 `contentScaleFactor`。不传时行为与原来相同（纸页预览、PDF 写入不受影响）。**需要 prebuild／pod install 并重编原生**。

## 开发演示（不需要 StoreKit、不读个人库）

开发构建中打开：

```
lampy://dev/export-showcase
lampy://dev/export-showcase?state=owned          # 已解锁
lampy://dev/export-showcase?state=binding        # 装订过程
lampy://dev/export-showcase?state=bound          # 装订完成
lampy://dev/export-showcase?style=handmade
lampy://dev/export-showcase?pos=1.3              # 定格翻页中间态
lampy://dev/export-showcase?scroll=700           # 截图用
```

使用 `spec/life-album-v2/sample` 同源的合成记录与首次引导照片，经真实 Core Text 分页。价格与装订步骤为模拟，不购买、不写文件。Release 构建中该路由直接回首页。

截图（iPhone 17 Pro 模拟器，iOS 26，中文）见 `shots/`。

## 验证

- Mac 本机 Xcode 26.5 原生构建并在 iPhone 17 Pro 模拟器运行演示页与正式导出路由；截图逐张核对：封面、翻页前后半程、展开跨页、价格、已解锁、装订中、完成、手作纸。
- TypeScript、改动文件 ESLint 无错误。相关 Jest：展台纯函数 8、导出服务（含进度上报 3 条新增）23、导出页 11、解锁组件、家庭购买面板、家庭打印页，共 51 条通过。全量 Jest 270 套件中 5 个失败，与 main 相同的 5 个（i18n 占位符、导航带标签等既有问题），本分支未新增失败。

## 尚未验证

- **真机**：翻页手势（横向拖动与外层竖向滚动的分工）、触感、真实大册（数十页、多张大图）的内存与首帧时间。模拟器无法注入触摸，拖动翻页只在代码层面实现，未实际拖过。
- **真实个人册 + 真实 StoreKit**：本轮在模拟器中没有建真实记录与生活册，正式页面只验证了「册不存在、商品未配置」时的安静退化；带真实册的展台与装订由 Jest 覆盖，未在原生跑完一次真实 PDF。
- 翻动中的那一页在 0.6 秒动作中略有颗粒感（透视合成）；静止页面清晰。
- 大册内存：同时挂载最多约 8 个页面视图，每个按显示尺寸绘制（像素数约为原来的 1/3 或更少）。原生绘制每次仍从文件解码整张照片，未做缩略解码。
