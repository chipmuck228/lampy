## 0. 审阅摘要与决定状态

### 0.1 已明确的产品方向

1. 用户容易记录，用户决定哪些片段值得放在一起，Lampy 负责认真呈现过往生活。
2. 生活册包含真实的文字、照片、声音与已有感受；不由 AI 补标题、摘要、照片说明或意义。
3. 手机等竖屏设备默认连续纵向阅读，避免为了纸页版式频繁翻页。
4. 连续阅读与打印版必须使用相同内容和同一套视觉规格；分页、换行和必要的媒介交互可以不同。
5. 主收藏格式优先采用包含媒体的离线生活册文件包，由 Lampy 阅读器阅读；不依赖长期音频托管。
6. 打印版独立完成可靠分页、断页与图文编排。
7. 家庭册由当前家庭创建者执行导出；创建者付费、成员和接收者阅读的方案作为商业方向，真实付费尚未实现。
8. 创建者承担妥善保护家人隐私的责任。导出后的文件和纸书不能承诺远程收回。
9. 创建者保存已生成成品；接收者从外部文件直接进入只读 Lampy 阅读器，不加入自己的生活册、不自动建立收藏、不永久保存副本。
10. 所有已生成成品（包括创建者自己的成品）使用同一个阅读器；第一版阅读器是 Lampy App 内的阅读模式，不另做独立 App。
11. 生活册首页统一入口，按「我的／家里的」分区呈现工作册；制作流程共用，来源与角色资格分别处理。
12. 新册按册内顺序取第一张有效照片作为自动封面，无照片用文字封面；不要求用户选封面，已有手选封面不被升级覆盖。
13. 家庭成册不设逐条许可。家庭分享规则一次说明后，创建者可选取或收入当前全部有效分享；不增加创建Moment时的导出选项、许可修改入口或审批流程。分享者继续使用现有撤回分享。
14. 核心原则：轻松留下，安静回看，简单成册。增加功能应减少选择、步骤和管理负担。

## 1. 产品定位

**生活册是一份可以慢慢读、认真收藏、交给重要的人的生活。**

用户负责决定哪些片段放在一起；Lampy 负责字体、照片比例、图文关系、留白、阅读节奏和打印分页。成品要认得出用户留下的原样，不让自动排版变成自动改写。

日常流程不要求用户先分类、打标签、选完全部记录或逐页排版。一册可以只收下一条，也可以以后继续添加。

### 1.1 核心用语

| 概念 | 用户用语 |
| --- | --- |
| 功能 | 生活册 |
| 创建 | 新建一册 |
| 收集 | 收进这一册／已收下 |
| 阅读 | 看看这一册 |
| 打印检查 | 看纸页 |
| 成品 | 导出这一册 |
| 打开成品 | 外部菜单「用 Lampy 打开」→直接阅读；App 内不增加导入按钮 |
| 工作册来源标识 | 本机／家庭（仅必要位置低强调显示） |

中文与英文界面同时设计。册名、开篇、原文、昵称不得跟随界面语言自动翻译。英文具体文案与样本在设计阶段单独校对。

### 1.2 不纳入第一版

AI 标题和摘要、自动情绪判断、自动照片说明、自动故事、复杂标签分类、社交推荐、网页托管册、纸质书在线扫码音频、实体印刷下单、装订服务、共同编辑、逐页拖拽装修、十几套模板、仿真翻书动画。

## 3. 工作册与成品：两种状态，不增加导入册分类

### 3.1 个人自建册

来源为用户本机个人记录。收集时保留引用，改册名、开篇、顺序、移出条目或删除册子不删除原 Moment 或媒体。新册使用自动封面，保留已有手选封面。

工作册读取当前有效来源；导出时生成独立冻结快照并复制所需媒体。来源缺失或发生变化时，按第 12 节处理，不暗中复活私密原件。

### 3.2 家庭工作册

来源为该家庭当前仍有效的分享快照，而非访问另一个成员的个人库。第一版建议由创建者创建、收集、排序与编写开篇，使用自动封面，成员阅读；共同编辑范围仍按R8待审。共享开篇不能代替或改写成员原文。

家庭成册遵循共同分享约定，不增加逐条许可。创建者可逐条收下，也可一次收入当前全部有效分享；后续新分享不会在用户不知情时自动加入既有册子。

条目身份必须包含来源类型、家庭 ID、分享 ID 和分享版本，不得把其他成员的个人 Moment ID 当作本机可读取对象。使用真实分享者信息；不为了版式补邮箱或电话号码。

创建者可以同时是其他家庭的成员。家庭之间不得混收；希望跨家庭组合的需求另行设计。

### 3.3 已生成成品：按次打开阅读

成品是冻结文件，不是第三种首页册子。创建者自己保存，接收者从微信、邮件或系统文件中使用「用 Lampy 打开」，直接进入只读阅读器。创建者打开自己的成品也走同一路径，不混入工作册编辑。

文件完整取得后，本次会话可离线阅读、播放、看纸页和使用包内 PDF 打印；不要求登录原作者、加入原家庭或购买阅读资格。关闭后不在首页、收藏或「最近打开」中留条目，不保存正文、封面缩略图、声音和跨会话阅读位置。

解码、校验和播放允许使用必要临时文件，不等于建立永久副本。临时数据按第14节清理；修改成品、转为工作册、接收者成品库均不在第一版。

## 4. 入口与信息布局

### 4.1 生活册首页

沿用现有封面墙，统一底带入口下以轻量「我的／家里的」分区呈现，默认打开「我的」。我的显示个人工作册；家里的按用户当前可访问的家庭组织工作册，必要时显示家庭名称，避免不同家庭混收。创建者显示制作操作，成员显示阅读操作，不能只靠标签模拟权限。

收到或打开的成品不进入首页，不增加「导入册」「收到的册子」或「最近打开」分区。宽度足够时两列，短屏／窄窗可变一列；列数由可用宽度决定，不为手机纸页缩字。

每册显示封面、册名与简洁范围／必要来源。新册按记录与媒体原顺序取第一张当前可用照片，移出该条或照片失效时回落到下一张有效照片；无照片用有层次的文字封面，不生成假风景。不用AI、人物或情绪判断选图。

已有手选封面保留，来源失效时仍按现有有效性规则回落。新流程不展示浏览全册照片再选封面的必经操作，也不提供新的手动更换入口；升级不删除旧封面数据。必要信息不能全部堆在封面上。

主入口「新建一册」，取消首页「打开生活册文件／导入」入口。轻量引导说明「边回看边收下 → Lampy 编排 → 阅读与收藏」，可收起，不做完成进度。外部成品通过系统打开方式进入阅读器，不要求用户在App中管理文件。

家庭册的入口亦可在当前家庭卡片操作中出现，但不要让成员误以为可以导出。现有「收进生活册」弹层视觉与取消／新建行为复用，不回退为垂直文字堆砌。

### 4.2 册子页

保留小封面、册名、真实条数与已知时间范围。主要动作「看看这一册」；编辑、整理、风格与导出位于低强调操作区，不将所有选项常驻堆叠。

编辑只包含册名与可缺省开篇，封面自动生成；整理保留上移、下移与「移出这一册」。统一个人／家庭操作，条目上的「删除」改称「移出这一册」，不删除Moment或撤回家庭分享。已有未保存输入保护、异步请求资格和封面URI解析必须保留。

### 4.3 阅读器

默认进入连续阅读。工作册与成品复用同一套呈现能力，以明确状态决定操作：工作册提供「看纸页」及符合角色／权益的「导出这一册」；成品只提供阅读、播放、看纸页与明确关闭，不提供编辑、收进、导入、自动保存或付费再导出。

阅读时减少固定工具占用，不把按钮插进正文每一条。工作册返回／重开可恢复持久阅读位置；外部成品只在本次会话保持位置，关闭后不持久记录。外部打开须有清楚的「关闭」出口，无工作册来源时不得强迫返回某个册子管理页。工具区隐藏时仍有明确、可达的唤出方式。

## 5. 创建、收集与成册流程

### 5.1 个人册

1. 新建一册，只需册名，允许默认名与空开篇。
2. 沿用回看连续阅读，逐条「收进这一册」；详情亦可收入已有册或就地新建。
3. 收集立即保存，不要求完成选择；收入状态同步，返回不丢阅读位置或播放器进度。
4. 看看这一册，默认长页；可改册名、可缺省开篇、顺序与整册风格；不要求选择封面。
5. 看纸页确认打印效果。
6. 导出前核对内容与媒体，生成冻结成品，再打开系统分享面板。

### 5.2 家庭册（共同分享约定已确认）

1. 当前创建者在「家里的」选择自己的家庭并建立一册，复用「册名＋可缺省开篇」流程。
2. 从该家庭的有效分享逐条收下，或「收下全部」；不向成员逐条申请。全选必须覆盖完整分页范围，不仅当前已加载记录，并在导出前重新核对。
3. 自己尚未分享的Moment须先完成明确的家庭分享，才能进入家庭册；「收进册子」不偷偷替用户分享。
4. 整理沿用上移／下移／移出。移出家庭册不撤回原家庭分享。
5. 家庭工作册阅读沿用当前家庭资格；后加入与再次加入成员可读仍有效内容。打开成员、目录或离开时保留现有声音暂停规则。
6. 创建者导出时重新验证角色、付费权益、分享状态与版本，再明确确认；不检查或创建逐条导出许可字段。
7. 导出成品不再是实时家庭记录，已交付文件与纸书无法远程收回；分享者使用现有「撤回分享」停止后续使用。

不把私人资料上传到服务器只为排版。家庭来源媒体本来通过家庭服务读取；完成成品所需数据在有权限时取得，生成本地成品。

## 6. 连续阅读与打印版的一致性契约

**同一册、同一内容快照、同一风格版本；同样的原文、照片、声音、日期、感受、顺序与图文关系。**

| 项目 | 一致要求 | 允许差异 |
| --- | --- | --- |
| 内容 | 全文、媒体、作者、日期精度不变 | 打印以声音标记代表声音，不假装能在纸上播放 |
| 字体 | 使用相同字体家族、字重和角色 | 阅读按宽度使用批准字号档；不强求逐行相同 |
| 颜色 | 纸、墨、辅助色与装饰一致 | 打印白底方案须单独批准，并让打印预览显示真实输出 |
| 版式 | 相同对齐、间距层次、线条和块顺序 | 换行、续页、纸页边距与装订空间不同 |
| 照片 | 原比例、原顺序、相同装饰 | 打印整张移到下页；窄屏并排版式变纵排 |
| 声音 | 相同位置、波形与时长 | 阅读可播；纸页标示「在电子册中听」 |
| 分隔 | 同一种记录间留白与分隔线 | 连续阅读无印刷裁切线或重复页脚 |

不能把连续版做成普通列表，把打印版做成另一套相册。也不能为追求逐行一致把整张纸页缩进手机。视觉一致须通过成对样本审阅，不以 JSON 相同作为证明。

## 7. 连续阅读设计

### 7.1 阅读结构

封面 → 可选开篇 → 正文记录 → 安静收尾。无开篇时直接进入正文，不留空白页。封面是一段有留白的开场，不强迫每种设备占满首屏或锁定高度。

正文为连续纵向阅读，不强制左右翻页。同日首次显示完整已知日期，其余同日条目用留白与浅线分开；不把多条合成一篇。未知日期按真实范围显示，不伪造星期或时刻。

### 7.2 响应式阅读

手机维持舒适的正文尺寸，平板／横屏限制阅读列宽并居中。第一版建议正文16–18pt作为实测起点；不把该范围当成已验证定稿，也不改变当前全局固定应用字号策略。

段落、照片与声音可形成连续章节感，但不自动添加章节标题。过长正文不截成六行；如果分段接续加载，要读起来连续且保持全文。

### 7.3 性能与定位

长页是逻辑连续，不是一张超长图片，也不一次挂载整册。按记录／媒体块接续加载，图片按需解码，声音只在点击后准备播放。

工作册阅读位置保存为册版本＋条目 ID＋块内位置；外部成品仅在本次阅读会话内保留同类定位，不写永久历史。宽度变化、照片迟到加载、字体就绪与会话内返回时尽量恢复原阅读行，不仅保存裸 scrollY。已有滚动恢复代码先复用，所缺能力再实现；不能因此自动留下成品副本。

## 8. 视觉语言与装饰

### 8.1 共同基础

沿用 Lampy 暖纸、墨色、sage 与感受小色点。默认参考现有 token：纸 `#F3F0E9`、墨 `#25231F`、浅墨 `#5C5851`、sage `#53604F`；最终以项目真实 token 和批准样本为准，不全局替换 App 配色。

中文衬线与英文衬线建立正文的阅读感，辅助信息用协调的无衬线。册名字阶最明显，日期次之，正文稳定，作者／时长／页码低强调；不靠大量颜色区别层级。

装饰不能遮正文或有效照片区域，不能暗示一个未记录的事件、季节、情绪或记忆意义。

### 8.2 两种候选风格（待审）

| 风格 | 主体 | 装饰 |
| --- | --- | --- |
| 素纸 | 字体、留白、细线、完整照片 | 可选轻白边，不使用胶带／角贴／重纹理 |
| 手作 | 仍使用相同结构和字阶 | 少量白边、相片角贴或轻胶带、克制日期印记与纸质感 |

用户为整册选一次风格，不逐页选装饰。默认素纸为建议，不是已确认决定。每种风格先交付完整中英文样本，不能只展示一页效果图。

### 8.3 装饰规则

- 拍立得白边不是每张照片必套；不同图宽高比使用协调边距，不机械放大下边框。
- 胶带／角贴只作装饰，不替代照片说明，也不因没有 caption 自动出现。
- 纸质纹理低对比，不影响文字与二维码辨认；第一版是否采用由打印样张确认。
- 日期印记仅包含已知信息；感受只用用户原词及已有色点，不生成太阳／雨云来暗示情绪。
- 声波由真实音频采样生成，装饰波形不能冒充内容。无波形时用安静的声音标记。
- 同一册布局／装饰选择可重复生成，不在每次打开时随机换样子。风格与装饰版本记录在成品中。

## 9. 自动排版与内容忠实性

### 9.1 有限版式

| 内容 | 建议处理 |
| --- | --- |
| 短句 | 左对齐、适量留白，不自动放大为海报或强制居中 |
| 长文 | 单栏为主，按真实字体测量，优先段落断点；不按150字强制双栏 |
| 单张横图 | 原比例，宽度与阅读列／版心协调 |
| 单张竖图 | 原比例，可适量收窄，避免过长空洞，也不裁切 |
| 多图 | 保留原顺序；空间足够时相邻协调，窄屏纵排；新并排规则须另审 |
| 声音 | 播放标记、真实时长、可选真实波形，视觉低强调 |
| 混合记录 | 文字 → 原序照片 → 声音 → 原感受；维持条目归属 |

第一批样本以现有「文字先、照片原序」为基础；不擅自改成照片优先。以后确有必要的杂志式图文并排需保持明确的阅读顺序。

### 9.2 不补造信息

照片没有说明就没有说明，不显示「无标题」，不补 AI 标题、EXIF时刻、设备型号或地点。原文有换行则尊重其段落；不改写以填空白。

发生时间按 exact／day／month／year／unknown 处理；只有真实日精度及以上才显示星期。记录时间不能冒充发生时间。跨时区策略先沿用项目已确认语义，不能从新字符串解析出虚构的本地日期。

只有声音／只有照片的记录仍是完整记录，不被认为内容不足。未知媒介和缺失内容不能无提示丢弃。

## 10. 字体与打印规格

### 10.1 字体策略

自定义阅读器使渲染可控，但不能让每台设备继续任意选择系统回退字体。导出要冻结字体策略，记录真实使用字形；不能只记录「Songti」名称就声称跨设备一致。

建议选择允许随文件分发、支持中英文的字体；可复用已有 OFL 字体来源作为候选，但须核对具体字体、许可、中文覆盖、混排、emoji与文件体积。不得复制系统字体文件进成品。

PDF需验证文字可选择、字体嵌入与回退；仅扫描 `/FontFile` 或诊断名称不是完整验收。连续版与打印版必须测试同字体下的真实样本。

### 10.2 第一版纸张

建议一种A5竖向尺寸。现有420×595pt为近似A5；正式打印可采用148×210mm对应的精确物理尺寸，调整时升排版版本并重测旧册。

边距按毫米／pt定义，区分内外装订边；以实际样张确认字阶、行距和留白，不使用15%–20%作为所有内容的硬比例。

普通打印版采用连续页序，不自行拼成印厂书帖。封面、可选开篇、正文、收尾随内容生成，不要求固定页数或人工凑页。

PDF文字与矢量线条不依赖统一300DPI。检查照片实际印刷尺寸下的有效分辨率；低清原图可提示，不用上采样伪装高清。第一版不宣称CMYK／PDF-X专业印厂认证。

留白版式不强制出血。未来满版图或印厂要求的出血、色彩配置和装订规范另行支持。暖纸色打印与可选白底应成对比较；不能让实际PDF与「看纸页」颜色不同而不告知。

### 10.3 分页硬规则

1. 全文不漏、不重、不截字；尊重段落和文本编码边界。
2. 不缩字、压行距硬塞。装不下就续页。
3. 日期与后续内容一起测量，避免日期孤立；长文避免单行悬在页首／页尾，具体规则由样本确认。
4. 图不从中间切断，整张放在页内；极长图缩到可用尺寸并提示可在电子册放大，不强裁。
5. 图文拆页后仍可辨认所属记录；必要续标记保持低强调，不生成故事句。
6. 同日日期去重，但每条记录仍分明。封面可复用册内照片，正文媒体不因封面再重复收录。
7. 页码只属于纸页，不插入连续阅读正文；电子页预览与PDF页码一致。
8. 缺失媒介、未确认时间和未知感受原样处理，不补日期、图或色点。

## 11. 声音阅读与纸质表达

声音不要求用户剪短才能成册。现有录音、上传、文件系统与导出限制实施前逐项核对；本文不宣称目前所有环节已经支持无限时长。

文件包保存全部已选择声音，不静默截断或降为网络地址。长录音使用分段读文件／流式复制与播放，不能把全部字节和波形同时载入内存。后台导出是否可持续取决于iOS能力，不能承诺任意时长都在后台完成。

播放必须用户点击；同一时刻一段；保留进度，暂停后可续播。离开册子、切后台或锁定暂停，返回不自动播；具体复用现有播放器，不能另起一套失控播放状态。

打印版保留同一声音标记、真实时长及文字「在电子册中听」。第一版不印一个需要云托管才能工作的二维码。未来可研究本次已打开成品的本地定位二维码，但不能承诺通用扫码直接播放，也不把完整声音塞进二维码。

## 12. 工作册、快照与成品

| 状态 | 内容规则 |
| --- | --- |
| 工作册 | 来源引用，读取当前有效版本；可编辑、增减、整理 |
| 正在导出 | 收集成册输入、核对权限，冻结快照，复制媒体，生成排版与PDF |
| 已完成成品 | 固定版本、自包含；后续原文修改或家庭撤回不偷偷改动已导出文件 |
| 再次导出 | 新快照与新版本，保留旧成品独立性 |

导出前二次核对来源版本与媒体。导出中来源、权限或封面变化则取消／重试，不能混用两份内容。

个人缺失内容先给核对提示，允许明确移出、修复或带缺失说明导出；不能把替代说明写成原文。家庭被撤回／无权限的内容不得从旧缓存输出成品；此类情况必须停止并重新确认。

媒体只在生成成品时复制，不在每次收入工作册时暗拷。成品输出使用临时文件，全部成功校验后原子完成；失败／取消清理未完成副本。

本机保护开启且锁定时不能开始、继续读取个人来源或弹出分享；未完成导出暂停／取消策略待原生实现验证。已交给系统分享或其他应用的成品不受Lampy盖层保护，首次分享给出简明说明。

## 13. 离线生活册文件包

### 13.1 成品要求

候选扩展名 `.lampy`，候选容器为ZIP；这是格式建议，审阅后再实现。用户只接触一个文件，不手工打开文件夹拼媒体。

成品中建议包含：格式版本、册名／开篇／风格、排序与记录快照、相对媒体引用、完整媒体、字体与许可、打印PDF、文件完整性清单。JSON或索引是内部结构，不出现在用户流程。

读取不依赖原本机路径、登录token、家庭服务、原作者账号或长期远程音频。不得打包绝对路径、邮箱、手机号、邀请秘密、服务端凭据或不必要的EXIF定位信息。作者仅保留本册批准显示的昵称与来源标识。

打印PDF与连续阅读共用内容快照，不能各自读取实时来源。字体、风格、内容与排版版本明确，后续阅读器支持兼容旧版本；不能静默用新样式改变旧成品。

### 13.2 完整性与容量

导出前估算文件大小和本机临时空间，允许用户取消。压缩／复制必须处理重复媒体、长音频、低存储、损坏输入；使用流式处理，不将全册Base64装进内存。

完整性校验能检测损坏，不等于证明发送者身份。第一版不宣传签名或防伪能力。

格式定义相对路径与受控内容类型。外部文件校验与临时解包拒绝路径穿越、可执行脚本、外部媒体回调、超额解压与损坏文件。具体资源上限来自设备测试，界面用生活化提示，不用「manifest schema」等内部术语。

### 13.3 不承诺的事情

文件包不是云同步，不保证不被复制，不支持远程撤回，不是全库备份。Lampy不自动留存接收者副本，不等于微信、邮件、Files或网盘没有外部副本，也不能阻止接收者在外部主动保存／转发。口令加密可后续设计；第一版若未实现必须准确说明，不能称作自动安全加密。

## 14. 创建者保存与按次打开阅读

### 14.1 导出

1. 从工作册的册子页或工作册预览进入「导出这一册」；已生成成品阅读器没有再制作／付费导出入口。
2. 简洁选择「生活册文件（含照片、声音和打印PDF）」或「打印PDF」。文字不写技术术语。
3. 核对内容／缺失媒体；家庭册核对当前创建者资格与有效分享，展示简明隐私提醒，不列逐条许可状态。
4. 未解锁导出权益时显示真实产品与价格；未接付费的测试阶段不展示假购买。
5. 用户明确开始；反馈当前阶段与取消，只有有可靠总量时才显示百分比。
6. 完成后提供创建者明确的「保存成品」、打开与分享操作。生成和分享不等于已经保存；保存失败／取消准确反馈，可在当前成品会话继续操作。取消系统分享不重复生成／扣费，不删除已明确保存的文件。

建议成品名称由册名生成，解决非法文件字符与重名，不暴露用户ID。生成与分享分开：重复分享同一成品不要求重新上传或重新成册。

### 14.2 外部打开与免费阅读（已确认）

微信／邮件／系统文件中的成品 → 选择「用 Lampy 打开」 → 校验和必要准备 → 直接进入连续阅读。不增加「导入」「加入收藏」「选择目录」「确认保存」步骤；准备耗时较长时只有轻量状态与取消。

第一版使用Lampy App内的只读阅读模式，不另做阅读器App。无需原作者账号、原家庭资格或购买阅读资格。未安装Lampy时，系统不能直接执行阅读；安装／网站打开指引属于后续外部流程设计，不在本稿承诺安装后自动找回文件。

同一成品在当前会话再次打开可聚焦已有阅读，不能叠多个播放器；关闭后再次打开则重新取文件并开始本次阅读，不查询永久收藏／恢复上次位置。另一个成品到来时作废旧请求，旧加载不能覆盖新册。

外部成品不写个人Moment／家庭册表，不生成首页条目、不保留封面缩略图、不生成阅读历史、不提供接收者管理副本功能。未知版本／损坏文件显示轻量失败，不改写外部原文件。

### 14.3 临时数据与退出

文件访问、解包、图片解码和声音播放可能需要临时副本；按本次会话隔离，尽量按需读取，不默认永久复制完整文件。来源需下载时如实显示准备中，不能在未取得完整内容时承诺断网可读。

明确关闭阅读器后：暂停声音、取消迟到任务、释放文件权限和句柄、清理该会话临时文件及敏感内存／缩略图；不删除外部原件。App异常退出留下的临时残留在下次启动时清理，并避免纳入长期备份。分享／打印尚在使用临时文件时等待其结束再清理；失败可反馈，不能假称已立即清空。

切后台不等同于关闭：声音暂停，开启本机保护时内容遮挡，当前会话可在解锁后继续。进程被结束后不自动恢复外部成品，用户从原消息／原文件再次打开。保存当前工作册位置与保留外部成品副本是两种行为，不能混用。

### 14.4 创建者保存与未来云空间

创建者负责保存自己生成的成品。第一版提供明确的保存动作及成功反馈，不能把只弹出分享面板称为保存成功，也不把导出临时文件当作永久收藏。

将来可把用户记录和成品同步到用户自己的云空间；这是后续方向，服务、权限、恢复和生命周期尚未设计／实现。当前阅读与保存不能依赖它，也不因此增加接收者副本库。打开创建者已保存成品仍使用同一只读阅读器；编辑则回到原工作册。

## 15. 家庭成册共同约定与隐私（R3已确认）

### 15.1 角色资格

| 身份／内容 | 家庭工作册阅读 | 整理工作册 | 执行导出 |
| --- | --- | --- | --- |
| 当前创建者 | 有效成员资格内可读 | 第一版建议是，协作范围见R8 | 有付费权益、来源仍有效时可导出 |
| 普通成员 | 有效成员资格内可读 | 第一版建议否，协作范围见R8 | 否 |
| 已离开／被移除 | 无在线读取资格 | 否 | 否 |
| 已解散家庭 | 保留历史目录，不恢复内容访问 | 否 | 否 |
| 正在打开成品的接收者 | 文件完整取得后本次会话可离线读 | 否 | 无制作／付费导出入口；外部文件可被主动保存／转发，不能伪装阻止复制 |

创建者角色与付费权益分别检查；转交不自动转移另一个人的购买，也不自动给予旧创建者新的导出资格。具体权益归账号／家庭的方式由商业阶段决定。服务端验证角色、分享有效性与版本，不能仅靠客户端隐藏按钮。

### 15.2 一次说明，不做逐条许可

家庭分享本身包含按共同约定成册的用途。第一次家庭分享时用简洁规则说明并明确确认；以后不要求每条Moment重复选择或审批。不增加创建Moment时的导出选项、不建立逐条许可字段、不增加许可修改页面。

规则文案：**「分享到这里的记录，家人可以阅读，家庭创建者也可以收进生活册，保存或打印。」**

首次规则说明同时交代：已交付的文件和纸书无法追回。已有成员与既有历史分享在启用新规则时一次明确告知，不静默改变用途；不建立逐条补许可、等待全体成员审批或新的成册管理系统。上线告知与隐私政策须对应真实行为，具体通知位置在UI样本中确认。

创建者可选取需要的内容，也可收入当前家庭的全部有效分享。全选不包含已撤回／无权访问的旧缓存，不跨家庭，不把未来新增分享自动收进册子，不生成摘要或改写原文。

### 15.3 继续使用现有撤回

分享者不希望继续使用某条记录时，使用已有「撤回分享」，不新增“关闭成册许可”接口。撤回后，家庭在线阅读和工作册后续预览／新导出均不可继续使用该内容；不是“只禁导出但还能从旧缓存预览”。

家庭工作册可低强调显示“这条已撤回”或让创建者移出，不继续显示私密原文／图片／声音。受影响的自动封面同样回落。正在读取／排版／导出的请求失效，停止受影响任务，重新核对后再生成，不静默交付一个混版本成品。

服务端收权与客户端缓存／播放器失效都必须验证；停止音频，不自动复播。已经导出的文件、已经打印的书不承诺删除或远程追回。

### 15.4 创建者责任

最终导出给一次低强调提醒：**「请妥善保护家人的隐私。」** 规则说明中保留保存／打印／转发的边界，日常流程不反复增加弹窗。

创建者付费取得执行导出的权益，保护家人隐私依旧是责任。第一版不做复杂DRM、审批或逐条授权管理；不得宣传能阻止接收者截图、转发或保存外部副本。

## 16. 商业边界

创建、收集、整理、完整预览为免费方向；正式成品导出拟付费，接收者阅读免费。具体一次解锁／订阅／按册、价格、退款和权益未确定，本稿不补造。

已由创建者保存或用户从外部取得的成品可以离线打开，不远程禁用；Lampy不为接收者自动留存。订阅到期影响新的导出权益，不影响旧成品按次阅读。基础个人备份不应被混同为美化导出付费功能。

购买失败／取消不生成假成功；生成失败不重复收费。具体商店商品与计费重试语义在商业阶段单独设计与真机验证。

## 17. 状态、异常与辅助功能

| 情况 | 用户反馈与行为 |
| --- | --- |
| 空册 | 先收下一条，也可以慢慢添；有明确收集入口 |
| 排版加载 | 保留册身份，显示正在编排；不闪出另一册旧内容 |
| 失败 | 明确失败与重试，原收入不丢；不伪装为空 |
| 缺照片／声音 | 核对时逐项指出，禁止静默省略 |
| 家庭内容失效 | 停止读取／导出；不从旧缓存复活 |
| 空间不足 | 可取消、清理后再试，不删用户原记录 |
| 文件损坏／版本过新 | 说明不能打开；不修改原文件、不添加收藏条目 |
| 外部来源不可用／文件尚未下载 | 提示从原消息或原文件重新打开；不伪装永久副本仍可读 |
| 分享取消 | 回当前册，成品状态正确，不重复提交 |
| 锁定／账号切换／快速换册 | 旧异步回调作废，不写回另一册或另一账号 |

触控目标至少48pt，声音装饰不替代可聚焦播放按钮。原生绘制若不自带文本语义，按真实阅读顺序提供辅助层，避免重复朗读；照片说明不由AI补造。

Reduce Motion时取消位移动画／淡入等待，内容直接就绪；无自动翻页或自动播放。无障碍朗读不能泄露锁定后的正文、昵称和册名。VoiceOver系统引擎必须实测，AX或Jest不写成系统PASS。

屏幕UI继续当前已接受固定字号策略；连续阅读自身的窄屏适配不等于重新打开系统字体缩放。是否增加用户自选阅读字号另行讨论，不扩大本轮范围。

## 18. 工程实现原则

### 18.1 共用内容与设计，分别布局

建议结构：来源适配（个人／家庭）→冻结内容快照→共用风格与字体规格→连续阅读布局／打印分页布局→阅读器／PDF→成品封装。

共用设计规格包含字体角色、颜色、照片装饰、间距、日期、声音与感受样式；两种布局允许不同断行／分页。不能为了表面统一把连续阅读器也锁成纸页截图。

沿用现有AlbumLayout与Core Text测量／绘制。不要在未经验证时更换为Puppeteer／Paged.js，也不把RN Text、浏览器字体和PDF各自再断行当作已同版。

### 18.2 数据与导出身份

工作册与成品分离。成品有自己的ID、格式版本、内容版本、风格版本、生成时间与完整性信息；生成时间不冒充记录发生时间。

个人来源保留moment／revision的内部可追踪关系；家庭来源使用family／share／snapshot版本；导出时白名单复制，不打包完整数据库、账户资料或多余私密字段。

旧册迁移、家庭册聚合、一次规则告知、角色／分享有效性校验与外部阅读会话分别设计；不建立逐条成册许可或接收者永久文件索引。不得复用未实现的Collection薄类型或AI回眸方案来伪装已有能力。

### 18.3 隐私默认

个人成册本机处理，默认无上传、无外部字体请求、无分析私人内容。文件中的图片显示副本保留视觉内容和方向，剥离不必要定位等元数据；任何转换不得修改原本机媒体。

媒体不足时不将联网下载默默升级为额外私密上传。锁定取消资格、账户切换与分享者撤回检查贯穿读取和导出，不只在入口检查一次。

## 19. 设计样本与验收

### 19.1 样本素材

先用合成内容制作两种风格、连续版与打印版成对完整样本。纸页不写测试旁白，不要求固定14页或按记录数凑页。

样本覆盖：中文长短文、英文和中英混排、标点／emoji、长册名／开篇、纯照片、1–3张不同原比例图、极长图、纯声音和长声音、图文声混合、同日多条、不同精度／未知日期、缺失／未知媒介、无封面、家庭同昵称作者。

### 19.2 验收矩阵

| 层 | 必须证明 |
| --- | --- |
| 内容 | 原文、顺序、媒体、日期精度不变，无遗漏重复；导出冻结一致 |
| 视觉 | 两种阅读呈现同一风格；字体、装饰、比例与留白协调；整册而非单页审阅 |
| 分页 | 真测量、无截字／孤立日期／裁图；连续版与纸页内容逐项对照 |
| 打印 | 实际A5样张字号、颜色、内边距和扫码占位（若未来增加）验证；PDF字体和图像质量检查 |
| 离线 | 成品完整取得后停Metro／断网／退出账号，本次阅读仍可读听，不依赖原作者路径／账号；关闭后需从外部再次打开 |
| 长内容 | 多记录、长音频、低空间、快速滚动与旋转不内存失控；工作册重开恢复位置，外部成品仅当前会话保位置 |
| 家庭 | 首次分享／历史规则一次告知；无逐条许可；选取／全选完整分页有效分享；非创建者不可导出，撤回／离开／移除／解散／转交与迟到读取不绕收权 |
| 首页与封面 | 我的／家里的分区不串来源，制作流程一致；自动首图／文字封面／来源失效回落，旧手选封面保留 |
| 保护 | 后台与认证期间册名、正文、昵称始终遮挡；声音暂停 |
| 文件 | 重复打开、换册、版本兼容、损坏、路径穿越／超额解压正确处理；关闭／异常退出后临时清理，不留下收藏／历史 |
| 设备 | iPhone短屏／常规屏、横屏、iPad分屏、中文／英文、VoiceOver与Reduce Motion |

自动化和实页分开。合成PDF、静态HTML、截图或字体关键词扫描不能直接写成正式用户导出／全设备PASS。
