# V2流程：同一套制作、两类来源、成品按次阅读

## 个人

我的 → 新建一册（册名＋可空开篇）→ 回看／详情收下 → 册子 → 看看这一册（连续）→ 看纸页／整理 → 导出 → 创建者明确保存／分享。

收集只引用Moment；上移／下移／移出不改原记录。「移出这一册」不是删除Moment。新册无手选封面步骤。现有收集同步、草稿／输入保留、目录暂停及滚动恢复不变。

## 家庭

家里的 → 选择当前有权访问的家庭 → 创建者新建 → 从有效分享选取／收下全部 → 同样阅读整理 → 核对当前角色、来源与权益 → 保存／分享。

首次分享一次说明：分享到这里的记录，家人可以阅读，家庭创建者也可以收进生活册，保存或打印。启用新规则时既有成员一次告知，不逐条补许可、不等待全体审批。

尚未分享到家庭的私人Moment不因收集而偷偷上传。全选针对当前全分页范围，不自动收未来新分享。其他家庭不混收。撤回停止后续阅读／预览／导出、失效缓存和播放，旧成品不可追回。

## 外部成品

微信／邮件／Files中的成品 → 用Lampy打开 → 必要校验与临时准备 → 只读连续阅读／播放／看纸页 → 关闭 → 清理临时数据。

无导入按钮，无保存确认，无接收者收藏库，无最近打开／跨会话位置恢复。异常退出的残留下次清理。切后台只暂停及遮挡，不等于立即关闭；本次会话内可继续。创建者自己的成品也用同一只读阅读器；工作册编辑回原工作册。

## 样本边界

样本只演示已冻结的合成成品与排版。没有家庭登录、真实许可／撤回、文件导出或购买。不能以样本打开成功声称以上流程实现。
