# 阶段 E：家庭数据、资格与撤回基础

当前客户端时序：读取有效期 15 秒，每 3 秒尝试续验，单次 validate 最多等待 5 秒并取消超时请求；瞬时网络错误在有效期内后台重试，明确失权/撤回仍立即隐藏。持续断网最多约 15 秒后隐藏（本地检查间隔 250ms）。下文早期 3 秒/500ms 调试记录仅为历史，已由本节覆盖。

基线：main 6a4ad76（#112 已合并）。#113 阶段 D 保持独立暂停验收，本分支不依赖其离线成品实现。

## 本次范围

- 家庭册服务端只保存册名、开篇、有序 shareId 引用、版本号；不复制个人 Moments 或分享正文到册表。
- 当前家庭成员确认一次规则后可读；仅当前创建者可建册、收入、移出、排序或修改册名/开篇。开发界面提供建册、选收/全收、移出及来源阅读；开发界面支持上移记录，提供统一的“编辑册子”，编辑册名、开篇及自动/手选封面。
- “全部收入”收入操作时仍有效的分享，后续新分享不会自动加入。遵循既有 family-history-v2：有效历史分享仍向当前成员可读，不额外要求作者仍在家庭。
- 创建者转交后，新创建者接续同一册；旧整理资格失效，即使以后转回也不能重用旧资格。
- 逐次读取关联当前分享状态。作者走现有撤回流程后，册内只留不可用占位，原文、作者与媒体不再返回，封面重新选择或退回文字。
- 离开/被移出/解散/会话失效后拒绝服务端读取。客户端不持久化册正文；离页、后台、锁定及资格检查失败清空显示并暂停声音。
- 客户端每 1.5 秒复核，读取资格最长 3 秒（起算于请求开始），本地每 250ms 检查过期。此为轮询与短期资格，不是服务端推送，不能承诺撤回瞬间隐藏；双设备实际延迟待验收。
- 解散后沿用既有 30 天保留清理，同时删除家庭册元数据及确认记录。

不包含完整家庭册文件导出、付费、离线成品，也不宣称完成首次分享处的规则提示和全员通知。当前确认仅覆盖家庭册开发入口。已交付文件及纸书不能追回。

## 开发环境

服务端使用隔离测试数据库，执行现有 migration 命令升级至 migration 30，并同时开启：

```sh
LAMPY_FAMILY_HISTORY_ENABLED=1 LAMPY_FAMILY_ALBUMS_ENABLED=1 npm run family-api
```

客户端沿用现有家庭功能/API 地址配置，在 `apps/ios` 下：

```sh
EXPO_PUBLIC_FAMILY_ALBUM_EVAL=1 npx expo start --dev-client --port 8082
```

这是仅开发构建可见的入口，生产构建始终关闭。家庭必须已按现有流程启用 family-history-v2。由“生活册 → 家里的”直接看到跨家庭的册子列表；新建家庭册时只有多个可管理家庭才需要选择所属家庭。在家庭页选中创建者家庭后，可点“添加到家庭册”，直接选择该家庭已有的册子与分享。服务端未部署；只有前端开关不能完成端到端验收。

## 双账号验收

| 操作 | 通过标准 |
| --- | --- |
| A 创建者、B 普通成员分别进入 | 各自一次规则确认；B 无整理入口，直接调用写 API 也被拒绝 |
| A 新建册、选收 B 分享，再全收 | 作者与原文正确、顺序稳定、不重复；未来新分享不自动收入 |
| B 撤回册内照片/文字分享 | A 当前册及来源选择列表复核后隐藏原文，封面不再引用撤回照片；重开只见占位 |
| A 向 B 转交，再转回 | 新创建者能继续整理；旧 authority 请求均失败 |
| B 被移出、重新加入 | 移出后无法读取；重新加入需重新确认规则 |
| 后台、锁定、离页，网络断开或挂起 | 内容隐藏、声音暂停、旧异步结果不能恢复显示；网络请求挂起时本地资格仍过期 |
| 跨家庭分享/册 ID，旧 revision，并发修改 | 被拒绝；失败不部分保存；两个 SQLite 连接同版本写入只有一个成功 |
| 家庭解散及清理期限 | 立即失去在线访问；期限前保留数据，期满清理册和确认记录；个人内容不受影响 |
| 默认配置、个人生活册 | 家庭册开发入口关闭；个人册现有功能不变 |

自动测试覆盖内存/真实 SQLite、独立数据库连接并发、迁移回滚、撤回、转交、重新加入、会话切换、短期读取失效与清理。模拟器、双设备和实际媒体播放仍待验收；Linux 环境未运行 iOS 构建。

## 家庭册入口调整

- “我的／家里的”同页切换，家里的直接展示册子及所属家庭，无册时提示并为创建者提供“新建家庭册”。尚未确认的家庭显示单独规则说明入口，不把家庭名伪装成册名。
- 新建页沿用个人册的名称输入和操作字体，先选所属家庭（只有一个可管理家庭时自动选定），确认规则后命名建册；建好直接进入此册，可选收或全收。
- 家庭页选中创建者家庭后，“添加到家庭册”将 familyId 直接带入。选定已有册后直接载入可选分享；只能收入同家庭有效分享。
- 直接点册子打开该册；册内可继续收入、移出和上移记录。普通成员只读；资格、撤回、后台保护及本地过期机制继续保留。
- 此次为客户端调整，沿用服务端 36681e6/migration 30，不需重新部署 API，不新增原生依赖；模拟器页面与双设备流程仍待人工验收。

## 编辑册子

家庭创建者在册内使用“编辑册子”，编辑册名、开篇和封面。封面可自动选择，或从当前册仍有效分享的照片中手选；选中照片提供受保护的预览。以一次 edit 命令保存全部字段，保留版本与 authority 校验，普通成员不能编辑。

手选封面只保存 shareId/objectId，不复制媒体。撤回或移出后读取结果不再返回该手选引用，封面回退为当前有效照片或文字；重新选择已撤回来源被拒绝。旧册无 coverChoice 字段时继续使用自动封面。JSON 存储字段扩展，不新增 migration；本次需更新云端 API 后测试编辑保存，旧服务不支持 edit 命令。

验收：创建者编辑三项并重开确认；取消不保存；普通成员无入口且写 API 拒绝；将手选照片撤回、移出，确认封面回退；旧 revision 或旧整理资格不覆盖新编辑；后台与锁定隐藏预览。

## 编辑续验时序修复

册子打开后立即续验，之后每 500ms 尝试续验，单次请求未完成时不叠加；最长 3 秒本地资格与 250ms 过期检查不变。续验直接调用携带原验证摘要的 validate，摘要已包含服务端账号、成员和整理资格；请求前核对本地账号与册子账号，请求后再次核对账号/token/页面代次，不再额外串行 access 请求。

有打开的册子时不重复轮询家庭目录，其资格由册子续验覆盖；只有展开的来源列表需要单独复核。初次读取当前家庭资格期间不启动重复目录轮询。失败重试重新读取路由指定的原册。自动回归模拟每次续验 1 秒、持续编辑 12 秒草稿保留，以及失败后重试恢复；断网挂起仍到期隐藏。该修复仅客户端，不需重部署 API，实际云端延迟仍需模拟器确认。

## 续验等待与明确失败分开

用户模拟器截图：上次续验 21ms 成功，下一次停留 SERVER_REQUEST 2616ms 时旧资格到期。这证明单次等待触发了本地截止，不证明服务端拒绝资格；网络/服务端等待的底层原因尚未确定。

资格到期且请求仍等待时，正文、封面与编辑区整体隐藏并移出辅助功能树，暂停声音，显示“正在重新核对家庭内容”。内存中保留草稿，继续串行续验；耗时超过资格窗口的响应不恢复显示，必须再发起一次新校验并在期限内通过后才恢复。明确撤回/失权/请求报错仍清空阅读并显示失败。后台/离页/锁定继续原先的清理逻辑，不持久化草稿。进入编辑关闭来源选择，避免无关来源列表轮询影响编辑。

自动回归覆盖超过 3 秒的挂起、等待时正文与编辑控件不可访问、旧响应不能恢复、新校验后草稿保留、撤回时不恢复。修复仅客户端，云端 API 无需再次更新；模拟器与实际网络待验收。

## 编辑稳定性调整

用户报告短期等待导致隐藏/恢复反复切换，打断编辑。统一使用 FAMILY_ALBUM_LEASE_MS=15000、FAMILY_ALBUM_RENEW_MS=3000。validate 请求具有 5000ms 超时与 AbortController 取消，包含读取响应正文的全过程；即使底层 fetch 不响应取消，逻辑超时也能返回并允许下一次续验。只有 validate 添加该超时，其他 API 保持原有行为。

SERVER_UNREACHABLE、NETWORK、RATE_LIMITED 属于暂时失败，不延长旧资格，也不清空仍有效的草稿；按间隔后台重试。明确内容变化、无成员资格、登录失效等仍立即隐藏。持续失败时按 15 秒有效期隐藏；过期后的恢复依然要求新校验通过，不能使用过时响应。无原生或服务端变更。

验证：每次续验 4 秒持续 60 秒，编辑控件一直可见、草稿保留；挂起超时取消、成功后清理超时器、瞬时失败不延长资格、持续断网过期与撤回不恢复均通过自动回归。实际模拟器待验收。底层请求偶发等待的原因尚未确定，本次修正的是等待策略及网络容错。
