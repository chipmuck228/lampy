# 电子册设计预览 V2：生活文集 / 影像小册

此 PR 为设计评审，不修改 App 或 EPUB 生成器，不改变购买与导出开关。
取消素纸／手作作为 EPUB 设计前提。两种方向使用相同示例内容，比较构图与阅读节奏，而非仅切换纸色。

## 查看与操作

在完整仓库内，用 Safari / Chrome 打开本目录 index.html，无需 Metro 或网络。图片引用仓库已有的 assets/first-run；演示音频位于同目录 demo.mp3。单独下载 index.html 不包含这些资源。交付下载包使用内嵌图片／音频的单文件 HTML，可离线独立打开。

- 顶部切换生活文集／影像小册。
- 切换单列阅读／双列总览，隐藏或显示设计说明。
- 点击六个版面锚点直达；保存 PDF 调用浏览器打印，打印当前方向。
- 声音版面可播放六秒合成轻音，非用户录音，不自动播放；切换方向、隐藏页面时暂停。

## 六种版面

| 版面 | 生活文集 | 影像小册 |
|---|---|---|
| 封面 | 小品牌标、完整主照片、册名与时间范围 | 放大完整主照片，下方集中的册名与时间信息 |
| 章节 | 安静的月份、年份、细线和留白 | 深绿色面、大月份，增强章节转场 |
| 短文配图 | 先文字再照片，文字带动阅读 | 先照片再文字，影像成为主角 |
| 三张照片 | 宽松的一大两小组合 | 放大主照片，收紧组合间距 |
| 长文 | 自然段连续阅读 | 更窄行宽，作为照片之间安静的文字段落 |
| 声音 | 照片、文字和原生声音区域相邻 | 照片占比更大，声音区域紧贴记录 |

## 内容与资源边界

所有文案均为虚构示例，不使用用户私人数据。照片复用仓库现有引导素材，来源与许可记录见 ../../../assets/first-run/SOURCES.md；不使用第三方照片书模板资产。音频为本次生成的六秒合成音，不伪造真实录音或波形。

照片使用 contain 保持完整与原比例；组合保持顺序。实际导出需要对不适合并列的照片回退为顺序单图。章节文案复用示例开篇，不由系统自动编造。不得截断、改写或抽取用户文字，也不得凭空生成标题、署名或照片说明。

## EPUB 实施边界

HTML 的 3:4 画板用于设计比较，不是实际 EPUB 的分页保证。生活文集优先探索流式 EPUB，保留可选择文字和调整字号。影像小册探索更精确的固定构图；是否采用固定版式仍待设计确认，不将本稿整页栅格化。原生 audio 控件由浏览器／阅读器决定外观。不保证阅读器复现画板纸色、字号或页码。

后续实施需保持 PR135 的流式写入、磁盘检查、取消、后台／锁屏／离页清理语义。验收覆盖长册名、缺图、未知日期、中英混排、不同照片比例、透明 PNG、长文、多声音、大字号、横屏与深色主题。

DOM 交互检查通过：六种样例、两方向状态与说明切换、单列阅读、设计说明开关、本地资源存在、无自动播放。交付单文件 HTML 嵌入照片及声音，ZIP 完整性检查通过。当前环境拒绝 Chromium 启动所需 socket，未完成真实浏览器截图、窄屏视觉检查或 Books 真机验收；DOM 检查不等于视觉验收。
