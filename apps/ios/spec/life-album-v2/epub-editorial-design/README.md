# 电子册版式设计 V1

本 PR 先交付可打开的六种版面设计与实现约束，等待视觉确认后再修改 EPUB 生成器。
基线：main e6dec8e（PR135）。不改变 App、付费、导出开关或已有电子册。

## 查看

直接用桌面浏览器打开本目录 `index.html`；无需 Metro、网络或构建。顶部切换素纸／手作，打印按钮可保存评审稿。示例均为虚构文字和原创 SVG 风景占位，不使用用户记录，也不引用第三方模板资产。

## 六种版面

| 版面 | 视觉规则 | 内容回退 |
|---|---|---|
| 封面 | 约半页主图，册名与时间范围，Lampy 小标 | 无照片使用文字封面；长册名自动换行，不裁字 |
| 章节 | 月份为主、细线与留白，章节照片作为探索项 | 未提供开篇就留白，不自动生成抒情文字；不得重复插入正文照片 |
| 短文配图 | 日期与感受退后，文字靠近完整照片 | 示例大字是正文首段的视觉探索，不新增标题、不自动摘要；正式映射默认保留统一正文 |
| 三张照片 | 一张主图与两张并列形成节奏 | 只有比例及阅读宽度合适才并列，否则按原顺序单图；不裁切、不跨记录混排 |
| 长文 | 稳定行宽、自然段落与舒适行距 | 分隔线只在已有语义分段适用；长文连续分页，禁止为塞满页面截断或压缩字号 |
| 声音 | 所属记录旁的安静声音区域，显示时长 | 实际使用 EPUB 原生 audio 控件，不承诺图中自定义播放器；不支持播放的阅读器明确告知，禁止自动播放 |

## 统一尺度

- 主文字墨绿灰，正文以用户阅读主题可读性为先；暖白纸色仅用于此评审画板。
- 封面减少品牌占比；正文日期和感受小于正文，不能仅靠颜色传达含义。
- 素纸保持整洁；手作仅薄照片框、轻微倾斜等探索，实际 EPUB 对不兼容效果可去除。
- 原图保持方向、比例、顺序；无裁剪授权时完整展示；透明 PNG 保留透明信息。
- 不改写用户文字、不发明记录标题、图片说明或声音转写。设计稿说明文字不导出为用户内容。

## EPUB 映射与边界

本稿以 3:4 画板表达构图，不是固定版式 EPUB 的决定。下一步优先保持流式 EPUB：章节标记、字体层级、段间距、单图与条件双图、声音区域。Books / Android 阅读器的字号、主题、分页可覆盖作者样式，因此不保证精确页码、画板比例或同页照片数量。

封面可独立构图；章节独立页、自动章节照片、正文首段放大、手作倾斜和装饰分隔线均为待确认探索。不要直接将整页栅格化，否则文字可选取、字号调整及无障碍阅读会退化。PDF 固定页面需要独立验证，不在本设计 PR 修改。

## 验收与下一步

1. 先确认六种构图、素纸与手作的克制程度；后续替换为明确授权的合成照片验证人像、横图、竖图、透明 PNG。
2. 实现后覆盖长册名、无封面、未知日期、长文、1/2/3 张不同长宽比照片、纯声音、多声音与中英混排。
3. Books 真机验证大字号、深色、横屏、目录、离线声音、照片完整与阅读顺序；不将浏览器画板截图当成 Books 验收。
4. 保持 PR135 的流式写入、磁盘检查、取消与后台／离页清理语义。
