# 阶段 B：个人生活册连续阅读

2026-10-13。独立分支 `ios/life-album-continuous-b`，基线 `cb3ecf025787a383f2bbdd79a7e1dd134b570567`（#110 普通 merge）。阶段 A 设计已由用户确认继续实施。本页区分源码自动检查、用户设备测试报告与未验证项目，不代表全部设备或发布验收通过。

## 已实现

- 「看看这一册」默认打开连续阅读，固定返回栏；「看纸页」仍打开已有纸页预览。编辑／整理与原记录入口保留。
- 全部原文，不截成列表摘要；封面、开篇、记录、收尾按册内顺序显示。照片原比例、声音明确点播，感受与不确定时间、来源缺失／读失败／后来改过的提示保留。无 AI 改写。
- 素纸／手作两种开发验收风格，默认素纸；字体请求来自同一 `ALBUM_FONTS`，纸色／照片装饰来自共同规格，感受色由原感受词解析后传至纸页，英文显示不重新猜测颜色。原生绘制 ABI 保持兼容，布局版本为 `album-a5-v4`。
- 新册自动首张当前有效照片，按册内顺序查找；无有效照片则文字。旧 `words`／`image` 选择不被自动改写；编辑中可明确改回自动封面。手选照片来源失效后显示回落，原手选意图保留。
- `cover_kind=auto` 使用现有无枚举约束字段，不改 SQL schema／migration 或 Moment；旧客户端读未知类型会回落文字，若旧客户端重新编辑此册，可能覆盖自动封面意图。数据库文件重开回归确认自动标记保留。
- 首页「我的／家里的」壳层；家里的只明确提示尚未开放，无家庭内容、创建或导出入口。已有家庭功能门控不变。
- 阅读位置／风格保存在设备 SecureStore，写入串行，纸页读偏好先等待已提交写入。位置只含内容 SHA-256、记录 ID 锚点与位置数值，不保存正文／照片 URI。内容、宽度或风格变化时回记录顶部，已删除锚点回开头；未变化时恢复偏移。横竖屏、长册恢复仍需实机。
- 连续读取不依赖 Core Text 打印测量；两次源读取核对完整输入，取消／解锁资格在 await 后复查。换册、离页、锁定与后台使旧读取失效；声音暂停，不自动复播。

## Mac／设备验收清单（逐项状态见下方设备报告）

1. 拉取此分支，按现有 iOS 构建流程重编；本 PR 改了 `LampyAlbumLayoutModule.swift`，仅重载 Metro 不足以更新纸页绘制。记录实际构建／JS SHA、设备／iOS、语言与原生模块版本。
2. 打开旧册：原收入与手选封面不变；新册收入含缺图、三张图、极长图、纯声音、长文、中英混排／emoji、同日多条、未知日期的记录。原文／照片／声音与「看纸页」逐项对照，读完收尾。
3. 两种风格：连续与纸页的纸色、照片框、感受色一致；真实字体诊断分别记录。RN Text 与 Core Text 实际字体／断行仍需验证，不承诺相同断行；Songti 请求不等于设备命中，不把浏览器字体当生产字体。
4. 连续滚至记录中部→退出／重开／杀进程重启；改原文、移动／移出记录、旋转、分屏和换风格后应回正确记录锚点，不套用旧偏移。存储失败不阻止阅读。
5. 点声音→暂停→另一段；离开、看纸页、锁定、后台均暂停，返回不自动播放。启动加载、快速换册、解锁与迟到回调不得露出另一册。
6. 短屏／横屏／iPad分屏；两种语言／长名称；常用册与大量记录、极长图的内存和滚动性能。当前连续阅读为 ScrollView，全册挂载，不能据 Jest 声称长册性能已达标；若实际压力测试失败，需进一步分块／虚拟化。
7. 系统 VoiceOver 实际阅读顺序、声音按钮与返回；Reduce Motion。当前无强制淡入、自动翻页或自动播放。后台保护遮挡须真机核对。
