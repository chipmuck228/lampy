# V2取代哪些旧规则

V1.2讨论设计为当前候选实现契约。旧life-album设计和WALK保留历史证据，不删既有实现记录；不能同时执行相互矛盾条款。

| 旧规则 | V2规则 |
| --- | --- |
| 回看右上进入生活册、不增加底带 | 保留当前三项底带，无回看重复入口 |
| 默认按纸页逐页阅读 | 手机默认连续阅读，纸页作为打印检查 |
| 整册只能一种固定旧版样式 | 共用风格规格；素纸／手作候选待完整样本审阅 |
| 用户浏览全部照片手选封面 | 新册原序首张有效图自动封面，旧手选保留，无图字封面 |
| 家庭接收快照不得成册 | 来源为当前有效家庭分享，按家庭独立聚合，不读取他人个人库 |
| 新版设计曾拟逐条成册许可 | 已取消；家庭规则一次说明，选取／全选，现有撤回收权 |
| 导入后自动建立独立收藏 | 已取消；外部成品按次只读，接收者不永久留存 |
| 预览和PDF必须逐页同版 | 打印预览与PDF同版；连续阅读同内容／风格，分页和换行不同 |
| 使用系统Songti名称即固定字体 | 候选随包合法字体需核对真实字形与嵌入；不能把回退当同版证明 |
| 正式导出仅PDF | 自包含图文声文件包＋打印PDF；包内是否含PDF仍待审 |
| 删除册子就清所有成品 | 工作册与创建者明确保存的成品分离；移出／删册不删除原记录和外部文件 |

旧sample/index.html与storyboard.html保留为#63历史稿；V2审阅使用本目录sample/index.html。阶段A不移除运行页面的手选封面或分页按钮。
