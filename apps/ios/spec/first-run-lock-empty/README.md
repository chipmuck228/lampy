### 本机 Face ID 保护（默认关）

| 设置 | 冷启动 / 回前台 | 页间跳转 | 落盘 |
| --- | --- | --- | --- |
| 未读完 | 中性遮挡，不露内容 | — | — |
| 关闭 | 立刻进 App，不弹认证 | 不认证 | enabled=false（或缺省） |
| 开启中：系统认证成功 | — | — | 这时才 enabled=true |
| 开启中：失败/取消 | — | — | 保持关闭 |
| 已开启且本会话未解锁 | 遮挡私人内容，可「再试一次」 | 未解锁不得看 | 不变 |
| 已开启且本会话已解锁 | 展示 | 不重复认证 | 不变 |
| 回后台 | 锁定本会话；停播放；切换器遮挡 | — | 不变 |
| 关闭保护：认证成功 | — | — | enabled=false |
| 关闭保护：失败/取消 | — | — | 保持开启 |

认证走 `expo-local-authentication`（系统 Face ID / 设备密码退路）。不存人脸。不改 `userId`、Apple 会话、`ownerId=local-user`、个人库路径。

改 `app.json` plugin / `NSFaceIDUsageDescription` 后需 **`npx expo prebuild --platform ios` 并重装**。Metro 热更新不算原生认证验收。

### 空库

| 表面 | 空 | 非空 |
| --- | --- | --- |
| 最近 | `getRecentLife().isFirstUse`（`listRecent` 长度为 0） | 有任意 Moment 行 |
| 回看 | `getLookbackBook().isEmpty`（年列表空 **且** `unknownCount===0`） | 有按 occurredAt 的年，或仅有未确认日期 |

读取失败、未知日期、媒体文件缺失都不得显示空库引导。第一条正式保存后两处空说明消失。最近仍按 `recordedAt`，回看仍按 `occurredAt` 与精度。
