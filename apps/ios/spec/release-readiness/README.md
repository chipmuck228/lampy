# 发布范围与缺口清单

更新日期：2026-10-11。核对基线：`eeb6d94d8bd90c2740280522270bff522d23a8f6`（#87、#105 已合并）。这是持续更新的发布台账，不是上架批准，也不是新的功能实现契约。

## 发布范围：尚需决定

建议第一版以「容易留下，重新阅读，收成生活册」为中心，保留已实现的个人记录和生活册预览；家庭是否随首版公开，是需要明确的产品决定。若公开家庭，必须完成下表中相应的账号、隐私、运维与体验缺口。也可以先发布个人版，继续通过受控 TestFlight 测试家庭。

| 范围 | 当前能力 | 首发建议／决定状态 |
| --- | --- | --- |
| 个人记录 | 文字、照片、声音、感受、草稿；最近、回看、详情；长按留下录音、主屏幕快捷操作 | 建议包含，尚未冻结首发范围 |
| 本机保护与中英文 | 系统认证盖层、固定应用字号、中英文界面 | 建议包含；固定字号为已接受策略，不重新要求系统字号缩放 |
| 生活册 | 本机创建、收集 Moment 引用、整理、封面、开篇、Core Text 分页预览 | 建议包含本机预览，不能宣传为已可导出 |
| 家庭 | 登录、昵称、邀请、Moment 分享、成员管理、转交、解散与历史状态 | 受控内部测试已开放；公开首发是否包含待决定 |
| 正式导出与付费 | 无用户 PDF 导出／系统分享闭环，无 StoreKit 商品与购买 | 建议后续独立实现；免费首发不以付费为前置，免费政策尚未确认 |
| AI、社交搜索、家庭内部邀请消息 | 不属于本轮已开放产品 | 不纳入建议首发范围 |

已接受边界：邀请由创建者通过外部 IM 分享链接或二维码；没有搜索家庭申请加入。分享对象是 Moment，不是生活册。邀请默认 7 天、1 个成功加入名额；有效历史分享对后来加入／重新加入成员可读。用户可以在不同家庭分别是创建者和成员。家庭初始上限 10，解散后清理期限 30 天。公开注册前须提供账号删除。

## 如何维护

1. 每个相关实现 PR 更新 GAPS 对应稳定编号；不要因代码合并就删除缺口。
2. 分别记录实现状态、验证状态、适用发布范围。未测标「未验证」，用户报告注明环境和 SHA 是否确认。
3. 关闭项须附实现 PR／SHA、实际检查与验收证据；撤回或回归时重新打开，保留历史。
4. 每次准备分发，记录 App 源码、原生构建、版本／Build、API 部署 SHA、数据库迁移版本和发布配置。App main 更新不代表服务器已更新。
5. 对未知能力先查源码。历史设计、Jest、AX、静态稿、健康检查、Archive 扫描各有边界，不能互相代替。
6. 不写密码、Token、邀请秘密或真实私人记录。尚未确定的价格、运营主体、渠道、政策不补造。

建议下一刀：先确认公开首发是否包含家庭，再做家庭加载测量与改进；公开账号和正式隐私说明独立切片推进。此顺序是建议，未启动实现。
