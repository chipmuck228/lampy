# 合成夹具 F

本轮改前 / 改后 storyboard、流程和验收共用这一批。**不是**真机库，也**不得**写入 Liuz17。

夹具只存在于独立、可丢弃安装。阶段 B / C 真机对照若需要预置，用一次性测试包，测完丢弃。

时间按观看者时区的日历日。`recordedAt` 与 `occurredAt` 分开写，不互相顶替。

感受词只使用现词汇或一个已知的旧词：`高兴` `平静` `感动` `疲惫` `难过` `烦乱` `说不清`，外加旧词 `温暖`（`known: false`）。

## 2. 同日多条（最近 · 记录于 10月1日）

按 `recordedAt` 新到旧，也就是最近页从上到下：

1. **F-mix** 长混合（发生于 9月28日）
2. **F-audio** 独立声音
3. **F-short** 短文字
4. **F-one** 独立照片

同一日块标题只出现一次：`记录于 10月1日`。同日相邻条之间有短浅线。**F-mix** 的发生日期不得写成记录日期。

## 4. 三种时间未确认

| ID | 范围 | precision | 条数 | 说明位置 |
| --- | --- | --- | --- | --- |
| **U-root** | `/lookback/unconfirmed` | `unknown` | 3 | 章节开头一句：时间还不能确定。不写星期。 |
| **U-year** | 2026 年，月份未确认 | `year` | 2 | 「这一年，月份未确认」 |
| **U-month** | 2026-09，日子未确认 | `month` | 2 | 「这个月，日子未确认」 |

计数口径与现 ViewModel 相同，不另算：

- 月份行 `count` = `exact` + `day` + `month`
- 日期行 `count` = `exact` + `day`
- `dayUnconfirmedCount` 只含 `month`
- `yearUnconfirmedCount` 只含 `year`
- 根上「时间未确认」= `unknown`

## 5. 空库与失败

| ID | 含义 | 最近 | 回看 |
| --- | --- | --- | --- |
| **E-empty** | 个人库无 active 记录 | 现空态「这里，留下自己的生活。」+「留下第一条」。不新增欢迎横幅或统计。 | 「以后可以按时间回来看。」 |
| **E-fail** | 读取抛错，库仍在 | 「最近的记录暂时读不出来…」可再进留下 / 设置 | 书页失败句，**不是**空库。提供重试。 |
| **E-part** | 目录成功、当天失败 | 不适用 | 目录可操作；阅读区失败 + 重试。不得清掉已展开的年月。 |

## 6. 版式夹具（同一内容，不同壳）

用 **同日四条**（§2）和 **D-dense 阅读态** 各画一帧：

| 代号 | 壳 |
| --- | --- |
| **V-xxxl** | 最大字号。最近日期轨收起；图一律纵排；触达 ≥ 48pt |
| **V-short** | 短屏（紧凑高）。底带在，首条真实记录仍在首屏 |
| **V-land** | 横屏。底带现网 rail，不新增左右双栏故事 |
| **V-ipad** | iPad 阅读列封顶，不拉成仪表盘 |

这些帧是结构稿。静态稿 ≠ 运行 PASS。
