## 1. 产品方向

Lampy 是自己的生活记录。

- **留下**轻松。
- **最近**看见刚留下的生活，便于扫读和继续记录。
- **回看**重新读一段过往，允许停留。

视觉沿用暖纸 `#F3F0E9`、墨 `#25231F`、软墨 `#5C5851`、现有图标、克制感受色点（`feeling-accent.ts`）。精致来自字形、照片比例、内容节奏和操作位置。

不要：彩色卡片、统计面板、打卡、评分、自动情绪、自动故事标题、背景音乐、装饰翻书、推荐、「为你精选」、把多条收成一段。

## 3. 两页完整流程

### 3.1 最近

```
打开 App / 底带「最近」
  → 标题「最近」+ 设置。无欢迎横幅、无统计。
  → 失败：失败句。空：现空态 +「留下第一条」。
  → 有记录：按记录日分块，首屏尽快出现真实记录。
扫读
  → 短句读完。长文看到预览和「还有正文」。
  → 图按规则纵排或组带。声直接播。感受色点属该条。
  → 「看这条」进 `/moment/:id`。播放不是进详情。
继续记录
  → 底带「留下」→ 保存 → 回到 `/`
  → 新条落在正确记录日。本次保存可淡入一次。
去回看
  → 底带「回看」`/lookback?o=` → 之后按 3.2
```

同日共享「记录于」日期。发生日不同仍单独写出。两条时间不得印成一个日期。

### 3.2 回看

```
进入 `/lookback`
  → 同进程有阅读记忆：回到那个日期和位置（目录收起）。
  → 否则：最近一个 exact/day 日子，阅读态。
  → 全无明确日：时间未确认阅读。
  → 读失败：失败 + 重试。不是空库句。
读这一天
  → 页首写一次日期和星期。
  → 按现日页顺序逐条。短条读完。长文可展开，也可「看这条」。
  → 图、声、感受仍属于原记录。
  → 条多：`hasMore` 时「继续往下看」，接在已读后面。
换一天
  → 「换一天」打开同页目录（年章节，只列有记录的年月）。
  → 同时只展开一个月。日期行：日 / 周X / 条数。
  → 点日期：目录收起，进入该日。无横滑。
  → 页尾：上一 / 下一有记录日，写出日期；没有则不画。
进详情
  → 「看这条」→ `/moment/:id` → 返回仍在该日、展开和滚动还在。
未确认
  → 三种范围保持。解释只在章节头。不伪造日期或星期。
离开
  → 底带回最近。声音暂停。冷启动下次仍从最近开始。
```

目标路径只有三步：进入回看 → 打开一天 → 连续阅读；必要时才进详情。年 / 月 / 日不再是必经跳转。旧深链仍活，见路由表。

## 4. 「最近」设计（阶段 B）

保留底带、设置、`StartupBrandLayer` 的 `homeSettled`、空态和失败句。标题区保持「最近」+ 设置，不加第二行口号。

### 4.1 一条记录

记录各自独立，不套卡片，不铺感受底色。

| 内容 | 采用 |
| --- | --- |
| 短文字 | 完整显示 |
| 长文字 | 最多 6 行（与现 `LOOKBACK_BOOK_NOTE_LINES` 同量，避免两套节奏）。截断处原句切断，不生成摘要。截断时「看这条」的可见字或辅助标签带「还有正文」 |
| 单图 | 原比例。框的 `aspectRatio` 来自图片自身 |
| 两图 | 仅当两张都可显示、且都是竖图（复用 `canPairDetailImages`）、且不是大字号 / 窄列时组带。否则纵排 |
| 三图 | 能组的两人带接在单张后（现 `detailImageBands`）。不能组则三张纵排。禁止只露一张 |
| 缺失 / 未知 | 中性说明，纵排，允许变高。不拿邻条的图补 |
| 仅声音 | 紧凑播放，可直接点 |
| 混合 | 文字 → 发生日（若有）→ 图 → 未知媒体 → 声 → 感受 →「看这条」。所属关系不拆 |
| 感受 | `RecentFeeling` 色点。未选不渲染。旧词未知色 `#8B867C` |

「看这条」继续 `LookThisHit`，低强调，≥ 48pt。整条 `View` 不是按钮。

同日：现网 `shouldShowSameDayRule` + 72pt 浅线。不同日：日块间距，不加线。

### 4.2 保存回声

见 `routes-and-state.md` §7。淡入只标刚写下的那一条。Reduce Motion 不播动画。无成功弹窗。

### 4.3 阶段 B 不碰

回看任何页面、日页、摘录上限、邻日、目录两态。不开放家庭。不改 `getRecentLife` 的 50 条窗口。

## 5. 「回看」设计（阶段 C）

`/lookback` 仍是根，底带仍在。同页两态：**目录**与**阅读**。实现顺序：先时间选择、当天阅读、返回状态；再加克制动效。动画不得掩盖读取或定位错误。

### 5.1 目录

- 简洁入口：阅读态页眉旁「换一天」（或等价低强调）。点击同页展开。
- 年份是章节，只列有记录的年和月。
- 同时展开一个月。再点已开月则收起。
- 日期行维持现网：`18日` / `周五` / `N条`。VoiceOver 用 `lookbackBookDayAccessLabel` 的完整日期。
- 根「时间未确认 · N条」、年「月份未确认」、月「日子未确认」仍在各自位置。
- 选日期或选未确认范围后收起目录，进入对应阅读。

不画七列月历、热力、安静日。

### 5.2 一天的阅读

- 页首一次：`9月27日` + `星期日`（完整，不是行内「27日 / 周五」那种目录压缩）。
- 顺序 = 现 `getHistoryDay` / `lookbackDayEntries`（`occurred-asc`，精确时刻在前）。
- 每条边界清楚：同日浅线或等价留白，不把下一条接成续写。
- 短记录直接读完。
- 长文默认 6 行，原位「展开全文」；「看这条」仍进详情。展开不是摘要。
- 图：与最近同一套组带规则。现网摘录 `images.slice(0, 1)` +「共N张」停用。
- 声：用户点了才播。与「看这条」分开。日页深链对齐，不再整行按钮、不再不能播。
- 感受：色点或现网感受行都可以，但只属于该条。回看不写叙事句。
- 条多：第一批最多 50（现 `HISTORY_PAGE_SIZE`）。`hasMore` 则「继续往下看」。取消「这一天还有 N 条 → 日页」。

页尾邻日：`上一有记录日 · 9月24日` / `下一有记录日 · 9月28日`。跨月写出月日。没有就不画。不用横滑。

### 5.3 未确认

三种范围、三种计数、三种深链都留。阅读页首用范围标题，不用假星期。说明一句放章节头，不逐条重复「时间未确认」。

### 5.4 日页深链

`/lookback/:year/:month/:day` 不删、不改成只 `return null`。阶段 C 让它渲染与阅读态同一块（含播放、展开、邻日、分批）。顶栏仍是「返回原来的位置」，无底带。离开仍写 `{year,month,day}` 意图。

这样旧冷链 `lampy:///lookback/2026/09/27` 仍是一天，不是 404，也不是只看到两条摘录。

## 6. 与当前方案的取舍

| 点 | 现网 | 曾考虑 | 采用 | 为什么 |
| --- | --- | --- | --- | --- |
| 回看主路径 | 目录常在 + 2 条摘录 + 日页 | 继续加厚摘录，或复活年页 | **同页阅读态**，目录按需打开 | 回看要停留。2 条摘录仍是索引 |
| 当天更多 | 进日页 | 日页当主阅读 | 原位分批；日页只服务深链 | 少一次必经跳转，又不删旧 URL |
| 默认日 | 不展开 | 「为你精选」 | 最近明确发生日；否则未确认 | 有东西可读，不做推荐 |
| 换日 | 点另一日期行（摘录仍夹在列表里） | 横滑 | 目录 + 页尾邻日 | 避看图 / 返回手势 |
| 最近长文 | 全文 | 自动摘要 | 6 行预览 + 还有正文 | 扫读。摘要是别人的句子 |
| 最近组图 | 全纵排 | 强制三宫格裁切 | 只在竖图且宽度够时组带 | 不裁、大字号安全 |
| 保存反馈 | 无 | 成功弹窗 / 每次刷新都闪 | 一次性淡入 | 只庆祝这次写下 |
| 限量读取 | 日 50 + `hasMore`；最近 50 无更多 | 新 `getLatestPlacedDay` / 最近分页 | **阶段 A 不加** | 现契约已够；真要加再单测同序和 count |
| 播放记忆 | Asset id，最近和摘录各一 hook | 全局单例跨详情 | 阅读树不卸播放器；记忆表照旧 | 开合目录不能重建 player |
| 冷启动 | 回最近 | 记住上回看 | 仍回最近 | 已验收政策，本轮不翻 |
