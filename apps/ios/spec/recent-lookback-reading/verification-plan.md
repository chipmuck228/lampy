# 验收与真机清单

阶段 A 只交设计。本页列出阶段 B / C 必须跑的项。

**静态稿、Jest、模拟器截图都不能写成运行 PASS。** 没做的标 `NOT VERIFIED`。每份实现 PR 写实际运行 SHA。

不得卸载、清空或重置 Liuz17。夹具 F 只进可丢弃安装。

---

## 1. 每个实现 PR 的命令

在 `apps/ios`：

1. `npx tsc --noEmit`
2. 相关 Jest，再全量 Jest
3. 改动文件 lint
4. `git diff --check`

失败要对照基线 `d5c02386ebd335948f172b487df157390f3a3d9c` 定性。不能只因为「这文件没改」就称既有。

阶段 A 自身：设计文件不进 TypeScript。合并前仍跑一次全量，证明本 PR 没有改运行代码。
