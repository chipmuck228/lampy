# 受控家庭测试账号登录

独立切片，基线 **`origin/main`（含 #42）**。只改 `apps/ios`。不叠 #41。不改微信代码。不开放家庭正式入口。`identityLoopAccepted` 保持 false。

目标是取得第二个真实可用的 Lampy `userId`，验证家庭命令和 App 流程。本轮不向公众提供邮箱注册。

Apple 与受控测试账号都在身份服务验证后签发同一种 Lampy 会话。家庭 API 仍以 `userId`、当前成员资格和分享授权为准。测试登录名可以长得像邮箱，只是账号标识，不是已验证邮箱，也不会自动合并 Apple 账号。

## 不做

- 公开邮箱注册、邮件验证、重发、忘记／重设密码、SMTP
- 按登录名／邮箱字符串自动合并账号
- 账号绑定或面向公众的账号管理
- 用删除本机个人 Moment 冒充服务端删号
- 生产库 / 生产 env / DNS / 证书变更
- 把 `/health` 200、本地测试 token 或内存账号写成真实双账号验收
