## 4. 性能

实现必须确认：

- **不监听大量 scroll。** 不要为每张照片在 `onScroll` 里算位移。用轻量视口 / 可见性，次数与照片张数同级，不要跟像素走。
- **不造成图片重复渲染。** 显现只动透明度与 8pt 位移。不要换 source、不要卸掉再挂 `Image`、不要重解码。
- **不影响播放器。** 滚动阅读、显现开始或结束，不得 pause / seek / 重建音频。声音与照片显现无耦合。

性能项没有自动化数字门槛时，实现走查写清观察（掉帧、重复 decode、误停声）。未观察则 **NOT VERIFIED**，不得写 PASS。
