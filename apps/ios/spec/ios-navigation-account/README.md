## 1. 当前真实盘点

Expo Router `Stack`，`headerShown: false`，切页 `fade`。无系统 Tab Bar，无应用内账户页。模拟器齿轮是 Expo Dev Client。

| 路由 | 页眉 | 现状离开 | 门控 |
| --- | --- | --- | --- |
| `/` | 标题「最近」；「回看」；门控「家庭」；「留下」 | 冷启动落点。保存留下后 `replace('/')` | 家庭入口仅 `isFamilyApiConfigured()` |
| `/lookback` | 「返回原来的位置」+「回看」 | `back()`；滚动 `lookback-session` | 冷启动不恢复上回看（ADR 0005） |
| `/lookback/[year]`…`/[day]`、`unconfirmed` | 返回 + 时间标题 | `back()`；滚动按 path | 无 |
| `/moment/[id]` | 钉住「返回原来的位置」 | `back()` | 分享同家庭门控 |
| `/leave` | 可见「最近」，无障碍「返回最近」 | 未保存 `back()`；保存 `replace('/')` | 无 |
| `/family`、`/share/[id]` | 「返回」 | `back()` | 入口受 API 配置门控 |

## 2. 角色

| 名称 | 是什么 | 不是什么 |
| --- | --- | --- |
| **最近** | 当前位置，也是页面标题 | 不是四个菜单里的首页图标 |
| **回看** | 另一处目的地：年 → 月 → 日 | 不是最近的筛选器 |
| **留下** | 创建动作，同一 `/leave` | 不是一级内容空间，不当 Tab |
| **详情 / 回看子页** | 读一条或一段时间 | 不铺一级菜单 |
| **家庭** | 明确分享或收到的内容 | 不得因导航方案开放入口 |
| **账户与设置** | 未来槽位，有真实能力才出现 | 现在不画假头像、空页、已同步 |

## 3. 路由与返回（可执行规则）

根页 = `/` 或 `/lookback`（恰好这两条）。子页 = 回看年/月/日/未确认、详情、留下、家庭、分享。只有根页有底带（方案 B）。

### 3.1 两个根页互切：禁止叠两层相同根

| 从 | 到 | 调用 | 禁止 |
| --- | --- | --- | --- |
| `/` | `/lookback` | `push('/lookback')` | 不要 `replace`，以便回最近时栈上的最近还在、滚动还在 |
| `/lookback` | `/` | **能返回则 `back()`**；不能（冷启动或深链只有回看根）则 `replace('/')` | **禁止 `push('/')`** |

`canGoBack()` 为真且上一帧是最近时，用 `back()`，不要再 `push` 一个最近。

**序列：最近 → 回看根 → 底带「最近」→ 再去回看**

1. 冷启动 `/`
2. 底带「回看」→ `push('/lookback')` → 栈：`/` , `/lookback`
3. 底带「最近」→ `back()` → 栈：`/` （最近仍是原实例，滚动在）
4. 底带「回看」→ `push('/lookback')` → 栈：`/` , `/lookback`

不得出现 `/` , `/lookback` , `/` , `/lookback`。

### 3.2 子页返回：打开它的那一页 + 本进程滚动

年 / 月 / 日 / 未确认 / 详情 / 家庭 / 分享：可见「返回原来的位置」，`router.back()`。

回看各 path 的滚动仍只记在 `lookback-session`（本次进程）。最近若仍在栈下，系统保留其滚动。冷启动不恢复上回看位置（ADR 0005）。

**序列**

1. `/` → `push` `/lookback` → `push` `/lookback/2026` → `push` `/lookback/2026/09` → `push` `/lookback/2026/09/27` → `push` `/moment/id`
2. 详情 `back()` → 日页（日页滚动按 path 恢复）
3. 再 `back()` → 月 → 年 → 回看根（各 path 各自的偏移）

### 3.3 冷启动或深链落在回看根

栈可能只有 `/lookback`，`canGoBack()` 为假。底带「最近」→ `replace('/')`，得到单独的最近。此时没有「原来的最近滚动」，这是冷启动，符合 ADR 0005。

深链若先进 `/` 再导航到回看，则仍走 3.1 的 `back()`。

### 3.4 「留下」：可见文案看从哪来；保存仍 `replace('/')`

现状：无论从哪进，可见返回都是「最近」，保存一律 `replace('/')`。契约把 **未保存返回** 和 **保存成功** 分开，避免稿上「返回打开它的地方」和按钮「最近」互相打架。

| 从哪 `push('/leave')` | 未保存返回 | 可见文案 | 无障碍 | 草稿 |
| --- | --- | --- | --- | --- |
| `/`（底带「留下」或「留下第一条」） | `back()` → `/` | **最近** | 返回最近 | 不保存、不删除；再进 `/leave` 仍走现有草稿恢复 |
| `/lookback`（仅根页底带） | `back()` → `/lookback` | **返回原来的位置** | 返回原来的位置，回看 | 同上 |

年/月/日 **没有** 留下入口，因此不会从子页打开 `/leave`。

**保存成功（与现码一致）**：`leave.tsx` 现为 `router.replace('/')`。无论从最近还是回看根进来，保存后都落到 **最近**，回看栈被换掉。本契约 **保持** 这条语义。若以后要「保存后回到回看」，另开产品决定，不在本稿偷偷改。

**序列 A：从最近留下后放弃**

`/` → `push` `/leave` → `back()` → `/`（草稿仍在）

**序列 B：从回看根留下后放弃**

`/` → `push` `/lookback` → `push` `/leave` → `back()` → `/lookback`

**序列 C：从回看根留下并保存**

`/` → `push` `/lookback` → `push` `/leave` → `replace('/')` → 只有 `/`

### 3.5 家庭

仅 `isFamilyApiConfigured()` 时根页出现「家庭」，`push('/family')`。返回 `back()`。未配置不画入口。

## 4. 两种可行结构（A 不是四项菜单）

四项并列「最近　回看　留下　家庭」是 **改前问题**，见稿，不是方案 A。

### 方案 A · 页顶标题 + 另一处目的地

标题表示你在哪。标题行旁边只有 **另一处** 和动词「留下」（及门控家庭）。当前页不再放同名按钮。

- 最近：标题「最近」；顶栏「回看」「留下」。
- 回看根：标题「回看」；顶栏「最近」「留下」。
- 子页：只有返回。账户槽在顶栏最末，现在空着。

### 方案 B · 阅读对 + 安静底带（采用）

标题只当书名。`/` 与 `/lookback` 底部有安静带（安全区之上，不悬浮）。当前处是文字不是按钮；另一处和「留下」是按钮。子页无底带。

`storyboard.html` 用 **同一条「门口的风还在。」、同一画幅** 并排 A / B。

### 为何仍选 B，以及代价

| 判据 | A | B |
| --- | --- | --- |
| 阅读空间 | 顶栏再占一行控件，日子更靠下（ui-round-1 已嫌 chrome 抢第一眼） | 日子紧跟标题；代价是底部少一段阅读高度 |
| 「最近」标题 vs 当前位置 | 靠「不画最近按钮」暗示 | 底带可读「最近，当前页」 |
| 可发现性 | 「回看」「留下」在顶，第一眼能看见 | 要滚或低头才看见底带；留下在空态仍有「留下第一条」补一次 |
| 最大字号 | 顶栏三项抢宽，易挤换行压住标题 | 底带允许整列 ≥48pt，不缩小系统字；代价是带变更高、内容底垫要跟着变 |
| 未来本机/账户 | 顶栏更挤 | 槽位在带尾，现在不画空入口 |

**采用 B。** 留下仍是动词；家庭不是常驻 Tab；子页一条返回。

**代价：** 实现要量底带实高并垫 `paddingBottom`；矮屏/横屏底带与内容争高，必须换行或侧收，不能缩小字号；从回看保存留下仍跳到最近（§3.4），用户可能以为会回到回看。

不采用图标 Tab Bar。

## 5. 底带空间（稿注；原生未测标 NOT VERIFIED）

底带是根页 **文档流里的固定底栏**，不是盖在 ScrollView 上的绝对浮层。内容滚动区的 `paddingBottom`（或等价 spacer）= **底带当前外接高度**（含安全区）。带变高，垫也变，禁止写死 64 然后裁切。

设计量（逻辑点，供实现对照，不是真机实测）：

| 块 | 常规 | 说明 |
| --- | --- | --- |
| 安全区顶 | 系统 inset | 标题在 SafeArea 内 |
| 内容滚动 | 其余高度 | 最后一项必须能滚到带 **上方** |
| 底带点击行 | ≥48 | 「回看」「留下」等 |
| 底带上内边 | 8 | 与内容分隔，不用满宽粗线当表格 |
| Home Indicator | 系统底 inset（约 34，视机型） | **点击行在 Indicator 之上**；Indicator 算在带高里 |
| 常规带宽 | 约 8+48+inset | 单行排得下时 |
| XXXL 纵排 | 每项 ≥48 + 间距 + inset | 三项约 3×48+间隙+inset，内容底垫同步加大 |

不得用缩小 `fontScale` 或缩小字号来塞带。带不能挡住最后一条正文、播放、或「看这条」。

稿中已画：同日两条滚到「看这条」、回看多年列表、窄屏、短屏、XXXL 纵排、横屏示意、iPad 左栏。横屏 / iPad / Home Indicator 实距 / 动态垫高：**NOT VERIFIED**。

## 6. 「账户与设置」

现在：槽位 **不画**。不留头像位，不写未登录。

家庭：仅 API 配置后出现「家庭」字，进现有 `/family`。家庭身份 ≠ 个人日记已上传。

「本机」：仅当能写真实句子（记录在这台 iPhone；权限去系统设置）才出现文字入口。

「账户」：仅未来真有个人账号能力时，同一槽改名。未交付同步不得画已备份。
