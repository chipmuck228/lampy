> 范围：只改 `apps/ios/spec/ios-navigation-account/` 的说明和对照稿。
> 基线：`origin/main` @ `217d5b9`（含 #32）。
> 本轮 **不改** 运行中导航代码、Moment / Asset、播放器、照片权限、家庭鉴权、`identityLoopAccepted`。
> 不实现账户、登录或个人记录同步。PR 保持 OPEN。

依据：`LAMPY_APP_PRODUCT_DESIGN_GUIDE.md` §8、§10、§12–13、§16；ADR `0005`、`0006`；`PHASE_0_UNIMPLEMENTED.md`。
对照稿：`storyboard.html`。

核对过的源码：`app/index.tsx`（`push` 回看 / 留下 / 详情）、`lookback-chrome.tsx`（`back`）、`lookback-session.ts`（进程内滚动）、`leave.tsx`（未保存 `back`，保存成功 **现码** `replace('/')`，契约改为 `dismissTo('/')`）、`moment/[id].tsx`（`back`）、`family-config.ts`（家庭入口门控）。
Expo Router `~57.0.22`：`canGoBack()` 只表示有历史；`replace` 只换当前页；`dismissTo(href)` 停在栈里已有的 `href`，若不在栈里则 **replace** 当前页（[Router API](https://docs.expo.dev/versions/latest/sdk/router/)）。实现切片必须在本仓库版本上走完下列序列，不能把文档当已验证。

## 1. 当前真实盘点

Expo Router `Stack`，`headerShown: false`，切页 `fade`。无系统 Tab Bar，无应用内账户页。模拟器齿轮是 Expo Dev Client。

| 路由 | 页眉 | 现状离开 | 门控 |
| --- | --- | --- | --- |
| `/` | 标题「最近」；「回看」；门控「家庭」；「留下」 | 冷启动落点。现码保存后 `replace('/')`；契约改为 `dismissTo('/')` | 家庭入口仅 `isFamilyProductEntryOpen()` |
| `/lookback` | 「返回原来的位置」+「回看」 | `back()`；滚动 `lookback-session` | 冷启动不恢复上回看（ADR 0005） |
| `/lookback/[year]`…`/[day]`、`unconfirmed` | 返回 + 时间标题 | `back()`；滚动按 path | 无 |
| `/moment/[id]` | 钉住「返回原来的位置」 | `back()` | 分享同家庭门控 |
| `/leave` | 可见「最近」，无障碍「返回最近」 | 未保存 `back()`；现码保存 `replace('/')` | 无 |
| `/family`、`/share/[id]` | 「返回」 | `back()` | 入口受 API 配置门控 |

## 2. 角色

| 名称 | 是什么 | 不是什么 |
| --- | --- | --- |
| **最近** | 当前位置，也是页面标题 | 不是四个菜单里的首页图标 |
| **回看** | 另一处目的地：年 → 月 → 日 | 不是最近的筛选器 |
| **留下** | 创建动作，同一 `/leave` | 不是一级内容空间，不当 Tab |
| **详情 / 回看子页** | 读一条或一段时间 | 不铺一级菜单 |
| **家庭** | 明确分享或收到的内容 | 不得因导航方案开放入口 |
| **账户与设置** | 未来槽位，有真实能力才出现 | 现在不画假头像、空页、已同步 |

## 3. 路由与返回（可执行规则）

根页 = `/` 或 `/lookback`（恰好这两条）。子页 = 回看年/月/日/未确认、详情、留下、家庭、分享。只有根页有底带（方案 B）。

### 3.1 `canGoBack()` 不能当「上一页是最近」

`canGoBack()` 只表示栈上还有历史，**不能**证明上一页是 `/`。回看根若从深链、分享、家庭或其它页进来，`canGoBack()` 为真时 `back()` 会回到别处。

**来源（进程内，与 `lookback-session` 同类，冷启动清空）：**

| 如何进入 `/lookback` | 记下 | 底带「最近」 |
| --- | --- | --- |
| `/` 上明确 `push('/lookback')` | `openedFrom = 'recent'` | **`back()`**，回到同一最近实例（滚动在） |
| 深链、冷启动、其它页、来源未记 | `openedFrom` 空 | **`dismissTo('/')`**，不读 `canGoBack()` |

禁止 `push('/')`。来源不明时直接去最近，不猜测上一页。

`dismissTo('/')`：栈里已有 `/` 则弹出它上面的页，停在那一页最近；栈里没有 `/` 时，本仓库文档写的是 **replace 当前页**。实现必须在模拟器上确认「没有 `/`」不会变成 `push`（部分旧 Stack 说明写过 push）。若实测是 push，来源不明改为 `replace('/')`。

### 3.2 序列甲 · 从最近进入回看

1. 冷启动 `/`　栈：`[/]`　`openedFrom` 空
2. 底带「回看」→ 记下 `openedFrom = 'recent'` → `push('/lookback')`　栈：`[/ , /lookback]`
3. 底带「最近」→ 因来源是最近 → `back()`　栈：`[/]`（同一最近，滚动在）→ 清 `openedFrom`
4. 再「回看」→ 再记来源 → `push('/lookback')`　栈：`[/ , /lookback]`

不得出现 `[/ , /lookback , / , /lookback]`。

### 3.3 序列乙 · 回看根深链（来源不明）

1. 冷启动或深链落在 `/lookback`　栈：`[/lookback]`　`openedFrom` 空（没有从最近 push）
2. 即使 `canGoBack()` 为真（下面可能是分享、家庭、未知页），底带「最近」**仍不** `back()`
3. `dismissTo('/')`　→ 停在已有的 `/`，或栈无 `/` 时替换当前回看根为 `/`
4. 没有「原来的最近滚动」。符合 ADR 0005

### 3.4 子页返回：打开它的那一页 + 本进程滚动

年 / 月 / 日 / 未确认 / 详情 / 家庭 / 分享：可见「返回原来的位置」，`router.back()`。滚动仍只记在 `lookback-session`。冷启动不恢复上回看（ADR 0005）。

`/` → push 回看根（记来源）→ 年 → 月 → 日 → 详情 → 各层 `back()` 回到打开它的那一页。

### 3.5 「留下」：未保存看从哪来；保存后要先定「再按返回去哪」

现状：可见返回都是「最近」；保存是 `replace('/')`。`replace` **只换掉当前 `/leave`**。对 `[/ , /lookback , /leave]` 会得到 `[/ , /lookback , /]`：屏幕是最近，再按返回却回到回看，而且栈上有两层最近。规格不得再写「`replace('/')` 之后栈里只有 `/`」。

**产品决定（保存后）：**

1. 人要看见刚留下的那条 → 落到 **最近**。
2. 再按返回：**不得**回到已保存的 `/leave`。
3. 若这次进程是从最近进的回看（`/` 仍在栈下）：返回 **不得**再落到回看，回看整段一起收掉，停在原来的那页最近。
4. 若最近从未进过栈（深链回看根再留下）：返回可以回到回看根（回看是这次会话的根）。

**动作：保存成功用 `dismissTo('/')`，不用 `replace('/')`。** 未保存仍 `back()`。

| 从哪 `push('/leave')` | 未保存 | 可见文案 | 保存成功 | 保存后再按返回 |
| --- | --- | --- | --- | --- |
| `/` | `back()` → `/` | **最近** | `dismissTo('/')` → 原来的 `/` | 不回 `/leave` |
| `/lookback` 且 `openedFrom = 'recent'` | `back()` → `/lookback` | **返回原来的位置** | `dismissTo('/')` → 栈下的 `/`，回看与留下都收掉 | 不回回看、不回留下 |
| `/lookback` 且来源不明 | `back()` → `/lookback` | **返回原来的位置** | `dismissTo('/')`：无 `/` 则替换 `/leave` 为 `/`，回看根仍在下面 | 回看根（须实测） |

年/月/日没有留下入口。草稿：不保存、不删除；再进 `/leave` 仍走现有恢复。

**序列丙 · 从回看进入留下再保存**（从最近进来的回看）

1. `[/]` → push 回看（记来源）→ `[/ , /lookback]` → push 留下 → `[/ , /lookback , /leave]`
2. 保存 → `dismissTo('/')` → **`[/]`**（回看与留下都不在了）
3. 再按返回：不进回看、不进留下
4. 若误用现码 `replace('/')`：会变成 `[/ , /lookback , /]`，再按返回进回看。实现切片必须证明走的是 `dismissTo`，不是这条错栈

**放弃：** `/` → `/leave` → `back()` → `/`。或 `/` → `/lookback` → `/leave` → `back()` → `/lookback`。

### 3.6 家庭

仅 `isFamilyProductEntryOpen()` 时根页出现「家庭」，`push('/family')`。返回 `back()`。未打开产品入口不画入口。设置授权 URL 不会打开该入口。

## 4. 两种可行结构（A 不是四项菜单）

四项并列「最近　回看　留下　家庭」是 **改前问题**，见稿，不是方案 A。

### 方案 A · 页顶标题 + 另一处目的地

标题表示你在哪。标题行旁边只有 **另一处** 和动词「留下」（及门控家庭）。当前页不再放同名按钮。

- 最近：标题「最近」；顶栏「回看」「留下」。
- 回看根：标题「回看」；顶栏「最近」「留下」。
- 子页：只有返回。账户槽在顶栏最末，现在空着。

### 方案 B · 阅读对 + 安静底带（采用）

标题只当书名。`/` 与 `/lookback` 底部有安静带（安全区之上，不悬浮）。当前处是文字不是按钮；另一处和「留下」是按钮。子页无底带。

`storyboard.html` 用 **同一条「门口的风还在。」、同一画幅** 并排 A / B。

### 为何仍选 B，以及代价

| 判据 | A | B |
| --- | --- | --- |
| 阅读空间 | 顶栏再占一行控件，日子更靠下（ui-round-1 已嫌 chrome 抢第一眼） | 日子紧跟标题；代价是底部少一段阅读高度 |
| 「最近」标题 vs 当前位置 | 靠「不画最近按钮」暗示 | 底带可读「最近，当前页」 |
| 可发现性 | 「回看」「留下」在顶，第一眼能看见 | 要滚或低头才看见底带；留下在空态仍有「留下第一条」补一次 |
| 最大字号 | 顶栏三项抢宽，易挤换行压住标题 | 底带允许整列 ≥48pt，不缩小系统字；代价是带变高、滚动区变矮 |
| 未来本机/账户 | 顶栏更挤 | 槽位在带尾，现在不画空入口 |

**采用 B。** 留下仍是动词；家庭不是常驻 Tab；子页一条返回。

**代价：** 矮屏/横屏底带与滚动区争高，带变高则滚动区变矮，必须换行或侧收，不能缩小字号；从回看保存后落到最近（§3.5），用户可能以为会回到回看。

不采用图标 Tab Bar。

## 5. 底带空间（一种布局；稿与实现同一条）

**选定：底带是滚动区外的固定兄弟节点，不是盖在滚动上的绝对层。**

根页列：安全区顶 → **ScrollView（flex 1）** → **底带（不滚动）**。带变高，滚动区变矮。最后一条、播放、「看这条」是滚动内容的末项，滚到底时停在滚动区下沿，也就是带的上沿。

因此 **不要** 再给滚动内容垫一整条带高。那是覆盖层才需要的。最多留内容自己的一点下边距（约 8），与带高无关。禁止写死 64 当带高，也禁止 `paddingBottom = 带的外接高度`。

对照稿按兄弟节点画（带在文档流底，不是 `position: absolute`）。实现用同一结构。

设计量（逻辑点，不是真机实测）：

| 块 | 常规 | 说明 |
| --- | --- | --- |
| 安全区顶 | 系统 inset | 标题在 SafeArea 内、在滚动区里 |
| 滚动区 | 剩余高度 = 屏高 − 顶 inset − **带的实高** | 带变高则此区变矮 |
| 底带点击行 | ≥48 | 「回看」「留下」等 |
| 底带上内边 | 8 | 与滚动区下沿分开，不用满宽粗线 |
| Home Indicator | 系统底 inset（约 34，视机型） | 点击行在 Indicator 之上；算在 **带高** 里，从而算进滚动区变矮 |
| 常规带高 | 约 8+48+inset | 单行排得下时 |
| XXXL / 放大字 | 按可用宽和文字实测：一行均分 → 四项 2×2 → 再单列 | 不因 `fontScale >= 1.3` 直接占满三行；每项触达 ≥48；不裁字、不缩小系统字 |

不得缩小 `fontScale` 或字号来塞带。验收盯：**同日最后一条的播放和「看这条」滚到底仍完整可见。**

稿中已画：同日滚到末尾、长年列表、窄屏、短屏、XXXL 纵排、横屏、iPad 左栏（左栏也是兄弟，右栏不垫带高）。横屏 / iPad / Indicator 实距 / 带变高后滚动区变矮：**NOT VERIFIED**。

## 6. 「账户与设置」

现在：槽位 **不画**。不留头像位，不写未登录。

家庭：仅 API 配置后出现「家庭」字，进现有 `/family`。家庭身份 ≠ 个人日记已上传。

「本机」：仅当能写真实句子（记录在这台 iPhone；权限去系统设置）才出现文字入口。

「账户」：仅未来真有个人账号能力时，同一槽改名。未交付同步不得画已备份。
