# iOS 导航与未来账户入口

> 范围：只交 `apps/ios/spec/ios-navigation-account/` 的设计说明和对照稿。
> 基线：`origin/main` @ `217d5b9`（含 #32）。
> 本轮 **不改** 运行中导航代码、Moment / Asset、播放器、照片权限、家庭鉴权、`identityLoopAccepted`。
> 不实现账户、登录或个人记录同步。PR 保持 OPEN，供 Codex 复审后再切实现。

依据：`LAMPY_APP_PRODUCT_DESIGN_GUIDE.md` §8、§10、§12–13、§16；ADR `0005`（回看位置与返回）、`0006`（家庭身份与个人记录隔离）；`PHASE_0_UNIMPLEMENTED.md`（无跨设备同步、无空壳宣称）。

## 1. 当前真实盘点（源码，不是愿望）

Expo Router `Stack`，`headerShown: false`，切页 `fade`。没有系统 Tab Bar，也没有应用内账户页。模拟器右上角齿轮是 **Expo Dev Client**，不是 Lampy 账户。

| 路由 | 页标题 / 页眉 | 离开与返回 | 门控 |
| --- | --- | --- | --- |
| `/` 最近 | 标题「最近」。次级：「回看」；「家庭」仅当 `isFamilyApiConfigured()`（`EXPO_PUBLIC_FAMILY_API_BASE_URL`）。主动作「留下」，空态「留下第一条」。 | 冷启动落点。保存留下后 `replace('/')`。 | 家庭入口关闭时不渲染。 |
| `/lookback` | 「返回原来的位置」+ 标题「回看」。年列表。 | `router.back()`。滚动记在进程内存 `lookback-session`。 | 无。冷启动不恢复上回看（ADR 0005）。 |
| `/lookback/[year]`、`/[month]`、`/[day]` 及 `unconfirmed` | 同一套 `LookbackScaffold`：返回 + 年/月/日标题。日页再进详情。 | 栈内 `back()`，路径在路由参数里；滚动按 path 记忆。 | 无。 |
| `/moment/[id]` | 钉住的「返回原来的位置」，内容在滚动区外。 | `router.back()`，回到打开它的最近或回看日。 | 「分享给家里」同家庭 API 门控。 |
| `/leave` | 「最近」（无障碍「返回最近」）。 | `router.back()`；保存后回最近。 | 无账户。权限在创作流内申请。 |
| `/family` | 「返回」+「家庭」。 | `back()`。 | 最近上的入口受 API 配置门控；本轮导航不得把入口做成常驻。 |
| `/share/[id]` | 确认分享。 | 「返回」。 | 同上。 |

「留下」在指南 §8.2 是 **行为，不是第四个内容空间**。回看格子只用发生时间（ADR 0005）。个人 Moment 在本机 SQLite；跨设备同步 **未实现**（`PHASE_0_UNIMPLEMENTED.md`）。家庭 Apple 身份若出现，只属于家庭空间，不是「日记已上云」。

## 2. 角色（必须分开说）

| 名称 | 是什么 | 不是什么 |
| --- | --- | --- |
| **最近** | 当前位置，也是页面标题。看见近期生活，最自然的留下入口。 | 不是四个菜单之一的「首页图标」。标题「最近」与「我在最近」要能分开读。 |
| **回看** | 生活记录的另一处目的地：年 → 月 → 日。 | 不是最近的筛选器，也不是详情的附件。 |
| **留下** | 主要创建动作，进入同一个 `/leave`。 | 不是一级内容空间，不做悬浮圆钮，不当 Tab。 |
| **详情 / 回看子页** | 读一条或一段时间。只有「返回原来的位置」。 | 不再铺 最近/回看/留下/家庭。保留现有栈与滚动恢复。 |
| **家庭** | 查看明确分享或收到的家庭内容。 | 不得因改导航而开放。无 API 配置则入口不出现。 |
| **账户与设置** | 未来稳定槽位。有真实能力才出现。 | 现在不出现假头像、假注册用户、空管理页；不暗示本机记录已同步到账号。 |

## 3. 两种可行结构

### 方案 A · 对页目的地（收束现状）

一级页用 **标题表示你在哪**，只链向 **另一处目的地**。

- 在最近：标题「最近」；sage 字「回看」（及门控下的「家庭」）；ink 动词「留下」。页上不再放一个叫「最近」的按钮。
- 在回看根：标题「回看」；sage 字「最近」（及门控「家庭」）。「留下」可在回看根保留同一动词，仍 `push /leave`，返回用栈。
- 年/月/日、详情、留下：只有「返回原来的位置」。
- 账户槽：一级页标题行最末。当前 **空着、不可点**。

好处：和现有 chrome 接近，第一刀实现小。坏处：标题和「我在这里」仍叠在同一个词上，要靠「不画当前页按钮」来区分；顶栏仍容易压住最近一天的生活（ui-round-1 已记过）。

### 方案 B · 阅读对 + 安静底带（采用）

**页面标题只负责这本书的名字；位置切换放在一级阅读页底部的安静带。**

- 仅 `/` 与 `/lookback` 有底带（安全区上，不悬浮、不挡内容）。
- 底带从左到右：
  1. **当前处**：文字，不是按钮。最近页读「最近，当前页」；回看根读「回看，当前页」。
  2. **另一处**：按钮「回看」或「最近」，≥48pt。
  3. **留下**：ink 动词，始终进 `/leave`。
  4. **家庭**：仅 `isFamilyApiConfigured()` 为真时出现。
  5. **本机 / 账户**：仅当该页有真实可陈述的能力时出现（见 §5）。现在不画。
- 页顶：最近是「最近」；回看根是「回看」。下面直接是日子或年份，不再并排四个菜单。
- 年/月/日、详情、留下、家庭、分享：**没有底带**，只有「返回原来的位置」（留下若只从最近来，文案可继续叫「最近」，实现切片再统一）。

好处：标题与当前位置分开；留下仍是动作；家庭不是常驻 Tab；子页保持一条返回和现有滚动恢复；符合指南 §8.1–8.2（底带可有，但不能是图标 Tab）。坏处：实现比 A 多一条底带，横屏/XXXL 要换行或侧栏（规则在 §6）。

**本轮选择 B。** 理由：Lampy 是翻阅自己的生活，不是四个并列功能。用户已要求把「最近」的标题和「我在最近」分开；A 只能用省略按钮暗示，B 能读出来。子页不加带，避免把年/月/日做成第二套菜单。

不采用图标 Tab Bar：会把留下和家庭做成「空间」，冷启动语义乱，也违反「图标不单独承担含义」。

## 5. 「账户与设置」：何时出现、里面是什么

### 现在（实现本导航时仍如此）

- 底带最末 **不画** 控件。不留灰色头像位，不写「未登录」。
- 家庭未配置：不出现「家庭」。
- 家庭若在测试环境配置了 API：只多一个「家庭」字，进现有 `/family`。家庭里的 Apple 测试登录仍是 **家庭身份**，文案不得写成「已同步个人日记」。

### 「本机」页 —— 有真实句子才出现

仅当页面只能陈述已存在的事实时，底带最末才出现文字 **本机**（不是剪影）：

- 个人记录保存在这台 iPhone 上；
- 相机 / 相册 / 麦克风：说明「Lampy 只在你留下时使用」，并提供打开 **系统设置** 的真实动作（系统页，不是自造权限开关）；
- 应用版本等已有信息。

没有导出、没有删号、没有云状态，就不写这些行。

### 「账户」—— 未来真有个人账号能力之后

同一槽位改名为 **账户**，仍配文字、≥48pt。页内只列当时 **已上线** 的能力（例如家庭空间所用的 Sign in with Apple）。必须同时写清：

- 家庭身份 ≠ 个人生活已上传；
- 本机 Moment / Asset 仍按 ADR 0003 / 0006 留在本机，除非另有已交付的同步 ADR 与实现；
- 不得用空列表假装「已同步的设备」。

未交付同步之前，任何账户页都不得画云、对勾或「已备份」。

## 6. 小屏、最大字号、横屏、iPad、VoiceOver

| 条件 | 规则 |
| --- | --- |
| 窄屏 / 矮屏 | 底带一项一行或自动换行，不缩小字。内容 `paddingBottom` 让出带高。不悬浮。 |
| 最大字号（约 fontScale ≥ 1.3） | 标题与底带纵向排。当前处、另一处、留下各 ≥48pt。回看年格已有纵向降级，保持。 |
| 横屏 | 底带可收到短边一侧或保持底行并可滚。主操作仍可达。本轮稿未实拍，**NOT VERIFIED**。 |
| iPad | 左栏：当前处 + 另一处 + 留下（及门控家庭 / 本机）。右栏：标题与生活。不把手机底带拉宽。本轮 **NOT VERIFIED**。 |
| VoiceOver | 标题 `header`。当前处是文本「最近，当前页」。另一处「回看，翻看更早的日子」（或反过来）。留下、家庭、本机各为独立按钮。子页返回「返回原来的位置」。图标若有，`accessible={false}`，含义在文字里。 |
| 返回 | 子页 `router.back()`。回看滚动仍按 path、仅本次进程。冷启动仍落最近。从详情回最近/日页，不重铺底带逻辑以外的栈。 |

图标可以使用低强调标记（如已有的 ›），但不能单独代替「回看」「留下」「本机」。
