# 家庭实施切片（Phase 3A 之后）

每条 PR 必须可单独审阅、带测试、只改声明范围内的代码。默认只改 `apps/ios`；共享领域变更单独成 PR 并在先决条件中写明。

**全程禁止：** mock 家庭成员、假时间线、把 `sent` 显示成「家人已收到」、未登录可加入家庭、家庭管理员替成员写私人 Moment、空库 seed。

---

## PR-F0 — 共享领域提案落地（仅当 F1 需要新聚合时）

**先决：** 用户已决定账号方案中「是否要 Family / Membership / Invitation 进根目录 `domain/`」，以及 Transmission 是否增加家庭目标。

**做：** 领域实体、校验、命令、不变量测试。不改微信页面，不改 iOS UI。

**测：** 根目录 `test/` 新用例：非法成员、空 familyId、received origin 三件套。

**不得伪造：** 网络送达、邀请推送。

若决定家庭先只活在 iOS application（不推荐，双真相风险），必须另写 ADR 说明为何暂不进共享领域。

---

## PR-F1 — 真实身份与成员

**先决：** 账号/同步候选已选定（ADR 0006）；若领域要新聚合，PR-F0 已合并。

**做：** 登录/登出或等价会话；Account 与 `local-user` 迁移计划的**可执行第一步**（至少：未登录保持个人闭环；已登录写入真实 `ownerId` 而不丢旧行）。Membership / Invitation 存储。无家庭时间页、无分享按钮也可。

**自动化：** 未登录不能 Invite/Accept；重复接受幂等；损坏成员行走 quarantine、不覆盖。

**模拟器：** 登录失败时个人最近/留下/回看仍可用。

**真机：** 真实账号弹窗（Sign in with Apple 等）必须真机；未跑不得写已验证。

**不得伪造：** 通讯录好友、预置「爸爸妈妈」成员。

---

## PR-F2 — 权限校验

**先决：** PR-F1。读取 API 只在 Membership 有效时返回家庭范围 id 列表。

**做：** application 层授权：谁可读哪次 Transmission / 哪条 Received Moment。个人 `getRecentLife` / 回看仍只看本人个人记录。缓存令牌过期 = 家庭范围拒绝，不是继续展示。

**自动化：** 非成员读家庭 id → 拒绝；退出后家庭列表为空；本机残留行不能让 API 返回 authorized。

**模拟器：** 无网时家庭入口为「授权未确认」，个人记录仍在。

**真机：** 会话过期。未跑不得写已验证。

**不得伪造：** 用 `visibility === 'shared_space'` 当通过。

---

## PR-F3 — 明确分享

**先决：** PR-F2；用户能看见目标家庭名称（来自真实 Membership，不是占位）。

**做：** 详情在内容之后提供「分享到家庭」；确认文案按产品指南（含不验证亲属关系）。Use case 写 Transmission；失败留在个人；幂等键含 family + moment + revision。

**自动化：** 对齐并扩展 `passMoment`：无 id 不写；非 owner 拒绝；非 active 拒绝；连点一条；草稿不分享。

**模拟器：** 确认 / 取消；失败文案不含「已收到」。

**真机：** 无网分享只出现「已记下意图」或等价，不出现已送达。

**不得伪造：** 自动分享、默认勾选家庭。

---

## PR-F4 — 接收与快照

**先决：** PR-F3；快照形成时机与 Asset 复制/引用已决定（否则本 PR 只收发送者出站，不开放家庭页）。

**做：** ReceiveShare 物化 Received Moment；部分媒体失败原位降级；精确 id 打开接收详情。

**自动化：** 同一 transmission 不重复物化；revoked 在物化前到达则不建 Moment；缺失图不删快照。

**模拟器：** 第二份测试身份或夹具服务（必须是测试账号，不是写死家人姓名）。

**真机：** 两台设备或一个账号 + 测试接收端。未跑不得写已验证。

**不得伪造：** nearby-mock、把发送者原 Moment 直接插进接收者列表。

---

## PR-F5 — 撤回 / 退出及失败恢复

**先决：** PR-F4；退出与撤回后快照策略已决定。

**做：** RevokeShare、LeaveFamily、RemoveMember（若角色已定）。超时对账、离线重试、进程重启重放。成员变化后飞行中的 Receive 落地再鉴权。

**自动化：** 幂等撤回；重启不重复 Transmission；资格失效后接收失败且不覆盖旧个人数据。

**模拟器：** 杀进程后再试分享/撤回。

**真机：** 飞行模式与恢复。未跑不得写已验证。

**不得伪造：** 撤回成功但家庭页仍用旧缓存当现授权。

---

## PR-F6 — 家庭时间页

**先决：** PR-F5 或至少 PR-F4 + 只读有效分享；`FamilyTimelineViewModel` 只含有权读取的真实条目。

**做：** 一级「家庭」：按时间与来源组织；空状态说明本人如何分享，不诱导邀生人；读取/Transmission 失败可重试。无热度、点赞、在线、推荐成员。

**自动化：** 空库无 mock；无权条目不出现；媒体缺失原位降级；指定 id 不存在不回退。

**模拟器：** 空 / 一条真实分享 / 失败重试。超大字号纵向可读。

**真机：** VoiceOver 范围（个人 vs 家庭）可区分。未跑不得写已验证。

**不得伪造：** 用个人最近列表换标题当成家庭。

---

## 建议顺序

```text
（可选 PR-F0 领域）→ F1 身份成员 → F2 权限 → F3 分享 → F4 接收快照 → F5 撤回退出 → F6 时间页
```

F6 不得早于 F2。没有 F3/F4 的「家庭页」只能是空状态 + 说明能力未接上，仍禁止假条目。
