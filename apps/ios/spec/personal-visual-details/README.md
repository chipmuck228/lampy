# 个人视觉细节：感受点缀、回看日期行、首次引导

独立分支 `ios/personal-visual-details`，基线 `origin/main`（含 #47 `e7580e3`）。只改 `apps/ios`。家庭入口关闭。不推进 AI 回眸。不改个人保存、草稿恢复、时间精度、播放状态机、本机保护与引导完成语义。

Lampy 是轻盈、私密的生活记录。颜色和构图只作辅助，不解释情绪好坏，不暗示云备份或同步。

## 最近 · 感受色点

只在「最近」条目上使用。详情、回看摘录、留下选择器仍用原来的文字感受，避免共享组件被连带改版。

- 有感受：文字旁一颗约 7pt 的圆点，与文字垂直居中。
- 整条记录不加底色、卡片边框、彩色分隔或评分条。
- 阅读顺序仍是文字/照片 → 声音 → 感受 → 看这条。
- 未选感受：无色点、无「缺省感受」、不要求补选。
- 未知旧词：原词照显示，配中性色点，不改写存储。
- 色点 `accessible={false}`，朗读仍是「当时的感受，{词}」。

浅纸底 `#F3F0E9` 上的实际色值（低饱和、相近明度，不按红绿好坏排）：

| 词 | 色值 | 用意 |
| --- | --- | --- |
| 高兴 | `#C4A06A` | 暖蜜，不是「好」 |
| 平静 | `#6F8B86` | 灰青 |
| 感动 | `#B0898C` | 灰玫瑰 |
| 疲惫 | `#9A8B78` | 灰褐 |
| 难过 | `#7A8494` | 灰蓝，不用鲜红 |
| 烦乱 | `#A38472` | 灰陶 |
| 说不清 | `#8A8680` | 中性石色 |
| 未知旧值 | `#8B867C` | 中性灰褐 |

感受文字保持 `#5C5851`。色点不承担唯一信息。

## 回看 · 日期行

C′ 时间书页、月份展开、精确 ID、摘录、「还有 N 条」、定位与滚动恢复不动。三类时间未确认入口仍是独立文案，不套成某日。

展开月份里的日期行：

- 主：`18日`；次：`周五`（月份已在上行）。
- 右侧浅底标签写 `1条`，无粗边框；旁边是现有展开/收起符号。整行 ≥ 48pt 可点，标签不是按钮。
- VoiceOver：`2026年9月18日，星期五，有1条记录，已展开/已收起`。
- 大字号可折成两行，不裁字、不缩字号。
- 不加七列月历或筛选。

## 首次三屏

文案是本轮新写，不是网站原句。检查后不含云备份、同步、家庭已开放。

| 屏 | 标题 | 说明 | 构图 |
| --- | --- | --- | --- |
| 1 | 一句话，也值得留下。 | 一张照片，一段声音，或此刻的感受。 | 示意字条、照片局部色块、声音短柱 |
| 2 | 那些平常的日子，后来都有了模样。 | 再读一句原话，再听一次当时的声音。 | 示意日期 + 一句摘录 |
| 3 | 自己的生活，安心放在这里。 | 记录保存在这台设备，也可以开启本机保护。 | 少元素；开始动作在按钮 |

最后按钮仍是「留下瞬间」。示意标明「示意，不是你的记录」。不读个人库。构图只用纸色/墨/青，不用外网照片。

动效：短淡入、约 8pt 上移，跟着手动翻页或「继续」。不自动翻页，不藏按钮。Reduce Motion 或查询未完成/失败时静态展示。失焦或卸载先停动画，再把 opacity 置 1、位移置 0，避免半透明场景留在前台。

擦除已用过的模拟器 **不够** 清掉 `lampy.first-run.v1`。要看三屏，须 **新建** 模拟器（或该机自己的空 Keychain）。不要在 Liuz17 上重置完成标记。

交互：上滑与页内滚动仍分开。只有最后一步写引导完成。中途退出不提前完成。已有记录或读库失败仍跳过。不加「重置首次使用」。

走查与截图见 `WALK.md`、`shots/`。
