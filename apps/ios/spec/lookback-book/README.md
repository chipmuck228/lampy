## 1. 三个方案（同一信息，不同页）

产品指南 §4.2「记录要轻，回看要深」，§9.4「从一年回到某一天」：看见疏密 → 日期节奏而不是缩略图墙 → 当天自然组合 → 打开一条 → 返回仍在原年/月/日与滚动。§10.4 历史空间叫「回看」，不是档案库或数据库。

| | **A · 当前 main** | **B · PR #36** | **C · 时间书页候选** |
| --- | --- | --- | --- |
| 回看根 `/lookback` | 年列表 + 时间未确认 + #34 底带 | 同 A | **连续阅读页**。年份是章节，不是再点进一页才开始读 |
| 年 | `/lookback/:year` 三列或列表 | 同左，可展开一个月 | 根上的章节。`/lookback/:year` **replace** 成同一书页滚到该年，不另开一张年网格页 |
| 月 | `push` 七列月历 + 有记录的日子 | 年页展开日期列表；月路由 **replace** 到年页 | 展开**一个月**：先定位，再读当天。同时只开一个月 |
| 日 | `push` 日页，整条进详情 | 仍 `push` 日页 | 选中**一个日期**后，月历（或日期行）**下方**出现当天可辨认内容。同时只开一个日期 |
| 一条 | 日页整条可点 → `/moment/:id` | 同 A | **「看这条」** → 精确 ID。音频与「看这条」分开点 |

C 的禁止项：统计仪表盘、完成率、热力图、卡片墙、把多年多个月同时拉成无限手风琴。

C 不是「少跳一页」的 B。B 展开之后仍是日期索引；C 展开之后要能**认出当天留下的东西**。

## 3. 月历在 C 里帮不帮定位

### 3.1 稀疏月（真图 S）

A 的月页为看 1 天，先铺满整月安静格：`../lookback-month/shots/iphone16-lookback-month.png`。

把同一张七列嵌进 C 的书页：安静格仍然占去首屏，当天正文被推到折线以下。**稀疏月里月历不帮定位，只重复 A 的税，还抢阅读高度。**

### 3.2 密集月（无真图，只算高度）

393pt 竖屏，书页已有返回、年章节、月份行之后，大约还剩 ~520pt。

| 展开后先画什么 | 大约高度 | 留给当天内容 |
| --- | --- | --- |
| 七列月历（星期行 + 5～6 周 × 44pt） | 260–310pt | **约 210–260pt**：长文、三图、图文声都折到屏外 |
| 只列有记录的日子（例如 20 行 × 48pt） | ~960pt | 若不先选日期就**没有**内容区；要先滚完索引 |
| 有记录的日子（2 行，态 D）+ 当天预览 | ~96pt + 正文 | 正文能留在首屏 |

结论：**密集月里七列月历对「星期几」有用，但对 C 存在的理由（读当天）有害**——定位和阅读叠在同一屏，阅读必败。不能只因为「少跳一页」就定稿嵌套月历。

### 3.3 C 的两个变体（必须一起看）

| | **C-cal**（题面原案） | **C′ 书页**（推荐） | **C″ 月历后收成一行** |
| --- | --- | --- | --- |
| 展开月 | 轻量七列一直留着 | **只列有记录的日子** + 日子未确认；日期行写「9月27日 · 星期日」 | 先七列；选定日期后月历**收成**「9月 · 27日周日 · 换一天」 |
| 选定日 | 月历下方预览 | 日期列表下方预览 | 芯片下方预览，月历让位 |
| 稀疏月代价 | 安静格税 + 正文折下 | 几乎没有安静格 | 先看安静格，点一次才让位 |
| 密集月代价 | 星期清楚，正文折下 | 失去网格疏密；20 个日期要先选再读，不把 20 行和正文同时铺开 | 多一步「换一天」；状态比 C′ 多 |
| 最大字号 | A 已证 `fontScale >= 1.3` 不画七列 | 与现 XXXL 月页同一信息 | 大字号本来没有月历，「换一天」变成日期列表 |

**推荐 C′。** 放弃 C-cal：它在真稀疏年重复 A 的税，在假设的密集月把阅读挤出首屏。C″ 只在「必须先看星期网格」时值得做；本库没有密集月真图证明这个必须，不把它当本轮定稿。星期信息用日期行的「星期日」写出，不花 300pt 画空格。

B 已经用日期列表解决了稀疏月跳转，但**停在索引**。C′ 接过这个索引，在下面读当天。

## 4. 必须覆盖的状态

条数口径与现 ViewModel 相同，三案都不另算：月份 `count` = `exact`+`day`+`month`；日期格 / 日行 = `exact`+`day`；`dayUnconfirmedCount` 只含 `month`；`yearUnconfirmedCount` 只含 `year`。

| 状态 | 真含义 | A | B | C′ |
| --- | --- | --- | --- | --- |
| **空月** | 无日精度、也无月精度 | 年格安静，不可点 | 不可展开 | 章节里该月不可展开 |
| **稀疏月** | 态 S：一天一条 | 整页月历 + 一行日期 | 展开后一行日期 | 展开后一行日期 + **该条预览** |
| **密集月** | 多日有留下（无真图） | 月历看星期 | 长日期列表，仍进日页才读 | 日期列表作定位；**只展开一天的预览**，不把整月正文拉成墙 |
| **同日多条** | 态 D：27 日 11 条 | 日页逐条 | 日期行「有11条」→ 日页 | 预览最多 **2 条**；「这一天还有 N 条」进现有日页 |
| **空月以外的空年** | 无月、无年精度 | 「这一年还没有留下什么。」 | 同 A | 该年章节一句中性空说明，不占展开 |
| **多年** | 根上多年 | 根是年列表，一次进一年 | 同 A | 根上按年新到旧连续章节；**不**默认展开任何月 |
| **长文** | 正文超过预览 | 日页可滚完 | 同 A | 6 行截断 + 「继续阅读」（进日页该条位置或详情，见 §5） |
| **三张照片** | 一条最多三图 | 日页原比例可滚 | 同 A | 预览 **第 1 张** + 「共3张」；其余只在日页 / 详情 |
| **图文声混合** | 文字、图、声、感受 | 日页整条可点（声在条内） | 同 A | 层次同「最近」：正文 → 图 → 声 → 感受 → **看这条**。声与看这条 **不是**同一块 |
| **媒体缺失** | 未知 Asset | 日页中性缺失，不补图 | 同 A | 预览同一句中性缺失，不拿别的记录顶上 |
| **最大字号** | `fontScale >= 1.3` | 年、月已是列表 | 月行下挂日期 | 无三列、无七列；章节 + 日期 + 预览竖排 |
| **窄屏** | 内容宽格子 < 44pt | 不画三列 / 七列 | 同左的列表路径 | 同列表路径 |
| **横屏 / iPad** | #34 未走 | 结构示意 | 结构示意 | 仍是一本书页、一个月、一个日期。**不**并排两年、**不**把月历当桌面小组件。**NOT VERIFIED** |
| **year 精度** | 月份未确认 | 年页、月份区域外 | 同 A | 落在**该年章节、月份列表之外** |
| **month 精度** | 日子未确认 | 月页顶上 | 展开区独立行 | 展开月的独立行，不写成某一天 |
| **unknown** | 时间未确认 | 回看根 | 同 A | 书页最前（底带之上的阅读流顶部），不进任何年章节 |

### 4.1 能读月精度 ≠ 留下能写月精度

回看**必须读**已有 `occurredAtPrecision` 为 `year` / `month` / `unknown` 的记录（ADR 0005）。

留下页只有「今天 / 某一天 / 时间不确定」。`resolveOccurredPatch` 只写 `day` | `unknown`。**当前 UI 不能创建 `month` 或 `year`。**

| | 读 | 写（留下） |
| --- | --- | --- |
| `day` / `exact` | 年、月、日、书页预览 | 可以 |
| `unknown` | 根上「时间未确认」 | 可以（时间不确定） |
| `month` | 「日子未确认」 | **不能**。验收用 repository `save`，或隔离夹具。用户路径 **NOT VERIFIED** |
| `year` | 「月份未确认」 | **不能**。同上 |

本对照不发明留下页的月/年选择器，也不改精度枚举。

### 4.2 C′ 当天预览上限

预览是书页上的**摘录**，不是第二张日页。

| 元素 | 上限 | 超出时 |
| --- | --- | --- |
| 当天展示条数 | **2** | 「这一天还有 N 条」→ 现有 `/lookback/:year/:month/:day` |
| 一条正文 | **6 行**（约 20 / 28） | 「继续阅读」→ 该条 `/moment/:id`（精确 ID，不是猜） |
| 一条照片 | **1** 张，可写「共3张」 | 日页或详情看齐 |
| 声音 | 紧凑控件，最小 44pt | 不在预览里展开波形墙 |
| 感受 | 跟在内容后，一行 | 不截成标签云 |

「继续阅读」与「看这条」若指向同一条，只保留 **看这条**（进精确 ID）。「这一天还有 N 条」才进日页。

### 4.3 声音：互不误触，不宣称已验证播放

- 播放/暂停与「看这条」是两个控件。预览**不得**整块 `Pressable` 包住声音（现日页整条可点，**不能**原样搬进 C′）。
- 展开月、收起月、换日期、滚走再滚回：**不得**在本设计稿或后续实现说明里写「播放已保持 / 已停止 / 已验证」。这些是 **NOT VERIFIED**，要另开带听筒的走查。
- 不改播放器状态机，不改最近页的 `recordedAt` 分组。

## 5. 路由与栈（不要 `canGoBack()` 猜来源）

签发规则沿用 #34：进程内 token。`canGoBack()` 只表示有历史，不能证明上一页该回最近、回看根，还是分享页。

### 5.1 页面是什么

| 路由 | A (main) | B (#36) | C′ |
| --- | --- | --- | --- |
| `/lookback` | 年列表 · 有底带 | 同 A | **书页** · 有底带 · 年份章节 |
| `/lookback/:year` | 年网格 | 年网格 + 展开 | **同一书页** `replace`，滚到该年。不保留一张独立年网格 |
| `/lookback/:year/:month` | **月历页** | `replace` → 年页并展开该月 | **同一书页** `replace`，该月展开。不再画必经月历页 |
| `/lookback/:year/:month/:day` | 日页 | 日页 | **日页保留**（当天全文 / 分页 / 旧深链） |
| `/lookback/unconfirmed` | 未知精度列表 | 同 A | 同 A |
| `/lookback/:year/unconfirmed` | 年精度列表 | 同 A | 同 A |
| `/lookback/:year/:month/unconfirmed` | 月精度列表 | 同 A | 同 A |
| `/moment/:id` | 精确 ID | 同 A | 同 A |

未确认路由**全部保留**。精度桶不是「某一天」，不塞进书页预览当一天。

旧书签 / 系统分享里的 `/lookback/2026/09` 必须仍能打开，语义改为「书页 + 9 月已展开」，不是 404，也不是空白跳板页留在栈上。

未确认、拼错、没有的年/月/日：沿用现文案（没有这一年 / 这个月暂时读不出来 / 日历上没有这一天），不发明新的「兼容首页」。

### 5.2 五条路径的页面与栈意图

`[` `]` 里是**意图中的可读表面**，不是 Expo 内部数组的保证。冷启动深链常常只有被打开的那一层。

#### 从最近进入回看

| | 栈意图 | 书页/根上「返回原来的位置」 |
| --- | --- | --- |
| A | `[最近, 回看根]` | 签发 `o=` 且上一页是最近 → `back()`；否则 `dismissTo('/')` |
| B | 同 A | 同 A（#36 未改根） |
| C′ | `[最近, 书页]` | **同一套根签发**。书页就是回看根 |

#### 打开旧月深链 `/lookback/2026/09`

| | 落地 | 返回 |
| --- | --- | --- |
| A | 月历页。冷启动栈上往往**没有**年页 | 现码 `router.back()`。无上一页时落点**未用签发写死** → 本对照标 **A 缺口 / NOT VERIFIED 为产品意图**，不是 PASS |
| B | `replace` 到年页 + 9 月展开；不留空月页 | 有可信上一页 → `back()`；**冷启动 / 来源未记 → `dismissTo('/lookback')`**。不经过月历，不读 `canGoBack()` |
| C′ | `replace` 到书页（URL 可以仍是 `/lookback/2026/09` 或收到 `/lookback` + 进程展开）。**栈上只有书页这一层阅读面** | 有最近签发且上一页是最近 → `back()` 到最近；**否则 `dismissTo('/')` 不得已时先 `dismissTo('/lookback')` 若书页 URL 不是根**。推荐：月深链落地后 URL **就是书页态**，返回与根相同——有最近来源回最近，无则 `dismissTo('/')`。**禁止**先回到一张月历 |

C′ 月深链若 `replace` 后 URL 仍带 `/2026/09`，则「返回」离开的是带状态的书页，不是再剥一层年页。不要为了兼容再 `push` 年页。

#### 打开日深链 `/lookback/2026/09/24`（或 27）

| | 落地 | 返回 |
| --- | --- | --- |
| A | 日页 | `back()`。冷启动上一页不明 | **NOT VERIFIED 产品意图**：无签发时应落到月页或回看根，现码未写死 |
| B | 日页 | `back()` → 年页且该月仍展开（进程内）。冷日深链无年页时 **不得**用 `canGoBack()`；应 `dismissTo` 年页或回看根并带上展开月（#36 走查的是「日页从年页打开再回」，不是任意冷日链） |
| C′ | **日页**（兼容旧链，给全文） | 有「从书页来」的签发 → `back()` 到书页，**该月仍开、该日仍选**；冷启动 → `dismissTo('/lookback/2026/09')`（书页 + 9 月展开 + 选中该日）。**不**猜最近 |

#### 从详情返回

| | 若从日页整条进入 | 若从 C′「看这条」进入 |
| --- | --- | --- |
| A/B | `back()` → 日页，滚动进程内 | — |
| C′ | 同左（「还有 N 条」进的日页） | `back()` → 书页，月与日仍是进详情前的选择。详情不写回看展开态 |

详情永不 `canGoBack()` 选择「最近还是回看」。来源只看这一次 `push` 的签发或栈上一层是否就是打开它的那页。

#### 冷启动深链再返回

冷启动清空：展开月、选中日、滚动偏移、签发 token（与 `lookback-session`、#34 `o=` 相同）。

| 冷打开 | A | B | C′ |
| --- | --- | --- | --- |
| `lampy:///lookback` | 回看根，无展开 | 同 A | 书页，**无**默认展开月 |
| `…/lookback/2026` | 年页 | 年页，无默认展开 | 书页滚到 2026，无展开月 |
| `…/lookback/2026/09` | 月历 | 年页 + 展开 9 月；返回 `/lookback` | 书页 + 展开 9 月；**无选中日**；返回按 §5.2 月深链 |
| `…/lookback/2026/09/24` | 日页 | 日页；返回见上 | 日页；返回书页 + 展开 9 月 + 选中 24 |
| `…/lookback/unconfirmed` 等 | 该未确认页 | 同 A | 同 A；返回书页对应章节，不猜 |

`exp+…/--/lookback` 会把路径当成 Metro bundle，**不是**回看深链。运行中用 `lampy:///` 三斜线；杀死后 `lampy://` 可能被 Expo Go 抢走——实现走查写，本设计不当成已验收。

### 5.3 进程内恢复 vs 冷启动

| 状态 | 进程内（书页未卸） | 冷启动 / 杀进程 |
| --- | --- | --- |
| 展开的那一个月 | 记住；从日页、未确认、详情 `back()` 后仍开。同时只准一个月 | 丢掉，除非 **这一次 URL** 就是月深链 |
| 选中的那一天 | 记住；换月则清空选中日 | 丢掉，除非从日深链返回时按 §5.2 写入，或 URL 仍带日 |
| 滚动偏移 | 记住（ADR 0005） | 丢掉，从顶部（或年深链的章节锚点）开始 |
| 音频是否在播 | **不写进恢复契约** | 不恢复 |

换一个可展开月：旧月收起，旧日选中丢掉，不把旧月的日期行或预览闪一帧在新月上（#36 已有「禁止画错月」的实现教训，C′ 若做要实现同一条）。

## 6. 推荐与放弃

### 采用：**C′ 时间书页（无嵌套七列）**

1. §4.2 / §9.4 要的是读当天组合，不是再收集一次日期。A 把阅读放在第四层；B 放在第三层仍是索引。只有 C′ 在回看根上读。
2. 本库真年是「一格有点、十一格安静」（`iphone16-year.png`）。A 再收一张满月安静格税。C-cal 把税搬进书页。C′ 只为有记录的日子付钱。
3. 月历的星期价值在密集月，但密集月正是预览最需要高度的时候。用日期行写星期，把高度留给 6 行正文和一张图。
4. 日页不删：同日 11 条、长文、三图、分页（`HISTORY_PAGE_SIZE`）仍有去处。书页不是卡片墙。
5. 未确认精度、最近、家庭、Moment 形状不动。

### 放弃 A 作为长期阅读模型

A 作为**现网基线**保留到有实现 PR。放弃的是「回看 = 年→月历→日→详情」这条档案走廊：稀疏年跳转税已由真图证明；日页整条可点也过不了 C 的声/详情分控。不是否定年/月/日数据模型。

### 放弃 B 作为产品定稿（#36 仍 OPEN）

B 诚实减少了月历跳转，走查过展开与深链，但是：

- 展开区没有可辨认内容，「有11条记录」仍要再跳日页；
- 年仍是单独一页，回看根仍是目录，不是书；
- #35 写「采用 B」是相对于当时只有 A/B，**没有**把阅读预览画完。

少一跳不是定稿理由。B 留下当备选：若复审认为书页一次改不动，可以先并 #36 只切跳转，**但不得把 #36 宣传成时间书页**。本轮建议：**先复审 C′，再决定 #36 关或并。**

见 §3。C-cal 在真数据上伤害阅读。C″ 多一套开合，等有密集月真用户再议。
