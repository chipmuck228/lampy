## 1. 三个方案（同一信息，不同页）

产品指南 §4.2「记录要轻，回看要深」，§9.4「从一年回到某一天」：看见疏密 → 日期节奏而不是缩略图墙 → 当天自然组合 → 打开一条 → 返回仍在原年/月/日与滚动。§10.4 历史空间叫「回看」，不是档案库或数据库。

| | **A · 当前 main** | **B · PR #36** | **C · 时间书页候选** |

| 回看根 `/lookback` | 年列表 + 时间未确认 + #34 底带 | 同 A | **连续阅读页**。年份是章节，不是再点进一页才开始读 |

## 3. 月历在 C 里帮不帮定位

### 3.1 稀疏月（真图 S）

A 的月页为看 1 天，先铺满整月安静格：`../lookback-month/shots/iphone16-lookback-month.png`。

把同一张七列嵌进 C 的书页：安静格仍然占去首屏，当天正文被推到折线以下。**稀疏月里月历不帮定位，只重复 A 的税，还抢阅读高度。**

### 3.2 密集月（无真图，只算高度）

C′ 的 `/lookback` 与现网根页同一套壳：`LookbackScaffold` `root` **没有**顶部「返回原来的位置」，有 #34 底带（`NAV_BAND_HIT` 48 + 底安全区）。A／B **子页**真图上的「返回原来的位置」是子页导航，不画进 C′ 根帧。

iPhone 16 393×852 竖屏，根页阅读列大约：

`852 − 状态/顶安全区(~59) − 标题块(~52) − 底带与底安全区(~82) ≈ 660pt`

再扣年章节行 + 月份行（~80pt）后，日期与摘录大约 **580pt**。先前按「顶返回 + 无底带」估的 ~520pt 作废。

| 展开后先画什么 | 大约高度 | 留给当天内容 |
| --- | --- | --- |
| 七列月历（星期行 + 5～6 周 × 44pt） | 260–310pt | **约 270–320pt**：长文、三图仍容易折出首屏 |
| 只列有记录的日子且预览贴在列表最底（例如先 20 行） | ~960pt 日期 | 选中月中段时，要先滚完上面所有日期才看见摘录 |
| 有记录的日子 + **预览紧跟选中日** | 选中行以上可滚走 | 摘录跟在该日下面，换日时滚进可视区 |

结论：**密集月里七列月历对「星期几」有用，但对 C 存在的理由（读当天）有害**。日期列表若把摘录放在整月之后，同样逼用户先滚完索引。C′ 定死：预览只插在**当前选中日期行正下方**；其他日期仍是一行；换日则旧摘录收起、新摘录进入可视区域。不能只因为「少跳一页」就定稿嵌套月历。

### 4.1 能读月精度 ≠ 留下能写月精度

回看**必须读**已有 `occurredAtPrecision` 为 `year` / `month` / `unknown` 的记录（ADR 0005）。

留下页只有「今天 / 某一天 / 时间不确定」。`resolveOccurredPatch` 只写 `day` | `unknown`。**当前 UI 不能创建 `month` 或 `year`。**

| | 读 | 写（留下） |
| --- | --- | --- |
| `day` / `exact` | 年、月、日、书页预览 | 可以 |
| `unknown` | 根上「时间未确认」 | 可以（时间不确定） |
| `month` | 「日子未确认」 | **不能**。验收用 repository `save`，或隔离夹具。用户路径 **NOT VERIFIED** |
| `year` | 「月份未确认」 | **不能**。同上 |

本对照不发明留下页的月/年选择器，也不改精度枚举。

### 4.2 C′ 当天预览：位置、顺序、数量

预览是书页上的**摘录**，不是第二张日页。静态稿不是运行中 PASS。

**位置（密集月也一样）**

- 摘录**紧跟当前选中的日期行**。
- 未选中的日期各占一行，行下没有摘录。
- 换日：旧日摘录收起；新日摘录插在新日期行下，并**滚进可视区域**。不要求先滚过该月其余日期才看见摘录。
- 「日子未确认」仍在日期列表之上，不是某一天，不挂摘录。

**顺序与条数**

与现有日页同一份列表：`getHistoryDay` → `projectHistoryDay` → `compareListedMoments`（有 `exact` 时刻的按 `occurredAt` 升序，其余按 `recordedAt` 升序）。书页取这份列表的**前 2 条**。不按最近页的 `recordedAt` 分组重排。

| 元素 | 上限 | 超出时 |
| --- | --- | --- |
| 当天展示条数 | **2** | 「这一天还有 N 条」，**N = 当天总条数 − 实际展示条数**（11 条展示 2 则 N=9）。进入现有 `/lookback/:year/:month/:day` |
| 一条正文 | **6 行**（约 20 / 28） | 截断。该条只留「看这条」 |
| 一条照片 | **1** 张，可写「共3张」 | 其余在日页或详情 |
| 声音 | 紧凑控件，最小 44pt | 不在预览里展开波形墙 |
| 感受 | 跟在内容后，一行 | 不截成标签云 |
| 媒体缺失 | 日页同一句中性说明 | 不拿别的记录或占位图顶上 |

「看这条」**始终** `push` 该条 `/moment/:id`，id 来自这一条 Moment，不猜、不写「当天第一条」。没有第二条「继续阅读」。当天其余记录只通过「这一天还有 N 条」进日页。

### 4.3 声音：互不误触，不宣称已验证播放

- 播放/暂停与「看这条」是两个控件。预览**不得**整块 `Pressable` 包住声音（现日页整条可点，**不能**原样搬进 C′）。
- 展开月、收起月、换日期、滚走再滚回：**不得**在本设计稿或后续实现说明里写「播放已保持 / 已停止 / 已验证」。这些是 **NOT VERIFIED**，要另开带听筒的走查。
- 不改播放器状态机，不改最近页的 `recordedAt` 分组。

## 5. 路由与栈（定死，不留两个实现）

签发沿用 #34：进程内 token。`canGoBack()` 只表示有历史，**不能**证明上一页该回最近、回看根，还是分享页。

C′ **可见的书页 URL 永远是 `/lookback`**（最近热进入可带 `?o=`）。不把 `/lookback/:year` 或 `/:month` 留作书页地址，也不在根上长期挂 `?y=&m=&d=`。

年、月路径是**跳板**：读出本次参数，写入一条**一次性书页指令**，立刻 `replace` 到 `/lookback`。指令在书页下一次 focus **用完即弃**。指令里的年/月/日来自**这一次被打开的路由参数**，不来自冷启动之前的 `lookback-session`。

| 被打开的 URL | 立刻变成 | 一次性指令 | 书页落地 |
| --- | --- | --- | --- |
| `/lookback` | 留下 | 无 | 根书页，**不**展开月、**不**选日 |
| `/lookback/:year` | `replace` → `/lookback`（保留已有 `o=`） | `{ year }` | 滚到该年章节，不展开月 |
| `/lookback/:year/:month` | `replace` → `/lookback`（保留已有 `o=`） | `{ year, month }` | 滚到该年，展开该月，**不**选日 |
| `/lookback/:year/:month/:day` | **不 replace** | （返回时才写，见下） | **日页**，不是书页 |

月跳板若该月既无日记录也无日子未确认：仍 `replace` 到 `/lookback`，指令里的月**不展开**。不要留一层空月历。

日页「返回原来的位置」：用**当日页路由里的 year、month、day**写成一次性指令 `{ year, month, day }`，再：

- 进程内从书页 `push` 来的 → `back()` 到已在的 `/lookback`，书页 focus 时消费指令（展开该月、选中该日、把该日摘录滚进可视区）。
- **冷启动 / 栈上没有书页** → `dismissTo('/lookback')`，书页 focus 时消费**同一条刚写下的指令**。禁止 `canGoBack()`，禁止读杀进程前的展开表来猜 9 月或 24 日。

未确认路由全部保留，不是书页。`/moment/:id` 不变。

旧书签 `/lookback/2026/09` 必须能打开：走月跳板，不是 404，不是空白页留在栈上。

拼错年/月/日：沿用现文案，不发明兼容首页。

| C′ | **日页**（URL 仍是 `/lookback/2026/09/24`） | 用**本页参数**写指令 `{ 2026, 9, 24 }`，再 `dismissTo('/lookback')`。书页消费指令：展开 9 月、选中 24 日、摘录在 24 日行下并进入可视区。**不**读冷启动前内存，**不** `canGoBack()`，**不**猜最近 |

进程内从书页点「这一天还有 N 条」再回：日页同样用本页参数写指令后 `back()`。结果与冷日链相同（月开、日选中），只是用 `back()` 而不是 `dismissTo`。

### 5.3 详情返回

| | 从日页进入 | 从书页「看这条」进入 |
| --- | --- | --- |
| A/B | `back()` → 日页 | — |
| C′ | `back()` → 日页 | `back()` → `/lookback`。月、日以进详情前书页上的选择为准（进程内未卸）。详情不写书页指令 |

### 5.4 冷打开一览

冷启动丢掉：展开月、选中日、滚动、`o=`、未消费指令、音频。只信**这一次** URL 或日页返回时新写的指令。

| 冷打开 | A | B | C′ 落地 | C′ 再离开 |
| --- | --- | --- | --- | --- |
| `lampy:///lookback` | 根 | 根 | `/lookback` 无展开 | 底带最近 → `dismissTo('/')` |
| `…/lookback/2026` | 年页 | 年页 | 跳板 → `/lookback`，滚到 2026，无展开月 | 同上 |
| `…/lookback/2026/09` | 月历 | 年页 + 展开 9 月 | 跳板 → `/lookback`，展开 9 月，无选中日 | 底带最近 → `dismissTo('/')` |

`exp+…/--/lookback` 不是回看深链。`lampy://` 与 Expo Go：实现走查写，本设计不当成已验收。

### 5.5 进程内 vs 冷启动

| 状态 | 进程内（书页未卸） | 冷启动 / 杀进程 |
| --- | --- | --- |
| 展开月、选中日 | 记住；消费指令后写入这次进程表。同时一个月、一个日期 | 丢掉。只靠这次跳板或日页新写的指令 |
| 滚动 | 记住（ADR 0005） | 丢掉；有年/月/日指令则滚到该章节或该日摘录 |
| 音频 | **不写进恢复契约** | 不恢复 |

换月：旧月收起，旧日丢掉，禁止闪一帧旧月日期或摘录。

## 6. 推荐与放弃

### 采用：**C′ 时间书页（无嵌套七列）**

1. §4.2 / §9.4 要的是读当天组合，不是再收集一次日期。A 把阅读放在第四层；B 放在第三层仍是索引。只有 C′ 在回看根上读。
2. 本库真年是「一格有点、十一格安静」（`iphone16-year.png`）。A 再收一张满月安静格税。C-cal 把税搬进书页。C′ 只为有记录的日子付钱。
3. 月历的星期价值在密集月，但密集月正是预览最需要高度的时候。用日期行写星期，把高度留给 6 行正文和一张图。
4. 日页不删：同日 11 条、长文、三图、分页（`HISTORY_PAGE_SIZE`）仍有去处。书页不是卡片墙。
5. 未确认精度、最近、家庭、Moment 形状不动。

### 放弃 A 作为长期阅读模型

A 作为**现网基线**保留到有实现 PR。放弃的是「回看 = 年→月历→日→详情」这条档案走廊：稀疏年跳转税已由真图证明；日页整条可点也过不了 C 的声/详情分控。不是否定年/月/日数据模型。

### 放弃 B 作为产品定稿（#36 仍 OPEN）

B 诚实减少了月历跳转，走查过展开与深链，但是：

- 展开区没有可辨认内容，「有11条记录」仍要再跳日页；
- 年仍是单独一页，回看根仍是目录，不是书；
- #35 写「采用 B」是相对于当时只有 A/B，**没有**把阅读预览画完。

少一跳不是定稿理由。B 留下当备选：若复审认为书页一次改不动，可以先并 #36 只切跳转，**但不得把 #36 宣传成时间书页**。本轮建议：**先复审 C′，再决定 #36 关或并。**

### 放弃 C-cal 与本轮不定 C″

见 §3。C-cal 在真数据上伤害阅读。C″ 多一套开合，等有密集月真用户再议。
