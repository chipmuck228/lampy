# 家庭分享与阅读 D2

基线：#95 普通 merge `5a9ee808095814a0b3a608abc7bc56e6a35aef53`。独立分支 `ios/family-share-reading-d2`。

## 契约

- 分享前明确选择家庭、照片/声音，确认后来加入的成员也能阅读有效历史分享。旧家庭只能由创建者明确升级；升级说明包含撤销旧未完成邀请，不自动升级。
- 分享保存文字、感受、发生日期精度和选中媒体的不可变快照。上传后重新核对原记录 revision、选中媒体字节、账号和家庭资格。只提交白名单，不上传本机路径或生活册。
- 分享成功只表示服务器保存，不代表所有成员已接收。重试复用确定的幂等请求。
- 家庭卡片的“家庭记录”进入明确 familyId 的列表；单条路由同时携带 familyId 和 shareId。读到的是分享快照，不写入个人 Moment。
- 服务端每次授权；离线或权限失败显示失败/重试，不用本地缓存代替权限。缓存按账号/家庭/分享隔离，迟到缓存写入也清理。
- 声音主动点按才播，播放前再鉴权；目录外的家庭页面失焦、切后台、锁定均暂停；同一声音保留进程内进度，返回不自动播。
- 账号、焦点、前后台、锁定或请求代次变化后，迟到结果不能继续保存、显示或播放。

## 范围

复用 D1 v2 API、现有 Keychain/播放器/接收缓存，不增加 migration。不改公开注册、短信、付费、家庭退出移除与解散清理、个人 ownerId 或生产配置。家庭入口默认关闭，identityLoopAccepted 不改。

媒体读取失败当前使单条阅读进入可重试失败态，不把不完整内容当成完整接收。正式双设备/公网闭环属于后续验收。
