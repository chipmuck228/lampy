## 1. 现在怎么走

回看根 `/lookback` 是根页，有 #34 底带。年、月、日、未确认是子页，只有「返回原来的位置」，无底带。

```
/lookback
  → /lookback/2026
    → /lookback/2026/09
      → /lookback/2026/09/24
        → /moment/:id
```

未确认不进格子：

| 精度 | 入口 | 页 |
| --- | --- | --- |
| 未知 | 回看根「时间未确认 · N条」 | `/lookback/unconfirmed` |
| 年 | 年页「月份未确认」 | `/lookback/:year/unconfirmed` |
| 月 | 月页「日子未确认」 | `/lookback/:year/:month/unconfirmed` |

安静月、安静日不可点，不进空页。`fontScale >= 1.3` 或格子不到 44pt 时不画三列 / 七列，只留「有记录的月份 / 日子」。

本库 2026 的真状态：十一个月安静，9 月一天一条。年页实拍 `../lookback-year-day/shots/iphone16-year.png`。月页仍画出整月安静格 + 一天圆点：`../lookback-month/shots/iphone16-lookback-month.png`。XXXL 年页已经没有三列：`../lookback-year-day/shots/iphone16-year-xxxl.png`。

## 2. 两个方案

| | **A · 跳转（现状）** | **B · 同页展开（采用）** |
| --- | --- | --- |
| 可展开的月 | `push` 月页。年页月份 `count` 已含 `exact`+`day`+`month`（见下），仅月精度的月在年格上已是有记录，但仍先跳进月历 | 有 **日记录** 或有 **日子未确认** 的月都可展开（与现 `count > 0` 同一口径）。仅月精度、没有具体日期的月也能展开 |
| 空月 | 不可点 | 既无日记录也无日子未确认 → 不可点，不展开 |
| 展开后看见什么 | 月历 + 「有记录的日子」+ 顶上「日子未确认」 | 「日子未确认 · N条」独立一行，**与日期列表分开**（有则在上）。下面才是具体日期。没有日期就只留未确认行 |
| 有记录的日 | `push` 日页 | **仍 `push` 现有日页** |
| 日子未确认 | 月页顶上入口 → `/lookback/:year/:month/unconfirmed` | 展开区内同一文案、同一路由。不把它写成某一天 |
| 月份未确认 | 年页顶上，月份区域外 → `/lookback/:year/unconfirmed` | **仍在月份区域外**。不进任何一个展开月 |
| 根上时间未确认 | 回看根 | 不动 |
| 大字号 | 列表跳列表 | 可展开的月行下直接挂未确认行和/或日子 |
| 底带 | 只在回看根 | 不变 |
| 月深链 `/lookback/2026/09` | 月页 | 见 §5 |
| 日深链 | 日页 | 日页，不改 |

不在年页上展开一条 Moment。日页刚按内容层次改过，媒体和分页留在那里。

不在回看根上展开各个年。多年并列时，年仍是一页。

## 3. 状态对照（用真结构，不造热力图）

| 状态 | 真含义 | A 跳转 | B 展开 |
| --- | --- | --- | --- |
| **空月** | 无日精度、也无月精度 | 年格安静、不可点 | 不可展开 |
| **稀疏月**（本库 2026-09） | 一天一条，无日子未确认 | 整页七列 + 一行日期 | 展开后只有日期行，不铺安静格 |
| **只有月精度** | 该月有「日子未确认」、0 个具体日 | 年页该月 `count` 已 > 0（含月精度），仍 `push` 月历；月页顶上才见未确认 | **可展开**。月份行仍写「有N条记录」（N 含月精度）。展开后只有「日子未确认 · N条」，没有日期列表 |
| **日记录 + 日子未确认** | 既有具体日，也有月精度 | 月页顶上未确认 + 月历/列表 | 展开：先未确认行，再日期列表，中间分开。月份行 N = 日精度条数 + 月精度条数 |
| **密集月** | 多天有留下 | 月历看星期 | 只列有记录的日子，不嵌七列 |
| **月份未确认** | `occurredAtPrecision=year` | 年页顶上，在月份格/列表之外 | **仍在月份区域外** |
| **根上未知精度** | 回看根 | 独立行 | 不动 |
| **大字号** | `fontScale >= 1.3` | 年、月都是列表，仍要切月页 | 可展开月行下挂未确认和/或日子 |
| **整年为空** | 无月记录、无年精度 | 「这一年还没有留下什么。」 | 相同 |
| **同日多条** | 一天 3 条 | 日页展开各条 | 日期行写「有3条记录」；点进日页 |

横屏 / iPad / VoiceOver：本对照稿只画内容宽够与否。**不得**把 #34 的未验证项写成已通过。实现 PR 按内容宽判断，不按机型。

### 条数口径（与现 ViewModel 一致，B 不另算）

现码：`getHistoryYear` / `projectYearSummary` 的月份 `count` 是 `exact`+`day`+`month`。`yearUnconfirmedCount` 只含 `year`。`getHistoryMonth` 的日期格只含 `exact`+`day`；`dayUnconfirmedCount` 只含 `month`。

| 行 | 字段 | 含什么 | 例：2 条日子未确认 + 9月24日 1 条 |
| --- | --- | --- | --- |
| `9月 · 有N条记录` | 年页该月 `count` / `summary` | **含月精度**（日子未确认） | **有3条记录**，不是 1 |
| `日子未确认 · N条` | `dayUnconfirmedCount` | 仅 `month` | **2条**。不写进某一天 |
| `9月24日 · 有N条记录` | 该日 `count` | 仅 `exact`+`day` | **有1条记录** |
| `月份未确认 · N条` | `yearUnconfirmedCount` | 仅 `year` | 不计入任何月的 N |

对照稿里凡同时画出未确认行和日期行，月份行必须是两者之和。只有月精度、没有日期时，月份行仍写「有N条记录」，N = `dayUnconfirmedCount`。

### 谁能写出月精度

留下页的发生时间只有「今天 / 某一天 / 时间不确定」，`resolveOccurredPatch` 只写 `day` 或 `unknown`。当前用户路径**无法**创建 `occurredAtPrecision=month`。回看仍须读出已有的月精度（测试仓库用 `createDraftMoment` + `activateMoment` + `moments.save`）。运行中页面若要看这一态，只能在隔离测试安装里放明确标记的夹具，**不得**改个人记录，也**不得**写成「通过留下页创建」。用户路径标 **NOT VERIFIED / 当前 UI 无法创建月精度记录**。

## 4. 选定 B 的原因

1. 本库真实年页已经是「一格有点、十一格安静」。再跳进整月月历，安静格比留下多。大字号路径已经丢掉月历，常规字号不必强迫多走一页。
2. 月历的星期位置只在**密集月**值钱。B 把密集月收成「有记录的日子」列表——与现 XXXL 月页同一信息，只是不再先切页。
3. 「日子未确认」属于**那一个月**，所以该月必须能展开；展开后它是独立行，不冒充某一天。「月份未确认」属于**那一年**，继续放在月份区域外。
4. #34 的根带、签发来源、`dismissTo('/')`、Release 无 `/` 栈**不动**。

放弃：在年页展开正文/照片；把回看根做成无限手风琴；把「日子未确认」写进日期列表；把「月份未确认」塞进某个展开月。

## 5. 月深链怎么展开、怎么返回

现码 `/lookback/2026/09` 是月页。B 不再把月历当必经页。

| 动作 | 落点 | 返回 |
| --- | --- | --- |
| 在年页点可展开的月 | 仍停在 `/lookback/:year`，该月展开。不 `push` 月路由 | 再点同一月收起；点另一可展开月则只开那一个月 |
| 打开 `/lookback/:year/:month`（深链或旧书签） | **年页**，该月已展开。实现用 `replace` 收到 `/lookback/:year`，展开态写进进程内（与 `lookback-session` 同类）。不要留下一层空月页 | 见下：有可信上一页才 `back()`；**冷启动 / 来源未记落到 `/lookback`**。**不会**先回到一张月历再回年页 |
| 该月既无日记录也无日子未确认 | 仍落在年页，该月不展开 | 同上 |
| 展开区点「日子未确认 · N条」 | `push` `/lookback/:year/:month/unconfirmed`（现页） | `back()` → 同一年页，**该月仍展开**，未确认行仍在日期列表上方 |
| 展开区点某一天 | `push` `/lookback/:year/:month/:day` | `back()` → 同一年页，该月仍展开 |
| 年页点「月份未确认」 | `push` `/lookback/:year/unconfirmed` | `back()` → 年页；月份区域外的那一行还在，与展开月无关 |
| 冷启动清空 | 展开态与 `lookback-session` 一样丢掉 | 再进年页时没有默认展开，除非这次 URL 是月深链 |

展开态冷启动不恢复。月深链是这一次打开的指令，不是永久书签状态。

### 年页返回：不要用 `canGoBack()` 猜来源

`replace` 掉月路由之后，年页「返回原来的位置」**一律 `back()` 会在冷启动上落空**：栈上可能没有上一页，或上一页是分享 / 家庭 / 未知页。与 #34 相同：`canGoBack()` 只表示有历史，**不能**证明上一页该回哪里。

| 如何进到这张年页 | 记下（进程内，冷启动清空） | 「返回原来的位置」 |
| --- | --- | --- |
| 应用内从回看根（或其它已知页）`push` 年页 | 记下可信上一页 | **`back()`**，回到那一页 |
| 月深链 `replace` 到年页，且**有**记下的可信上一页 | 沿用已记的来源 | **`back()`**。不经过月历 |
| 月深链 `replace` 到年页，**无**可信上一页（冷启动、外链、来源空） | 不记 | **`dismissTo('/lookback')`**，落到回看根。栈里已有 `/lookback` 则停在那里；没有则落到回看根。**不** `dismissTo('/')`，也**不**读 `canGoBack()` |

禁止用 `canGoBack()` 在「回看根 / 最近 / 退出」之间猜测。无可信上一页时的落点是 `/lookback`，不是 `/`。

## 6. 实现切片必须遵守（下一 PR，本轮不写代码）

1. 可展开 = 该月有至少一天的 day 精度，**或** `dayUnconfirmedCount > 0`。两者都没有才是空月。
2. 展开区顺序：若有日子未确认，先独立一行「日子未确认 · N条」；其下才是具体日期。没有日期时不要补「这个月还没有留下什么。」
3. 「月份未确认」只出现在年页月份格/「有记录的月份」列表**之外**。
4. 同时只展开一个月。年页进程内记住展开的月份；从日页或月未确认页 `back()` 后仍展开、滚动仍在。
5. 空月不可点。
6. 日行仍 `push` 日页。日子未确认仍 `push` 现有月未确认路由。
7. 月深链按 §5：`replace` 到年页 + 展开，禁止再做一页必经月历。
8. 年页返回按 §5：有可信上一页才 `back()`；无则 `dismissTo('/lookback')`。**禁止**用 `canGoBack()` 猜来源。
9. 月份行 `有N条记录` 继续用年页现 `count`（含月精度）。日子未确认行用 `dayUnconfirmedCount`。不另开一套加法。
10. 不改 `occurredAt` 精度、Moment 读写、家庭门控、底带。
11. 横屏、iPad、VoiceOver 在实现走查里单独标，**不得**把 #34 的 NOT VERIFIED 当 PASS。

## 7. 走查（实现 PR 才跑）

年页 → 展开有日记录的 9 月 → 见日期行 → 进 24 日 → 返回年页且 9 月仍开。
展开同时有日记录和日子未确认的月 → 未确认行在上、日期在下 → 点未确认进原页 → 返回仍展开。
只有月精度的月 → 可展开 → 只有「日子未确认 · N条」→ 进原页 → 返回仍展开。验收：测试仓库写入 `month` 精度；用户路径留下页无法创建，标 NOT VERIFIED。
月深链 `/lookback/:year/:month`（栈下已有回看根）→ 看见年页且该月已开 → 返回回看根，不经过月历。
冷启动 `/lookback/:year/:month` → 年页且该月已开 → 「返回原来的位置」落到 `/lookback`，不经过月历，也不进最近。不得用 `canGoBack()` 作为这条的依据。
空月不可点。月份未确认仍在月份区域外。
同时有日子未确认与日期时，月份行 N = 两者之和（例：未确认 2 + 24 日 1 →「9月 · 有3条记录」）。
XXXL：无三列，规则相同。
