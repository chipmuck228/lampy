## 1. 现在怎么走

回看根 `/lookback` 是根页，有 #34 底带。年、月、日、未确认是子页，只有「返回原来的位置」，无底带。

```
/lookback
  → /lookback/2026
    → /lookback/2026/09
      → /lookback/2026/09/24
        → /moment/:id
```

未确认不进格子：

| 精度 | 入口 | 页 |
| --- | --- | --- |
| 未知 | 回看根「时间未确认 · N条」 | `/lookback/unconfirmed` |
| 年 | 年页「月份未确认」 | `/lookback/:year/unconfirmed` |
| 月 | 月页「日子未确认」 | `/lookback/:year/:month/unconfirmed` |

安静月、安静日不可点，不进空页。`fontScale >= 1.3` 或格子不到 44pt 时不画三列 / 七列，只留「有记录的月份 / 日子」。

本库 2026 的真状态：十一个月安静，9 月一天一条。年页实拍 `../lookback-year-day/shots/iphone16-year.png`。月页仍画出整月安静格 + 一天圆点：`../lookback-month/shots/iphone16-lookback-month.png`。XXXL 年页已经没有三列：`../lookback-year-day/shots/iphone16-year-xxxl.png`。

## 2. 两个方案

| | **A · 跳转（现状）** | **B · 同页展开（采用）** |
| --- | --- | --- |
| 有记录的月 | `push` 月页（月历 + 列表） | 年页上展开该月「有记录的日子」 |
| 空月 | 不可点，不进空月页 | 同样不展开 |
| 有记录的日 | `push` 日页 | **仍 `push` 现有日页**（照片、长文、分页） |
| 未确认 | 独立子页，不占格 | 仍是年页/回看根上的独立行，**不塞进展开的月** |
| 大字号 | 已是列表跳列表 | 月行下直接挂日子，少一次切页 |
| 底带 | 只在回看根 | 不变。年页仍是子页 |
| 深链 `/lookback/2026/09` | 月页 | 实现时落到 2026 年页且 9 月已展开 |
| 深链 `/lookback/2026/09/24` | 日页 | 日页，不改 |

不在年页上展开一条 Moment。日页刚按内容层次改过，媒体和分页留在那里。

不在回看根上展开各个年。多年并列时，年仍是一页。

## 3. 状态对照（用真结构，不造热力图）

| 状态 | 真含义 | A 跳转 | B 展开 |
| --- | --- | --- | --- |
| **空月** | 该月 0 条 day 精度 | 年格「1月」安静、不可点。要看 9 月仍得先离开年页 | 安静月无展开。点 9 月只在年页拉出有记录的日子 |
| **稀疏月**（本库 2026-09） | 一天一条 | 整页七列，29 个安静格 + 24 日一点，再加一行列表 | 展开后只有「9月24日 · 有1条记录」，不铺安静格 |
| **密集月** | 多天有留下 | 月历有用：星期位置一眼能看 | 只列有记录的日子，**不在年页里嵌七列**。星期位置让给日页标题。一天一行，不按条数染色 |
| **时间未确认** | year / month / 未知精度 | 独立入口，不进月格/日格 | 仍在年页或回看根顶部。展开 9 月不得出现未确认条 |
| **大字号** | `fontScale >= 1.3` | 年、月都已去掉格，只剩列表，但仍要切到月页再切日页 | 年页本来就是「有记录的月份」；点开即日子。少一跳，不恢复三列 |
| **整年为空** | 12 月安静 | 「这一年还没有留下什么。」 | 相同，无展开 |
| **同日多条** | 一天 3 条 | 月历一格；日页展开各条 | 展开行写「有3条记录」；点进日页 |

横屏 / iPad / VoiceOver：本对照稿只画内容宽够与否。**不得**把 #34 的未验证项写成已通过。实现 PR 按内容宽判断，不按机型。

## 4. 选定 B 的原因

1. 本库真实年页已经是「一格有点、十一格安静」。再跳进整月月历，安静格比留下多。大字号路径已经丢掉月历，常规字号不必强迫多走一页。
2. 月历的星期位置只在**密集月**值钱。B 把密集月收成「有记录的日子」列表——与现 XXXL 月页同一信息，只是不再先切页。
3. 未确认继续孤立。同页展开最容易犯的错，就是把「日子未确认」塞进某个展开月。
4. #34 的根带、签发来源、`dismissTo('/')`、Release 无 `/` 栈**不动**。本设计只动年页往下怎么打开月和日。

放弃：在年页展开正文/照片（日页职责）；把回看根做成无限手风琴；为展开重画热力月历。

## 5. 实现切片必须遵守（下一 PR，本轮不写代码）

1. 年页进程内记住展开的月份（与 `lookback-session` 同类，冷启动清空）。返回日页后，该月仍展开、滚动仍在。
2. 同时只展开一个月。再点另一个有记录的月，收起上一个。
3. 空月不可点。不可为了对称把安静月展开成「这个月还没有留下什么。」
4. 未确认行仍 `push` 现有 unconfirmed 路由。
5. 有记录的日仍 `push` `/lookback/:year/:month/:day`。
6. `/lookback/:year/:month` 实现时改为年页 + 该月展开，不要再做一页必经月历。七列月历从主路径拿掉后，不必为 B 再实现一版嵌套月历。
7. 不改 `occurredAt` 精度、Moment 读写、家庭门控、底带。
8. 横屏、iPad、VoiceOver 在实现走查里单独标，**不得**沿用 #34 的 NOT VERIFIED 当 PASS。
