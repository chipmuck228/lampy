# 三屏文案（供确认，不直接实现）

删除功能标签、小引言、重复品牌层之后，每屏只剩：照片短句、主张、解释、动作。

「不必翻找」不能表示永远不用寻找。下面主张已改。第一屏短句按用户已确认文案，与源码「一杯咖啡」的差异只记录、不改稿。

---

## 采用稿（请确认）

### 01 · 留下

| 层 | 文案 | 备注 |
| --- | --- | --- |
| 照片短句 | 一段咖啡，一段午后。 | **已确认文案**。Figma Make 源码是「一杯咖啡，一段午后。」保留差异，本次不要擅自修改 |
| 主张 | 日子，不必特别才值得留下。 | 与截图一致 |
| 解释 | 自己的生活记录，不必写成故事。只是把这一刻，轻轻留给自己。 | 与截图气质一致；「自己的生活记录」在这里是解释的一部分，不是眉题重复层 |
| 动作 | 继续 | |

### 02 · 最近

| 层 | 文案 | 备注 |
| --- | --- | --- |
| 照片短句 | 今天，也有想记住的光。 | 截图原文 |
| 主张 | 轻轻扫过，也能看见日子的样子。 | 截图原文。说的是扫读，不是「全部一眼看完」 |
| 解释 | 文字、照片和声音，照着它们原来的样子。想再读的时候，可以停下来。 | 截图是「想再读一遍的时候，随时停下来。」「随时」略满，改成用户能停。若确认要更贴稿，可改回 |
| 动作 | 继续 | 另有「上一屏」 |

### 03 · 回看

| 层 | 文案 | 备注 |
| --- | --- | --- |
| 照片短句 | 有些日子，值得再坐一会儿。 | 截图原文 |
| 主张 | 从一个日子，继续读起。 | **不采用**截图「不必翻找，从一个日子继续读起。」 |
| 解释 | 回到那一天，慢慢读完那一天。过往就在这里，允许停留。 | 截图原文。这是回看的阅读方式，不是「永远不用找」 |
| 动作 | 进入 Lampy | |

眉题：Lampy + 色点。进度：`01 / 03` … `03 / 03`。

## 明确不用的句子

| 句子 | 原因 |
| --- | --- |
| 一杯咖啡，一段午后。 | 与用户原文冲突，除非用户改口 |
| 不必翻找，从一个日子继续读起。 | 「不必翻找」过满 |
| 现网「一句话，也值得留下。」三句 | 旧引导，结构也不是照片短句 |
| 「自己的生活，安心放在这里。」里的设备 / 本机保护承诺 | 本轮引导不讲保护；保护仍在设置 |

## 空状态（最近 / 回看）

同一气质：一句主张 + 一句说明。不放假记录。留下走浮动按钮，空态不再堆一枚同样的按钮。

| 页 | 主张 | 说明 |
| --- | --- | --- |
| 最近空 | 还没有留下。 | 想起来的时候，再写一句、一张照片，或一段声音。 |
| 回看空 | 还没有可以回看的日子。 | 留下之后，会按发生的日期出现在这里。 |
| 回看某日空 | 这一天还没有留下什么。 | 现网句。不是空库 |
| 日历无效 | 日历上没有这一天。 | 现网句 |

回看未知入口文案（目录，不是空态）：

| 范围 | 采用 |
| --- | --- |
| 根 unknown | 还没有日期的片段 |
| year | 这一年，月份未定 |
| month | 这个月，日子未定 |
