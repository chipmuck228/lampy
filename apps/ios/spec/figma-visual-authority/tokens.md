# 字体、颜色、间距、行距

分两栏写：**提取值**（从 Figma Make 源码或截图读到的）和 **原生适配建议**。网页 `px` 不是 iOS `pt`。

截图是带外壳的 JPEG，约 442–540 × 1024。**不要**按这个高度做页面。

---

## 1. 字体

### 提取值（来自 `references/figma-make/index.css`）

| 角色 | 网页家族 | 把握 |
| --- | --- | --- |
| 阅读标题、记录正文、引导主要文字 | `Noto Serif SC` | 源码写明 |
| 操作及辅助文字 | `Noto Sans SC` | 源码写明 |
| 英文品牌 Lampy / 数字 | `DM Sans` | 源码写明 |
| 网页加载方式 | `@import` Google Fonts CSS | **原生禁止**运行时网络字体 |

### 许可与可打包性

| 家族 | 许可 | 可否打进 App |
| --- | --- | --- |
| Noto Serif SC | SIL Open Font License 1.1 | 可以。需自备可打包文件，不要运行时拉 CDN |
| Noto Sans SC | SIL Open Font License 1.1 | 可以。同上 |
| DM Sans | SIL Open Font License 1.1 | 可以。同上 |

本设计 PR **不**加入字体文件。完整字体与配色改版仍是独立视觉切片。切片实施时：

- 只打包已核对许可的文件
- 加载完成前不要短暂显示错位的正文
- 回退仍用系统字形

### 原生适配建议

在字体切片落地之前：

- **继续用 iOS 系统字形**（中文 PingFang SC，西文 SF Pro）
- 先落地**固定字号**，不要先换脸
- 不要为了「看起来像」自行换成宋体 / Source Han / New York

字号策略（覆盖旧 Dynamic Type 要求）：

| 角色 | 建议 |
| --- | --- |
| 全部用户可见文字 | `allowFontScaling={false}`。系统设置不改变应用字号 |
| 页面标题 | 28pt |
| 阅读正文 / 留下输入 | 17pt，行高约 30–34pt |
| 操作文字、按钮、底带、FAB | 16–17pt。不要为了塞进一行而缩小 |
| 日期、感受、辅助信息 | 14–15pt |

这些是待实页确认的应用参数，**不是** Figma 源码精确值。网页正文 `13px`、照片短句 `10px`、底带 `10px` **不得**照抄成 iOS pt。

## 2. 颜色

### 提取值（源码优先，截图不再当色值权威）

| 角色 | 源码 | 现网 `life-page.ts` |
| --- | --- | --- |
| 纸色 | `#F8F6EF` | `#F3F0E9` paper |
| 正文列宽浅分隔线 | `#E4E4DB` | `hairline` `rgba(37,35,31,0.16)` |
| 深墨正文 | `#373B34` / `#363A32` | `#25231F` ink |
| 软墨元信息 | `#9D9F91` / `#838A7C` | `#5C5851` inkSoft |
| 低饱和绿操作 | `#424B3C`、按钮浅底 `#E8EBE1` | `#53604F` sage |
| 感受色点 | `#B69C7E` | 现 `feeling-accent.ts` |

### 原生适配建议

完整换色仍属视觉切片。本轮只记依据：

- 纸色目标 `#F8F6EF`，现网先保持 `#F3F0E9` 直到切片落地
- 分隔线目标 `#E4E4DB`，改的是**宽度**（沿正文列）和后续色值
- 操作保持低饱和绿，对比要够
- 不铺感受底色。不把截图照片当页面底图

## 3. 字号与行距

### 提取值（网页，禁止直接当 pt）

| 角色 | 网页 |
| --- | --- |
| 最近 / 回看标题 | `29px` / 阅读日 `31px` |
| 列表正文 | `13px` / `line-height: 2.05` |
| 详情正文 | `15px` / `line-height: 2.2` |
| 留下输入 | `17px` / `line-height: 2` |
| 引导主张 | `clamp(27px, 8vw, 33px)` |
| 引导解释 | `11px` |
| 展开 / 完整阅读 | `11px` / `10px` |
| 底带 | `10px` |

网页列表正文偏小，是桌面并列稿的密度，不是 iOS 阅读尺寸。

### 原生适配建议

沿用上一节固定基线。行距要舒展，不靠压紧段落提高密度。不要为了塞进一行而缩小正文或操作文字。

---

## 4. 间距

### 原生适配建议

- 左右：继续 `pageGutter`（常规 24，宽屏 48）。横线画在**正文列**上。
- 引导：小屏先减照片高度和块间距，再让解释滚动。底按钮始终在安全区上。
- 最近 / 回看：同日条之间 = 一条列宽浅线 + 中等留白。换日 = 日期行 + 更大章节留白，**不再加线**。
- 列表 `paddingBottom` = 底带 + FAB 实际高度 + 安全区 + 一条完整入口的高度。
- 布局依据实际可用宽度、文字尺寸与内容高度，不再用系统 `fontScale` 决定日期轨、组图、底带横纵排、TextInput 高度。

---

## 5. 组件尺寸

| 组件 | 建议 |
| --- | --- |
| 展开 / 完整阅读 / 换一天 | 可见高度 ≥ 48。可换行。无 `hitSlop` 补救 |
| FAB | 按文字 + 内边距算，贴右下，避开 Home Indicator 与底带 |
| 底带 | 两项均分或按字宽和可用宽度。窄屏可叠，不因系统字号叠 |
| 播放条 | 现紧凑条。时间数字跟应用固定字号 |
| 照片 | `aspectRatio` 来自图片。组带看列宽。缺失纵排 |

---

## 6. 还缺什么才能把字体真正换进 App

1. 可打包的 Noto Serif SC / Noto Sans SC / DM Sans 文件（OFL）
2. 加载完成前的占位策略，避免错位闪一下
3. 独立视觉切片：换脸 + 纸色 / 分隔线，不和固定字号基础混成一次改版
