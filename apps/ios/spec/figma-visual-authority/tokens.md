# 字体、颜色、间距、行距

分两栏写：**提取值**（从截图或现网读到的）和 **原生适配建议**。没有 Figma Inspect，提取值是目测 + 截图近似，不是变量面板里的 token。

截图是带外壳的 JPEG，约 442–540 × 1024。**不要**按这个高度做页面。

---

## 1. 字体

### 提取值

| 观察 | 值 | 把握 |
| --- | --- | --- |
| 引导大主张 | 偏衬线、高对比、字距松。例如「日子，不必特别才值得留下。」 | 只看见外形 |
| 引导解释 / 照片短句 / 按钮 | 更接近无衬线或同一家族的轻字重 | 未证实是否同一家族 |
| 最近 / 回看正文 | 无衬线、字重中等偏书刊 | 未证实 |
| 眉题 `LAMPY · 生活记录` | 无衬线、字距略开、字重细 | 未证实 |
| **PostScript / 家族名** | **未知** | 画布与源码都没读到 |
| **许可** | **未知** | 没有字体文件 |

### 原生适配建议

未确认名称、可用性、许可之前：

- **继续用 iOS 系统字形**（中文 PingFang SC，西文 SF Pro）。现网没有 `fontFamily`。
- **不要**自行换成宋体、Source Han Serif、Noto Serif、New York 或其他「看起来像」的脸。
- 层次用**同一系统家族**的字号 / 字重 / 颜色区分，不要中英混两套展示脸。
- 若产品之后提供授权字体：单独切片加入，写清文件、许可、回退。

缩放：

| 角色 | 建议 |
| --- | --- |
| 引导主张、照片短句、页眉大标题 | 可以设 Dynamic Type 上限，避免一屏只剩两个字。上限也必须仍能读完，不能裁成「日…」 |
| 正文、展开、阅读完整记录、按钮、错误、空态、播放时间 | **充分**跟系统字号。禁止 `allowFontScaling={false}`，禁止靠缩小字号塞进固定海报 |
| 底带、FAB 标签 | 大字号时按钮可以增高、可以换行。不裁字 |

## 2. 颜色

### 提取值（截图近似）

从 `references/` 目测，不是色值面板。压缩和外壳会偏。

| 角色 | 截图近似 | 现网 `life-page.ts` |
| --- | --- | --- |
| 纸色 | 很浅的暖白，略亮于现网 | `#F3F0E9` paper |
| 深墨（主张 / 标题 / 正文） | 近黑暖灰 | `#25231F` ink |
| 软墨（解释 / 元信息 / 眉题） | 中暖灰 | `#5C5851` inkSoft |
| 引导按钮底 | 浅灰绿 | 无同款；现按钮偏纸色 |
| 引导按钮字 | 墨绿 | `#53604F` sage |
| 浮动留下 | 很深的墨绿，近黑 | 无 FAB；sage 偏浅 |
| 底带未选 | 软墨 | sage |
| 浅分隔线 | 低对比暖灰横线，几乎通栏 | `hairline` `rgba(37,35,31,0.16)`，现同日线只有 72pt |
| 感受色点 | 小圆点，不铺底 | 现 `feeling-accent.ts` |
| 照片短句 | 白色压在照片下沿 | 无 |

### 原生适配建议

- 纸 / 墨 / 软墨 / 感受色点：**沿用现网**，不要为了贴近截图再发明一套冷白。
- 引导按钮：浅底 + 墨绿字 + 细边，圆角按原型说明约 16pt（Version 5 文字，不是 Inspect）。
- FAB：比 sage 更深的墨绿，对比要够。具体色在实现切片里用现 `sage` 加深一档或新常量，需对照真机，不在本静态稿锁死。
- 分隔线：现 `hairline` 即可，改的是**宽度**（沿正文列），不是另做一条高对比线。
- 不铺感受底色。不把截图照片当页面底图。

## 3. 字号与行距

### 提取值

无法从 JPEG 读出准确 pt。相对关系：

| 角色 | 相对 |
| --- | --- |
| 引导主张 | 最大。行距看起来 ≥ 1.2em，左对齐，两到三行 |
| 引导解释 | 主张的约 40–50%，行距更松 |
| 照片短句 | 小于主张，压在照片里 |
| 「最近」「回看」标题 | 大，但小于引导主张 |
| 正文 | 中等，行距明显舒展（约 1.5–1.7） |
| 眉题 / 元信息 /「慢慢看」 | 小、软墨 |
| 展开 / 阅读完整记录 | 小、软，行尾可带箭头 |

### 原生适配建议（常规字号起点，随系统缩放）

沿用现网已经舒服的正文，不压行距换密度。

| 角色 | 建议起点 | 行高 |
| --- | --- | --- |
| 引导主张 | 34–40 | ≥ 1.25 |
| 引导解释 | 16–18 | ≥ 1.5 |
| 照片短句 | 14–16 | 1.4 |
| 页眉大标题 | 28（现 `wordmark`） | 1.2 |
| 最近 / 回看正文 | 21（现 `recent-moment` note） | 保持舒展，约 32 |
| 元信息 | 13–15 | 1.3 |
| 入口（展开 / 完整阅读） | 16 | ≥ 22，命中高 ≥ 48 |
| 底带 | 17 | 命中高 ≥ 48，大字号可再高 |
| FAB | 16–18 + 符号 | 大字号增高，不缩小系统字 |

## 4. 间距

### 提取值

截图里：页边约一指、照片与主张之间有一段空气、记录之间靠一条细线和留白、日期章节比同日条间距更大。

无法得到可靠的 4pt 网格数。

### 原生适配建议

- 左右：继续 `pageGutter`（常规 24，宽屏 48）。横线画在**正文列**上，不是画到屏幕出血。
- 引导：小屏先减照片高度和块间距，再让解释滚动。底按钮始终在安全区上。
- 最近 / 回看：同日条之间 = 一条列宽浅线 + 中等留白。换日 = 日期行 + 更大章节留白，**不再加线**。
- 列表 `paddingBottom` = 底带 + FAB 实际高度 + 安全区 + 一条完整入口的高度。以真机量，不靠估计。
- 不要按截图把一屏锁成海报。

## 5. 组件尺寸（适配，不是提取）

| 组件 | 建议 |
| --- | --- |
| 展开 / 完整阅读 / 换一天 | 可见高度 ≥ 48。可换行。无 `hitSlop` 补救，不关缩放 |
| FAB | 按文字 + 内边距算，贴右下，避开 Home Indicator 与底带。横屏贴安全区 |
| 底带 | 两项均分或按字宽。大字号可叠高，不裁「最近」「回看」 |
| 播放条 | 现紧凑条。时间数字跟系统字号 |
| 照片 | `aspectRatio` 来自图片。大字号纵排。缺失用现提示句 |
