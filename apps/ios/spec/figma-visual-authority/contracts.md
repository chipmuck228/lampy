## 2. 最近：展开与完整阅读

| 记录 | 可见入口 | 行为 |
| --- | --- | --- |
| 短文（可见行 ≤ 6） | 只有「阅读完整记录」 | `push(/moment/:id)` |
| 长文 | 「展开正文」+「阅读完整记录」 | 展开只改该条 `numberOfLines`。完整阅读进详情 |
| 仅图 / 仅声 / 无字 | 只有「阅读完整记录」 | 不显示展开 |

「展开正文」收起后回到 6 行预览。展开不是进详情，也不生成摘要。

#51 的「看这条 / 看这条，还有正文」在视觉切片里换成上表。VoiceOver 仍要说清是打开这一条，还是在原位展开。

保存回声资格继续 #51：最近聚焦 + 本次 `getRecentLife` 成功 + ID 在结果中 + `AppState === 'active'`。失焦 / 新读 / 失败清 `loadReady`。消费一次。

播放与打开仍分开。进度按 `AudioView.id`。

列表底部垫高必须按**量过的** FAB + 底带 + 安全区。末条的文字、播放、展开、完整阅读都要能滚到完全露出、可点。短屏或窄列把首屏占满不算失败，但滚到条尾后上述入口必须可点、不被挡。系统最大字号不得把应用文字放大。

## 4. 回看（引用 #50，只补外观与日期）

必须保持：

- 默认日查找（跳过只有月精度的月；失败即停；year/month 不进根 unknown）
- 目录覆盖：先暂停，阅读树不卸，底层不可点不可读，关闭不自动播
- 进程内阅读快照、先内容后位置、`hasMore === false` 停页
- 当天分批、「继续往下看」
- 邻日写出目标日期
- 日页深链仍活
- 冷启动回最近

本轮补：

| 项 | 采用 |
| --- | --- |
| 页眉 | 「回看」+「慢慢看」。目录入口文案可仍叫「换一天」或时间目录，低强调，≥ 48 |
| 目录年月 | `2025年 · 6月` |
| 阅读页首 | `6月18日` + 周几。删除独立 `2025 · 06`。条数不在页首 |
| 每条 | 不重复当天日期；只有精确时刻才写时刻 |
| 邻日 | 目标日期；跨年补年 |
| 分隔 | 列宽浅线，规则同最近 |
| 长文 | 原位展开 + 阅读完整记录（与最近同一对入口） |
| 空 | 无假日期 / 假章节 / 空目录 |
| 「这一日，读到这里」 | 仅 `hasMore === false` |
| 未知入口 | 「还没有日期的片段」；年/月用未定句 |
| 未知条 | 可写「留下于…」，不编入该日发生章节 |

## 5. 发生日期切片（实现时单独 PR）

| 事件 | 采用 |
| --- | --- |
| 新建草稿 | 写入当天本地日精度。UI：「发生日期：今天」 |
| 午夜仍开着这份新草稿 | 不改已写入的默认值 |
| 恢复草稿 | 保留草稿上的日期，包括未知 |
| 已有 unknown 记录 | 不回写、不迁移 |
| 最近分组 | 仍 `recordedAt` |
| 最近发生日不同 | 仍 `occurredLabel` |
| 回看归位 | 仍 `occurredAt` + precision |

现网留下已会给新草稿 `persistOccurred({ kind: 'today' })`、恢复保持未知。本切片要补的是**明确可改的日精度 UI**，以及「已有未知永不补」的验收，不是再暗改一次默认值。
