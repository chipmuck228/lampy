## 没找到、因而不能假装有的

- Figma Make 导出的 React / CSS / 字体文件
- 字体的准确 PostScript 名、字重轴、厂商许可
- 回看稿上是否画出与最近同一枚浮动「＋ 留下」（已给的回看上下图里**没有**这枚按钮）
- 精确到 0.5pt 的 Figma 间距 token

缺字体文件和许可时：**不换近似字体**。原生继续用系统字形，直到有可进 App 的授权字体。

缺回看浮动按钮的稿时：取舍要求回看也要有清楚的留下入口，并与最近保持一致可发现性。实施时**沿用同一浮动按钮**，在稿里标成「取舍覆盖原型」，不是「我在回看截图里看到了 FAB」。
