## 1. 采用

### 1.1 三屏首次引导

这是**首次引导**，不是每次启动重播的原生 Splash。完成条件、中途退出不完成、继续 / 上滑、最后一步才完成、Reduce Motion：沿用现 `first-run` 规则。

只保留三层文字：

1. 照片内短句
2. 一句主张
3. 一句解释

删除功能标签（「留下 / 最近 / 回看」）、小引言、重复的「自己的生活记录」品牌层。眉题「Lampy」+ 色点可留，不另堆品牌说明。

照片先用原型占位，来源和替换见 [`references/README.md`](./references/README.md)。

第一屏照片短句**暂按用户原文**：

> 一段咖啡，一段午后。

不自行改成稿上的「一杯」。标 **待确认用词**。

主张与解释按截图气质：左对齐、舒展留白、同一字体家族，用字号 / 字重 / 颜色分层次。具体三屏文案见 [`copy.md`](./copy.md)，不直接沿用不准确承诺。

标题和装饰短句可以有最大字号缩放上限。正文、按钮、错误提示必须跟着系统大字号走完。小屏先减照片高度和间距，正文可滚，操作不被挡，不做成固定海报。

动作：01 / 02「继续」，03「进入 Lampy」。进度 `01 / 03` … `03 / 03`。

### 1.2 最近

- 保留「LAMPY · 生活记录」和「最近」。
- 设置用齿轮，沿用现有 `LifeIcon` 体系，不另做线性太阳。
- 正文按现网阅读列排。照片原比例，不强制裁切。组带规则仍是 #51：非大字号且实际图片列 ≥ 280 才并排。
- 感受和「阅读完整记录」放在**该条末尾**。
- 长文同时提供：
  - **展开正文**：原位置展开 / 收起
  - **阅读完整记录**：进入精确 Moment ID 详情
  - 短文不显示展开。
- 不同记录之间：沿正文列宽的浅色水平线。同一记录内不插线。首条前、末条后不加线。不同记录日用日期和章节留白区分，不叠多道线。
- 感受色点保留。未选无点。不铺情绪底色。
- 录音播放与打开详情分离；最近 / 回看各记各的进度（现 `AudioView.id` 记忆表）。
- 空状态：同一字体、纸色、留白。一句主张 + 一句说明。不展示假记录，不堆重复按钮。去留下用页上的浮动入口，不在空态再放一枚同样的「留下」。

#51 已做且本轮视觉**不回退**的：6 行初始预览、保存回声四条件、稳定外壳、「看这条」换行代码。视觉切片把「看这条」换成「阅读完整记录」，资格与组带留下。

### 1.3 导航与浮动留下

- 最近保留墨绿浮动「＋ 留下」。
- 根页底带只留最近 / 回看，去掉底带中的留下。
- 回看也要有清楚的留下入口。已给回看截图**没有**画出 FAB。取舍要求一致可发现性 → **沿用同一浮动按钮**，标成取舍覆盖原型。
- 导航改两页一起核。来源 / 返回栈不改：`/lookback?o=`、`dismissTo('/')`、详情 `back()`。
- FAB 按实际尺寸 + 安全区避让。末条文字、播放、完整阅读入口必须能滚到不被挡住的位置。
- 大字号允许按钮增高，不裁字，不关系统缩放。
- 子页不擅自加根页导航。

### 1.4 回看

外观按新 Figma 气质，**流程沿用 #50**。

- 标题「回看」，低强调「慢慢看」。
- 舒展行距。不靠压紧段落提高密度。
- 不同记录之间：正文列宽浅色横线。同一套分隔规则，见上。
- 日期分工见 §1.5。
- 目录按需打开、当天连续阅读、长文原位展开、分页、邻日、详情返回、旧深链：#50。
- 打开目录先暂停声音；阅读树保留但不可触达、不可朗读；关闭不自动播放。
- 空状态：没有假日期、假章节、空目录。安静文案 + 明确去留下（同一 FAB）。
- 「这一日，读到这里」仅在当天**全部加载完成**（`hasMore === false`）时出现。
- 不编造声音标题，不自动播放，不生成生活叙事。

### 1.5 发生日期（独立行为切片，本 PR 不实现）

- 新建草稿默认今天。设备当前**本地**日期，日精度。界面明确写「发生日期：今天」，可改到其他日或「日期不确定」。
- 默认值在**新建草稿时**确定。不因午夜或恢复草稿而悄悄改。
- 恢复草稿保留原日期，包括未知。
- 已有未知记录不补日期，不批量迁移。
- 最近仍按 `recordedAt` 分组。发生日不同仍单独标出。两个概念不混。
- 回看整体未知入口改为「还没有日期的片段」。
- 年精度：「这一年，月份未定」。
- 月精度：「这个月，日子未定」。
- 不得把 year / month 精度并进根上 unknown。
- 未知记录可写「留下于…」作辅助线索，**不**归入该日的发生日期章节。

日期在阅读页上的分工：

| 位置 | 写 | 不写 |
| --- | --- | --- |
| 目录入口 | `2025年 · 6月` | 条数以外的第二套年月 |
| 阅读页首 | `6月18日` + 周三 | 再来一行 `2025 · 06`；不在页首重复条数 |
| 条数 | 留在目录 | 阅读页首不再强调 |
| 每条 | 只有**真实精确时刻**才显示时刻 | 不重复当天日期 |
| 邻日 | 目标日期；跨年补年份 | 空按钮 |
| VoiceOver | 完整年月日 | — |
