# Figma Make 网页原型源码

这些是用户提供的 **Figma Make 网页原型**，不是 Lampy 原生业务实现。

不要把这里的 React / CSS 当成 iOS 页面。不要复制：

- 手机外壳、假状态栏、固定 755 / 852 屏高
- Google Fonts 运行时网络请求
- 网页 `px` 当 iOS `pt`（尤其不要照抄正文 `13px`）
- 假进度、假声音标题、假记录数据
