# 常规、最大字号、短屏、横屏、iPad

静态稿。不是运行 PASS。不要按 `references/` 的 1024 像素高度做页面。

现网断点继续用：`COMPACT_HEIGHT = 500`，`REGULAR_WIDTH = 768`，`LARGE_TYPE = 1.3`，`READING_MAX = 520`。

---

## 1. 常规（iPhone 竖屏，系统默认字）

- 引导：照片在上，主张和解释在下，底按钮固定。一屏能看完主张和解释时，解释不必滚。
- 最近：眉题 +「最近」+ 齿轮。记录按 `recordedAt` 日块。同日浅线通栏（正文列宽）。FAB 右下。底带两项。
- 回看阅读：页首日期 + 周几。条与条浅线。目录按需盖上。
- 照片原比例。能组带才组。

对照：[`storyboard.html`](./storyboard.html) 常规列。

---

## 2. 最大字号（AX XXXL）

允许：

- 照片把首屏操作顶出去（与 #51 收尾口径相同）
- 引导主张达到缩放上限
- FAB / 底带 / 完整阅读入口增高、换行

不允许：

- 裁「阅读完整记录」「展开正文」「继续」「进入 Lampy」
- 关掉系统缩放
- 用 `hitSlop` 冒充可见命中区
- 底带或 FAB 挡住条尾入口（滚到条尾之后）

引导：主张可上限；解释和按钮跟系统字。解释滚动，按钮留在安全区上。

最近 / 回看：大字号纵排照片（现 `shouldPairRecentImages`）。日期可折行。VoiceOver 完整年月日。

#51 在隔离机滚到条尾后，可见控件没有出示完整「看这条」，点击也未进详情。记在 #51 走查，**不是**本静态稿的 PASS。实现切片必须在真机或稳定模拟器上再验一次「阅读完整记录」。

---

## 3. 短屏（高度 < 500，或 iPhone 横屏高度）

- 引导：先减照片高度，再减块间距。解释可滚。底按钮不被挡。不把三屏塞成固定海报。
- 最近 / 回看：标题可更紧，正文行距不压。目录覆盖要露出关闭和至少一行年月。
- FAB 仍避让安全区；横屏短高时允许略缩小**内边距**，不缩小系统字。

---

## 4. 横屏

- 阅读列仍受 `READING_MAX` 约束，不要拉满整宽。
- 浅线仍只画在正文列上。
- FAB 贴右下安全区，避开底带。
- 引导保持单列，不要突然改成桌面双栏（那是 Figma V1 的桌面并列，**不采用**为原生横屏方案）。

---

## 5. iPad（宽 ≥ 768 且高度足够）

- 可用现网日期轨：日期在左，正文在右。大字号时仍改为上下叠（现 `shouldStackRecentDay`）。
- 底带在常规宽且非大字号时可用现侧轨规则；两项导航，无「留下」项。留下只走 FAB。
- 不要把 Figma 桌面「最近 | 回看」并排做成 iPad 默认。回看仍是单独根页。
- 照片组带按**实际图片列宽**，不是按窗口宽。

---

## 6. 各布局都要能看见的结构（同一批夹具）

短文、长混合、同日多条、1–3 图、声音、缺失媒体、空、三种未确认。见 [`samples.md`](./samples.md)。storyboard 用 CSS 画这些结构，**不用**参考图当背景。
