# 常规、最大字号、短屏、横屏、iPad

静态稿。不是运行 PASS。不要按 `references/` 的 1024 像素高度做页面。

现网断点继续用：`COMPACT_HEIGHT = 500`，`REGULAR_WIDTH = 768`，`READING_MAX = 520`。`LARGE_TYPE` / 系统 `fontScale` **不再**决定日期轨、组图、底带或输入高度。

---

## 1. 常规（iPhone 竖屏，系统默认字）

- 引导：照片在上，主张和解释在下，底按钮固定。一屏能看完主张和解释时，解释不必滚。
- 最近：眉题 +「最近」+ 齿轮。记录按 `recordedAt` 日块。同日浅线通栏（正文列宽）。FAB 右下。底带两项。
- 回看阅读：页首日期 + 周几。条与条浅线。目录按需盖上。
- 照片原比例。能组带才组。

对照：[`storyboard.html`](./storyboard.html) 常规列。

---

## 2. 系统最大字号（AX XXXL）

系统把文字调到最大时，**应用字号仍应与常规系统字号一致**。这是策略验收，不是旧 Dynamic Type 布局竞赛。

允许：

- 短屏 / 窄列把首屏操作顶出去，用户向下滚
- FAB / 底带按可用宽度换行或增高

不允许：

- 应用文字跟着系统变大或变小
- 裁「阅读完整记录」「展开正文」「继续」「进入 Lampy」
- 用 `hitSlop` 冒充可见命中区
- 底带或 FAB 挡住条尾入口（滚到条尾之后）
- 把旧 XXXL 裁切走查或 Face ID 黑屏修补写成这一版 PASS

引导：解释可滚，按钮留在安全区上。不复制网页外壳。

最近 / 回看：组图看实际列宽和原比例。日期可折行。VoiceOver 完整年月日。

---

## 3. 短屏（高度 < 500，或 iPhone 横屏高度）

- 引导：先减照片高度，再减块间距。解释可滚。底按钮不被挡。不把三屏塞成固定海报。
- 最近 / 回看：标题可更紧，正文行距不压。目录覆盖要露出关闭和至少一行年月。
- FAB 仍避让安全区；横屏短高时允许略缩小**内边距**，不缩小应用正文和操作字。

---

## 4. 横屏

- 阅读列仍受 `READING_MAX` 约束，不要拉满整宽。
- 浅线仍只画在正文列上。
- FAB 贴右下安全区，避开底带。
- 引导保持单列，不要突然改成桌面双栏（那是 Figma V1 的桌面并列，**不采用**为原生横屏方案）。

---

## 5. iPad（宽 ≥ 768 且高度足够）

- 可用现网日期轨：日期在左，正文在右。只在宽度/高度不够时上下叠，不再因系统字号叠。
- 底带在常规宽时可用现侧轨规则；两项导航，无「留下」项。留下只走 FAB。
- 不要把 Figma 桌面「最近 | 回看」并排做成 iPad 默认。回看仍是单独根页。
- 照片组带按**实际图片列宽**，不是按窗口宽。

---

## 6. 各布局都要能看见的结构（同一批夹具）

短文、长混合、同日多条、1–3 图、声音、缺失媒体、空、三种未确认。见 [`samples.md`](./samples.md)。storyboard 用 CSS 画这些结构，**不用**参考图当背景。
