# 家庭举报 Admin：单账号图形处理

基线 main 9cc82fc（已合并 #127），独立实施。仅运营人员通过专用账号和密码登录，不使用 Apple 登录，不存在公开注册或默认密码。页面与管理员服务不进入移动端导航，不开启付费、导出或打印。

## 最小范围

- 举报列表：待处理、已核对、已限制和全部；每页 50 条，列表不返回正文。
- 举报详情：原因、补充说明、家庭、分享者、记录日期，以及仍存在的被举报家庭分享。正文按纯文本展示；照片和声音需明确点击载入，不自动访问媒体。
- 处理：已核对／下架分享／限制作者新增分享／解除作者分享限制。填写原因，确认对话框展示目标和原因后提交。
- 记录：查看该分享和作者的处理审计。限制分享与下架复用 #127 规则，不能以“已核对”或“解除账号限制”恢复已下架内容。
- 不提供全量用户／家庭／私人库搜索，不编辑内容、不永久删除媒体，不提供批量处罚、账号注册、找回密码或自动邮件。

## 身份与访问

管理员名称、密码哈希仅放在主机独立环境文件。密码工具在交互终端无回显读取 16–256 字符，不通过命令参数传入，不输出明文。使用独立 salt 的 Node scrypt（N=131072，r=8，p=1）保存哈希；不要求外部认证服务。建议用密码管理器生成长随机密码。

Cookie 使用 `__Host-`、Secure、HttpOnly、SameSite=Strict，无 Domain；令牌和 CSRF 不写入 localStorage。会话保存在单进程内存，30 分钟无操作／8 小时绝对过期，后台验证不延长闲置时间；退出或重启 Admin 清除会话。修改凭据并重启即可轮换密码、撤销所有会话。

所有写入校验精确 Origin 和 CSRF。登录有每来源及全局频率上限，同时只允许一个密码派生操作。用于限流的来源标识只以随机盐哈希保存在进程内存，15 分钟到期，不写数据库。Admin 仅绑定 loopback；Caddy 覆盖 Host 与来源头，浏览器通过 HTTPS 同源访问。CSP 禁止内联脚本、外部资源、框架嵌入和任意表单目标。

每次媒体请求重新核对举报、原分享、家庭状态、媒体归属和内容哈希，不接受磁盘路径或任意对象引用。只允许 JPEG／PNG／MP4 音频，支持声音 Range 请求；撤回、家庭关闭或账号删除后不继续通过接口提供。已载入页面约每 30 秒验证状态，变化后清空内容并要求重新打开；不能追回运营人员已在浏览器或 App 外保存的副本。

处理提交携带服务端状态版本，旧页面返回冲突，不能覆盖较新的决定。处理写入与 Admin 操作审计在同一 SQLite 事务中，审计失败回滚。已有家人 API 保持独立，没有新增管理员权限到公开家庭 API。

## 数据与日志

Admin 使用现有家庭数据库与媒体目录，不复制正文、照片或声音到新仓库。启动仅要求既有 #127 schema 33，不运行 family 迁移；新增独立 `family_admin_audit` 表及时间索引，家庭迁移版本仍为 33。

Admin 访问审计记录管理员名、操作类型、时间、举报引用和必要的媒体引用，不记正文、密码、Cookie、IP 或声音副本。此新表保留 30 天，启动及每小时清理；清理是数据库行删除，不是磁盘安全擦除。现有举报、内容处理及作者限制审计继续沿用 #127，独立的保留期限仍须在隐私工作中收口，不能将本表 30 天误写成全部数据均保留 30 天。

未登录尝试的来源信息只用于内存限流。成功登录／退出、列表／详情／媒体／历史访问及处理动作有审计，不开放日志下载或批量内容导出。HTML、JSON、媒体响应均 no-store，不接入外部统计、字体或 CDN。应用服务不打印请求体或凭据；主机／Caddy 既有日志与云快照仍按其独立规则管理。运营原因只写判断依据，避免复制私人原文。

## 部署准备

本片暂不自动部署，不更改 DNS、现有 API、环境文件或密钥，不创建真实管理员密码。部署前应做现有 SQLite 的一致性操作副本。

1. 在权威 DNS 管理处增加 `admin` 的 A 记录，值为操作者的服务器 IPv4，不添加到 Vercel 网页项目，不修改现有官网／家庭 API 解析。
2. 独立部署代码到 `/opt/lampy-family-admin`，在 `apps/ios` 安装完整依赖（含 TypeScript）。不替换正在运行的家庭 API 代码目录。
3. 参考 `src/family-admin/deploy/admin.env.example`，用 `sudoedit` 创建 `/etc/lampy/admin.env`，root 所有、0600。只配置 Admin 所需字段，不复制 Apple 密钥或整个家庭环境文件。
4. 在独立交互终端运行 `node scripts/family-admin-password.cjs`，将输出的哈希行写入该环境文件；真实密码与哈希都不要提交到 git、PR、公开日志或聊天。用户名使用自己的专用账号。
5. 安装 `src/family-admin/deploy/lampy-family-admin.service` 到 systemd，沿用具有数据库访问权的家庭服务用户，进程只监听 `127.0.0.1:8790`；模板限制凭据目录访问，不开放额外公网端口。
6. 现有 Caddyfile 中增加唯一一份 `src/family-admin/deploy/Caddyfile.example` 站点块。先 validate 再 reload，不替换其他站点。不要为 Admin 开启带凭据或正文的请求日志。
7. 启动 Admin 后访问 `https://admin.yunpura.com`；API、App 和 TestFlight build 12 不需重编。这里只增加独立 Admin 服务及访问审计表。

需要恢复旧 Admin 代码时，只停止／替换该独立服务；不恢复旧数据库覆盖已有举报处理，不回退已生效的内容决定。停止 Admin 也不会开放被限制的分享。

## 验收

先用专门测试家庭和测试举报，不使用无关私人资料。

1. 无登录不能读取列表、详情、媒体、历史或执行操作。正确凭据可登录，错误凭据无详细账号提示；频繁尝试受到限制。
2. Chrome／Safari 及手机宽度下页面可读、可滚动，筛选和分页不串数据；刷新保留未过期会话。
3. 打开举报可读正文，恶意 HTML 仅显示文字；照片／声音只在点击后载入；声音可播放、暂停和拖动。
4. 每项处理必须填写原因并再次确认，取消不写入；核对对应 App 行为与 #127 一致，已有私人原记录保留。
5. 两个浏览器页同时处理，旧版本提交被拒绝，刷新后再确认；正文及操作记录中的任意文本不能执行脚本。
6. 分享撤回或账号删除后，重新请求媒体拒绝提供，页面状态验证后收起；无关、未被举报媒体不能凭对象编号读取。
7. 退出、会话过期或重启后无法继续请求内容；退出清空详情与确认框内容，切后台停止声音。
8. 处理及访问审计存在，处理人、原因和时间正确；密码轮换重启使旧会话失效。

## 本地验证边界

本地 HTTP／SQLite、密码与会话、页面 DOM 交互测试不等同真实浏览器渲染。当前环境缺少可用浏览器引擎，下载也未成功，未宣称 Chrome／Safari 视觉、真实图片解码或音频播放通过。这些与 Caddy／DNS／TLS、主机权限和真实凭据一起保留为部署验收项。

本地已通过 7 个相关套件、63 项测试（包括 Admin 身份／会话／HTTP／DOM 与既有举报／清理／账号删除回归），另有正式 appstore-v1 配置 3 项测试通过。交互密码工具用合成凭据验证无回显并生成哈希，未创建任何真实管理员。TypeScript、Admin TS 的 ESLint、两个入口脚本语法及差异检查通过。DOM 检查不替代真实浏览器视觉与播放验收。
