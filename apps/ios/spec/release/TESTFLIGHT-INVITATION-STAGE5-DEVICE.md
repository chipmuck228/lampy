## 本次实施

- 邀请详情新增显式“保存到相册”，只保存选中且仍有效的家庭邀请 PNG，不自动生成新邀请、不保存任何 moment 图片。
- 保存前后检查页面/账号代次；只请求添加照片权限；本机临时 PNG 在 finally 中尝试清理，文件名不含邀请 token。拒绝权限或失败仍可分享链接。保存到系统相册是用户选择的持久副本，撤销邀请会令二维码失效，不会远程删除图片。
- 使用 Expo 57 兼容 expo-media-library 57.0.6（~57.0.5）；iOS 使用 add-only，Android 11+ 使用 scoped 写入。更旧 Android 不开放直接保存，继续分享邀请链接，不放开广泛存储读取。
- 图片添加用途说明在 iOS Info.plist 和中英 locales 中声明；更新 Archive 检查器，要求对应声明，不删除其他隐私检查。当前 settings 说明同步。
- 网页区分已安装打开、复制邀请和未安装的说明；微信提示使用浏览器或复制。没有自动跳商店或自动加入；剪贴板不可用时显示可选择复制的链接；读取有超时和重试。
- 原生入口兼容完整链接及 Expo 传入的严格 app-relative 路径；邀请仍只存于进程内存，不进入路由 query。拒绝新邀请时清理旧 pending 邀请；账号登录之后仍必须明确确认加入。服务端邀请码、单次使用、有效期、权限与数据模型均未变。

## 测试顺序

先完成 PR150 购买测试，不需要中途切分支。之后在 Mac 的本分支根目录运行原有 prepare-family-epub-device.sh sandbox（商品 lampyepubexport），覆盖安装；新依赖需要 npm ci、iOS prebuild 和 Pods，不能只刷新 Metro，不能卸载 App 清记录。

1. 创建者生成并展开邀请，进入页面不会自动保存。点“保存到相册”才请求添加权限，允许后照片中有可扫描的二维码，拒绝后可继续分享链接，不自动跳设置。
2. 保存等待中离开、后台、锁屏或换账号，不允许旧回调覆盖新页面或在检查失效后继续发起保存。过期/已用/撤销邀请不提供保存/分享操作。已有历史但本机无二维码时不伪造图片。
3. 新网页代码部署到隔离的 family-test 服务后，再验证 Safari/微信。尚未部署前，公网仍显示旧页，不应把旧网页当成本 PR 的结果。部署会重启服务，应安排在当前购买验收完成之后，不能顺带替换生产服务。
4. Safari 已安装：点击打开 Lampy，冷启动及已启动均到邀请预览；未登录先登录，再返回邀请并明确确认。仅打开、登录、取消不会加入。
5. 微信不能唤起时：按网页说明在浏览器打开；或复制邀请链接，在 Lampy 家庭页“通过邀请加入”中粘贴。自动剪贴板失败时可以手动选择复制。
6. 未安装：说明尚未开放公开下载；不出现假商店链接。将来正式上架后，在服务端明确配置真实 LAMPY_APP_STORE_URL；安装后需要重新打开/粘贴原邀请，不声称自动保留邀请码。
7. 普通成员、已满家庭、已用/过期/撤销邀请、切换账号、重复确认沿用原服务端校验。未验证真机、微信唤起、真实相册写入或公网部署前，不标记通过。
