# 家庭共享安全：实施与验收

基线：main 8cc9153（#124）。#124 的 8 项客户端验收已由用户在 iPhone 17 Pro / iOS 26.3.1 真机通过。服务器清理 timer 仍未部署验收。本片保持购买、个人及家庭导出和打印关闭。

## 已实施，待部署及真机验收

- 他人的家庭记录详情（含家庭列表内展开的详情）提供「⋯ → 举报这条内容／不再看这位家人的内容」。本人记录保留撤回入口，不提供举报自己。
- 举报可选不当内容、骚扰、隐私侵犯、其他，补充说明最多 1000 字；提交返回回执。设置 → 家庭内容「屏蔽与举报」显示本人的回执状态和已屏蔽家人，可确认解除。
- 举报只保存账号、家庭和分享引用、原因、说明、时间和处理状态，不复制正文或媒体。重复举报同一记录返回已有回执；同一请求 ID 更换内容报冲突；每账号每小时最多 10 条新举报，并限制新请求键为每小时 30 个。不可举报陌生家庭、本人或当前不可读分享。
- 屏蔽关系跟当前账号走，覆盖本人所属家庭，不移除成员、不转交 creator，也不通知对方。其他成员视图不受影响，作者本机私人记录不变。设置可在对方离开家庭后解除旧屏蔽。
- 家庭记录列表／详情／媒体授权、家庭册来源、正文、自动及手选封面统一过滤。家庭册 validation 随视图变化失效；收集全部时只收集当前可读记录。
- 本机屏蔽成功即停止声音、清掉页面视图、失效在途请求，再串行隔离该账号的家庭读取缓存（不触碰私人库）。解除也重新联网核验。磁盘删除失败沿用现有隔离与清理队列，不能承诺物理擦除成功。
- 家庭记录阅读每 5 秒续验、最长 15 秒读租约，网络失败不延长租约；家庭册沿用已有续验。其他设备屏蔽或运营限制需联网续验发现，不声称即时推送或追回 App 外副本。
- 账号删除清除相关举报、屏蔽关系和本人分享的处理记录；家庭解散清理同时删除该家庭的举报及处理资料。未分享私人记录不会提交给运营。
- 运营工具在主机通过受保护数据库访问，不开放公网管理 HTTP。限制内容对所有家庭读者生效；保留决定不会把此前限制解除。每个决定记录操作人、原因和时间。

## 云端升级

本片新增迁移 **33**。先备份正式 SQLite 数据库（使用 SQLite 一致性备份方式），按既有正式部署流程上传代码及安装完整依赖，停止 API 后以 `lampy-family` 服务账号和 `/etc/lampy/family.env` 运行 `family-api:migrate`，确认迁移成功再启动 `lampy-family.service`。不要用测试环境目录或重置数据库。无需购买密钥。

迁移失败应保持 API 停止，查明错误后再迁移／启动；新版本依赖 schema 33，不可只 reload App。服务成功启动不代表主机清理 timer 已安装。

## 运营命令

入口：`/opt/lampy-family/apps/ios/scripts/family-api-safety.cjs`。沿用 `systemd-run --wait --pipe --collect`，指定 User/Group=lampy-family、WorkingDirectory=/opt/lampy-family/apps/ios、EnvironmentFile=/etc/lampy/family.env，使用 `/usr/local/bin/node` 执行下列参数。普通 App 账号无法调用这些主机命令。

| 参数 | 用途 |
| --- | --- |
| `list` | 只列待处理回执编号、原因和时间，不列记录原文 |
| `inspect REPORT_ID` | 显式查看该举报及仍存在的家庭分享正文、媒体引用；不会读取私人库，CLI 不直接输出媒体文件 |
| `review REPORT_ID keep` | 标记已核对，不解除既有限制 |
| `review REPORT_ID restrict` | 限制该家庭分享，后续记录及媒体读取拒绝提供 |

review 必须通过 `--setenv=LAMPY_SAFETY_OPERATOR=实际操作人标识` 和 `--setenv=LAMPY_SAFETY_REASON=处理原因` 提供审计信息。inspect 输出包含用户提交及家庭分享内容，不要复制进公开日志或 PR。只应由授权处理人运行；部署端数据库／目录权限是访问边界。

## App 测试

两台设备或两个模拟器分别登录 A、B；A 创建家庭并邀请 B。B 分享带文字、照片、声音的记录，A 将其收进家庭册并设为手选封面；第三账号 C 用于验证他人视图不变。

1. A 打开 B 的家庭记录 → ⋯ → 举报。取消不提交；选原因提交有回执，设置可见且无原文、媒体；重复提交不制造重复回执。
2. A 屏蔽 B。原文、媒体、家庭册和封面隐藏，声音停止，反复切页和重启不恢复；C 仍正常阅读 B。成员关系和 B 私人记录不变。
3. 在设置确认解除，重新联网恢复仍有效内容；撤回的记录不可恢复。
4. 加载照片时屏蔽；迟到下载不能恢复被隐藏内容。后台、锁定、离页期间的迟到操作不弹回执或提交新的写入。
5. 运营 inspect 后 restrict；A/C 最迟在当前读租约失效后收起内容，旧媒体入口不可读，回执显示已限制。keep 有审计且不能解除限制。
6. 其他账号不能读 A 的回执，陌生家庭和过期成员不能举报／屏蔽。删除账号后重新 Apple 注册不恢复旧关系。
7. 中文／英文、大字号、横屏可用；私人记录、个人册和家庭册免费预览不回归；购买、导出和打印继续关闭。

## 上架前尚需落实

本片不能单独证明 App Store 内容安全要求全部满足。公开支持渠道、实际处理人和处理频率、举报及审计保留期限、发布前有害内容防范方案仍需确认和落实。未接入第三方自动扫描，也没有上传私人库做分析。运营工具存在不代表已有专人监控；完成服务器部署、运营演练和双账号真机测试前保持草稿状态。

## 本地验证

45 个 Jest 测试套件、395 项回归通过，覆盖内存／SQLite、迁移回滚、HTTP 权限、运营 CLI、缓存迟到结果、页面和中英文说明。后续幂等限制调整的相关账号删除／安全测试另做针对性复验。TypeScript、针对性 ESLint、CLI 语法和差异空白检查通过。Linux 环境不提供 iOS 原生编译或真机验收证据。
