# 1.0.0 家庭内容安全最小首发

基线 main 8cc9153（#124）。本分支独立交付；#125 保持暂停，不合并、不部署其分支。复用其中经审查的举报、屏蔽、媒体及家庭册可见性实现，再补本次确定的最小范围。

## 已确定的产品与运营规则

- 支持及申诉邮箱：**dev@yunpura.com**。开发者每天查看待处理举报，内部目标为 24 小时内初步处理，严重情况优先；该目标不是 Apple 保证或统一法定期限。
- 家庭记录详情「⋯」提供举报与屏蔽。举报原因：不当内容、骚扰、隐私侵犯、其他；补充说明可选，最多 1000 字。成功有回执，可接着选择屏蔽，不自动删除内容。
- 家庭成员面板可选他人并屏蔽，包括普通成员对创建者；屏蔽不改变成员关系。设置「屏蔽与举报」管理已屏蔽家人、查看本人回执、账号分享限制及被限制分享的编号，提供邮件联系入口。无邮件客户端时显示可手工使用的邮箱。
- 屏蔽关系跟当前 Lampy 账号走，覆盖所有共同家庭。列表、详情、媒体接口、家庭册来源、正文和封面统一过滤；其他家人视图与作者本机私人记录不变。解除后联网恢复仍有效内容，不能恢复撤回或下架内容。
- 分享提交前，服务器对文字、感受、昵称、家庭名称、家庭册名称及开篇执行基础规则检查；明确命中时拒绝该次发布，不修改私人原记录。规则归一化字符宽度、大小写及零宽字符，仅涵盖少量明确威胁和儿童色情短语，存在漏判和误判；不是完整语义审核，也没有图片扫描或声音转写。对误判可通过支持邮箱申诉。
- 开发者经人工核对，可下架某条家庭分享；严重或重复违规可限制该账号继续分享，复核后可解除账号分享限制。已下架分享不会因解除账号限制自动恢复。阅读、私人记录和其他成员内容不连带删除。
- 不开放公网运营接口；不增加运营 Web、自动邮件、推送或付费功能。购买、个人及家庭导出、打印继续关闭。

## 隐私与读取边界

举报仅保存必要账号与分享引用、原因、说明、时间和处理状态，不复制正文或照片／声音。查看举报时，只按需核对仍存在的被举报家庭分享，不读取未分享私人库。作者提示不含举报人身份或说明；运营原因不直接返回作者。

屏蔽成功停止声音、失效页面和在途请求，并隔离该账号家庭缓存。家庭记录采用 5 秒续验、最长 15 秒读租约；家庭册沿用已有续验，断网不延长授权。其他设备的操作在联网核验时发现，不承诺即时推送或追回 App 外副本。

删除账号清除相关举报、屏蔽、本人分享处理和账号限制／审计资料。家庭解散时，其举报及分享处理资料随既有家庭清理流程移除。独立的举报及审计时间保留上限尚未落实，需在隐私保留规则收口时明确；本片不宣称已完成完整数据保留合规。

## 服务端迁移与部署

新增 **schema 33**，仅从正式 schema 32 升级。不得先部署旧 #125 的 schema 33：本分支的 33 包含账号分享限制表。若已部署过旧草稿，需要另行增量迁移，不能假设同号迁移会重跑。

按现有正式部署流程：一致性备份 SQLite → 上传本分支代码 → 安装完整依赖（含 TypeScript）→ 停 API → 使用服务账号、正式环境文件运行 `scripts/family-api-migrate.cjs` → 成功后启动 API → 检查 health → 更新 App。迁移失败保持 API 停止，不重置数据库。现有清理 timer 已由操作者验证手动及定时空队列运行成功，不需重新创建。

本文件使用操作者提供的运行环境，不记录主机地址、SSH 身份、服务账号或生产文件绝对路径。

## 开发者每日处理

用服务环境、授权账号在主机运行 `scripts/family-api-safety.cjs`。数据库文件权限和主机权限是访问边界，无需购买密钥。

| 参数 | 行为 |
| --- | --- |
| `list` | 列待处理回执编号、原因和时间，不列正文 |
| `inspect REPORT_ID` | 显式查看被举报分享的正文及媒体引用；不输出媒体二进制，不查询私人库 |
| `review REPORT_ID keep` | 标记已核对，不解除已有限制 |
| `review REPORT_ID restrict` | 下架该分享，拒绝所有家庭读者及媒体读取 |
| `author REPORT_ID restrict` | 限制被举报作者新增家庭分享，保留原有阅读能力 |
| `author REPORT_ID keep` | 复核后解除账号分享限制，不恢复已下架分享 |

review／author 必须提供 `LAMPY_SAFETY_OPERATOR` 和 `LAMPY_SAFETY_REASON`，记录操作人、原因、时间。author 不代替单条举报结案，需要另做 review。工具只依据实际举报定位作者，不能从公开 HTTP 调用。

每天：检查待处理队列 → 显式核对被举报内容（必要时按受保护媒体引用检查照片／声音）→ keep 或 restrict → 严重／重复违规再限制作者 → 复核 App 回执和阅读权限。收到邮箱申诉后人工复核，用邮箱回复；不要求接入 Resend。inspect 输出含私人家庭分享内容，不写入公开日志、PR 或截图；核对媒体时不创建长期外部副本。

## 待执行的发布验收

两账号 A/B（最好双设备），A 创建家庭邀请 B，B 分享文字、照片、声音；A 收进家庭册并设为封面。第三账号 C 用于核对其他家人不受屏蔽影响。

1. 举报取消不写入；提交有回执，重复提交不重复建单；可继续确认屏蔽，设置可查看状态。
2. 普通成员可从成员面板屏蔽创建者；不能因此得到移交／移除权限。屏蔽覆盖家庭列表、详情、照片、声音、家庭册正文与封面，重启后保持；C 仍可阅读。
3. 加载媒体期间屏蔽，迟到结果不恢复内容；解除屏蔽后，撤回和运营下架内容仍不可读。后台／锁定／离页后的迟到确认不提交写入。
4. 用测试文字 `kill you` 或 `杀了你` 测试分享检查；本机原记录不变。正常文字、照片及声音可分享；昵称、家庭名、册名和开篇也检查。
5. 运行 list → inspect → review restrict；A/B/C 联网核验后不再获得该分享及媒体，举报者回执已限制，B 的设置显示被限制编号；不暴露举报人身份。
6. author restrict 后 B 新增分享失败但仍能阅读；退出／重进不能绕过。author keep 后可分享，原下架内容仍不可读。无操作人／原因时命令拒绝执行。
7. 支持邮箱可见，邮件入口可用；未安装邮件客户端时仍能读到邮箱。中文／英文、大字号、横屏和本机保护可用。
8. 私人记录、个人册和家庭册预览回归；购买、导出和打印仍关闭。删除测试账号后相关安全数据清除。

本地自动检查不替代服务器迁移、每日运营演练和双账号真机验收；有限文字规则不代表所有媒体均已自动审核，也不保证 App Store 审核通过。
