# 页面与流程

采用现有暖纸色、系统图标、统一文字组件和 48pt 点击区；文案中英文成对交付。当前固定字号策略不重新引入系统字号驱动布局。短屏、横屏和 iPad 保持可滚与操作可达。

## 个人与家庭入口

当前 Release 不新增可用家庭入口，不改变底带的最近 / 回看 / 生活册。后续受控验收再决定家庭入口位置，不挤掉个人记录入口。本机保护先解锁；家庭登录再独立请求，取消任一步仍能回个人功能。

无家庭：安静说明“和家人分享你愿意留下的片段。”，创建家庭 / 打开邀请。不提供搜索家庭、搜索用户或申请加入。多个家庭按名称与本人角色展示，可切换；未登录不展示上次账号家庭。家庭名称由创建者输入，服务器校验长度，正式实施时确定限制与内容处理。

## 创建与发出

登录 → 输入名称 → 创建 → 家庭页。达到 10 个显示明确上限，失败不伪装成功。
创建者 → 邀请家人 → 展示有效期与“可供 1 位新成员加入” → 系统分享 / 复制链接 / 展示二维码。创建者可看自己发出的邀请状态并撤销。不搜索接收者、不访问通讯录、不自动发 IM。

## HTTPS 邀请网页（待实现）

候选地址 family.yunpura.com/invite/{token}，不是已部署路由。有效时显示 Lampy、家庭名称、到期时间、一次加入名额、打开 Lampy、下载安装。说明：“安装后，请重新打开这条邀请。”“加入不会自动分享你的个人记录。”

不显示成员名单、手机号、Moment 正文 / 图片 / 声音。无效未知 token 给通用说明；过期 / 撤销 / 已用 / 解散显示对应不可加入状态及联系邀请者建议。网页只预览，不创建账号或 membership，不因访问扣名额。无第三方分析脚本；Referrer-Policy: no-referrer，缓存 no-store，并在代理层屏蔽 token 日志。

尚无正式 App Store 下载地址时，只能使用真实获准的测试渠道；不得虚构商店链接。Universal Links 的 AASA、Associated Domains 和实机跳转后续单独交付。

## 接受

已安装：外部链接 / 通用扫码 → App → 本机解锁（如开） → 登录（如需） → 家庭名称、历史可读说明、确认加入 → 服务端重新裁定 → 家庭内容。
未安装：网页 → 安装 → 重新点原链接 / 扫原码 → 同上。不承诺安装后自动接回原邀请；不做剪贴板偷读或设备指纹匹配。

仅用户实际打开的邀请可作为暂存待办；安全存储、短期有效、退出账号 / 完成 / 撤销时清除，最终还要重新确认。不自动接受，不是内部邀请 inbox。失败保留可重试意图；已是成员可进入，超上限不消费名额。

## 分享与管理

个人详情 → 分享到家庭 → 选家庭 → 原文媒体预览 → 明确确认 → 服务端保存 → 家庭中可见。
家庭页读快照，不借标题替换个人“最近”。网络失败保留个人原件；可重试同一操作，不能重复分享。
成员页 → 离开（解释分享保留） / 创建者管理移除、转交、解散。撤回从本人分享管理单独进入。退出账号只清账号家庭视图与受控缓存，不删除个人库。

上述为文字设计流程；没有可运行截图、静态稿或设备 PASS。
