## 必验

| 场景 | 预期 |
| --- | --- |
| 未登录个人记录/生活册；本机保护 | 原个人闭环不变；认证期不露家庭和个人内容 |
| 两账号同名邮箱；同账号双设备 | 不合并账号；设备会话按新契约各自恢复 |
| A 创建/B 成员/C 另创建 | 家庭目标与角色分开，不串缓存/请求 |
| 已有 9 家庭并发创建和加入 | 最多 10，失败不占邀请；离开后可再加入 |
| 成员发邀请、移除、解散 | 全部拒绝；无搜索/内部邀请入口 |
| 两人同时用一邀请 | 只有一人成功；事务失败可重试不损名额 |
| 已成员确认/成功重试/离开后旧 token | 前两者无重复扣减；最后不得重新加入 |
| 7 天边界、撤销与接受竞争、解散 | 以服务端事务/时间为准，无半加入 |
| 通用扫码未安装→安装→重新打开 | 明确路径可完成；无虚假自动恢复 |
| 链接打开后锁定、登录取消、后台 | 不自动接受，不迟到拍照/录音，不泄露内容 |
| 分享 mixed Moment、源 revision 改变 | 精确字段和媒体；不混版本；Album 不上传 |
| 新加入/重新加入、旧策略未确认 | v2 读有效历史；legacy 不静默扩大读权 |
| 分享列表/详情/媒体；撤回/退出/移除 | 同一授权规则；迟到下载不复活缓存 |
| 离开家庭 A 且仍在 B | A 失权、B 可用，个人原件不变；A 原分享默认留 |
| 前成员撤回本人分享 | 能撤本人、不能读其他人或恢复成员权限 |
| 转交接受/取消/并发/对方已离开 | 恰一创建者；不转移收费；原角色直到成功才变 |
| 解散/任务失败/服务重启/跨家庭媒体 | 立即拒读；截止持久化、重试；B 引用不误删 |
| 断网、401、读取失败、退出账号 | 家庭失败与空分开；本机数据正常；缓存不能冒充授权 |
| 中英文、短屏、横屏、iPad、VoiceOver | 关键确认与取消可达，48pt，原文不翻译 |
| 公开注册开放检查 | 未有真实账号删除、UGC/运营前置项不得开放 |

双账号/双设备、公网 HTTPS 身份、历史分享、媒体、邀请网页和清理必须分别记录设备、构建/JS SHA、服务端 SHA 与实际结果。模拟器不能写真机 PASS；生产进程/库版本本轮 NOT VERIFIED。
