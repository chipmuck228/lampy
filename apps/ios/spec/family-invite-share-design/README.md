# 家庭邀请与分享闭环 · 阶段 A

日期：2026-10-08。源码基线：`d2d9d442d6dbebf571a17eaf5460d31296ff08ad`。

这是独立设计 PR，不是运行实现或设备验收。只改 spec；不改个人库、账号、家庭服务、生产 env、DNS、TestFlight 或付费。家庭入口保持关闭，identityLoopAccepted 不推进为 true。

## 固定产品决定

| 项目 | 第一版规则 |
| --- | --- |
| 个人功能 | 本机即可记录、回看和生活册；可选 Face ID / 设备密码保护，不要求注册 |
| 家庭身份 | 首次创建或加入时登录；账号身份不等于成员资格 |
| 多家庭 | 同一用户可同时创建和加入；最多 10 个有效家庭，合并计数 |
| 邀请 | 仅创建者生成，固定 7 天 / 1 个成功加入名额，可撤销 |
| 送达 | 系统分享交给外部 IM / 短信 / 邮件；没有内部邀请消息系统 |
| 内容 | 只分享明确选择的 Moment 独立快照，不分享生活册、不自动上传个人库 |
| 历史 | 当前有效成员可读仍有效的历史分享；重新加入也如此 |
| 离开 | 默认保留既有分享，撤回是独立操作；个人原件不受影响 |
| 创建者 | 转交给已加入成员且对方接受，或解散后才可离开 |
| 解散 | 立即停止读权和邀请；30 天内清理家庭分享及不再被引用的媒体 |
| 账号删除 | 本阶段不实现；真实账号删除是正式开放注册的前置项 |

30 天是此版对“1 个月”的确定执行口径，从服务端 dissolvedAt 起计算，不是恢复期。10 个上限可日后另改规格；本版不得让客户端配置绕过。

## 与旧规格的关系

本稿为后续实施的新产品依据，明确替代 ADR 0006 的“最多一个家庭”和“加入前不可见”两项，以及 FAMILY_ACCESS_AND_SNAPSHOT 对应矩阵。旧文档保留为历史依据；本设计合并本身不改变旧代码的授权。个人库隔离、固定 revision 快照、无法确认权限不展示、不能收回设备外副本等原则继续有效。

创建者付费、成员共享是后续方向：权益按家庭判断，用户可在不同家庭有不同角色；转交角色不代表自动转移订阅或向接受者收费。本阶段没有价格、购买或 StoreKit。
