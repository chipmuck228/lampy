# 固定契约

## 身份与家庭

个人 ownerId=local-user 不改；登录不迁移、不绑定个人记录。服务端 userId 是稳定账号标识。Apple subject 独立关联；不按同名邮箱 / 手机号自动合并账号。手机号 / 短信是将来的登录切片，不用模拟验证码冒充真实验证。

每个有效家庭恰有一个创建者；角色按 familyId 计算。同一 userId 在同一家庭只能有一条 active membership。创建与加入均在服务端事务内检查有效家庭数量 < 10；客户端预判只作提示。已是目标家庭成员返回现资格，不新增 membership、不扣邀请名额。离开、被移除、已解散不占上限。

服务器逐请求校验账号、当前家庭状态和成员关系。无网络或资格未知时不显示家庭缓存；个人功能继续可用。缓存不能证明授权。

## 邀请

创建者为指定家庭生成安全随机 bearer token，固定 expiresAt = createdAt + 7×24h，最大一个成功新加入。邀请可转发，持有链接不等于被指定真人；不承诺身份定向。

浏览、扫码、安装、打开 App、锁定、登录、取消确认、失败、超 10 家庭上限，都不消耗。服务端一次事务完成：验证家庭与邀请 → 当前成员幂等检查 → 上限检查 → 原子 claim → 建成员 → 保存结果。事务失败不能占名额。

有效边界以服务端时间为准；now >= expiresAt 不可新加入。撤销、解散、接受竞争按提交先后裁定，不能产生半加入。已为成员重复确认返回当前成员资格（家庭须仍有效），不借旧邀请建立新关系。

已成功接受后重试同一命令：仍是成员则同一结果。已离开或被移除后，旧已用邀请 / 旧幂等结果不得让其自动重新加入；必须由创建者发新邀请。其他人使用已用邀请返回已使用。最终接受必须重新校验，网页“有效”不是资格承诺。

邀请码仅存安全哈希；token 不进访问日志、分析、崩溃正文或第三方脚本。生成时提供一次链接，遗失可撤销并重建；不为再次分享持久化明文。生产缺安全随机数则拒绝生成，不退回 Math.random。预览和接受防枚举、限速，异常不泄露私人信息。

## 分享与阅读

用户确认目标家庭与白名单字段（原文、原感受、发生时间及精度、选中媒体与来源）。不上传未选媒体、人物 context 或整个领域 JSON；绝不上传设备路径。首次分享提示：“加入这个家庭的成员，也能看到这里仍保留的分享。”

目标 familyId、Moment ID、revision 和字段在本次操作固定；切家庭、账号、锁定或失焦不得使迟到结果投到新目标。上传后、保存前复查来源；原件变化则重试或失败，不混版本。

现成员能读所有仍 active 的该家庭分享，不按 joinedAt 或旧冻结 audience 限制。撤回、家庭解散、退出、被移除、账号会话无效立刻阻止对应服务端读请求。不会读取未分享个人记录。接收副本是家庭缓存，不 upsert 为个人 Moment。

分享成功只表示服务端保存，不表示每位家人已收到。用户主动播放声音；目标或账号变化暂停，不自动续播。退出默认保留本人已分享快照；删除个人原件不自动撤回已分享快照。

## 离开、转交和解散

成员主动离开或创建者移除成员：撤销该家庭读权，清该 family 缓存，不影响其他家庭或个人库；既有分享默认保留。退出确认解释这一点。

撤回本人分享是独立命令。前成员可在“我的家庭分享”受限管理路径找到本人曾分享的必要信息并撤回，不可借此读其他人内容或恢复家庭访问。只能作者撤回；重复撤回幂等。已解散的家庭仅报告清理状态，不恢复读权。

创建者不能直接离开或移除自己。转交：选现成员 → 发起 → 接受者登录后主动接受 → 事务内复核双方仍有效、原创建者和转交版本 → 原创建者改成员、对方改创建者。待接受可撤销；对方离开或家庭解散使请求失效。转交不发内部邀请加入通知，不增加自动消息系统；成员管理页显示待处理转交即可。转交期间原创建者仍负责。付费责任另行显式确认，未具备付费政策不得静默转交收费。

解散需破坏性确认：立即停止全员访问、撤销全部邀请、终止待转交；服务端记录 dissolvedAt 和 cleanupDeadline。30 天内清家庭快照及无其他有效引用的媒体。没有恢复窗口，不能再加入。清理失败重试并报警，不能只靠页面文案承诺。数据库保留最小必要的幂等 / 清理审计，不保留可复原正文媒体。

## 注册开放边界

本阶段不做账号删除，保持受控测试及家庭入口关闭。正式开放注册前必须交付真正的账号删除：身份确认、所有会话撤销、创建者转交或解散处理、分享与媒体处置、标识清理和失败恢复；退出登录、离开家庭不能代替。UGC 举报 / 屏蔽 / 联系渠道等正式分发要求也需独立审查；本稿不是合规完成声明。
